# 剧情框架 · 06 伪装受辱后清算

> 来源型复用卡。分类、归类边界与使用方式见[总索引](../爆款结构库.md#plot-library)；数据与复用记录沿用原卡入口。

## 一句话机制

主角先伪装成失能、弱势的一方，放任亲属在利益分配现场暴露嘴脸；旧账与实力揭晓前后夹击，最终决定断绝关系。

## 完整骨架

夫妻密谋建立伪装 → 掌权亲属公开不公分配 → 受宠者和帮凶递进羞辱 → 主角翻旧账但暂未翻盘 → 外部商业成果到场改变利益格局 → 按原版本穿插带货与撕伪装 → 亲属因钱变脸 → 用前账或实物封住辩解 → 拒绝新索取、断亲并互动收束。

旧账先使观众看到情义债，资金或实力揭晓再改变谁有裁决权；反派翻脸讨好是第二次暴露。两者都保留，不能只剩助手报出一笔钱。

## 保留与换新

- 保留：预先伪装、分配现场的多方功能、旧账反击暂时受阻、财富与伪装双重揭晓、掌权者变脸后的再清算。
- 原卡中的开口、撕绷带与带货先后并不一致，分别跟随装哑和装残版；装残版U盘封路不得自动复制到装哑版。
- 真实落难不归此处：《装哑分红打脸》尾部32号变体已有独立清洁棒结构卡，主归“落难逆袭—蛰伏翻身后清算”，不计本类新增来源。
- 换新：分配对象、偏心资源、贡献旧账、伪装载体与台词；先假弱、后揭真的因果仍需保留。
