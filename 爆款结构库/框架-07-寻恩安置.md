# 剧情框架 · 07 寻恩安置

> 来源型复用卡。分类、归类边界与使用方式见[总索引](../爆款结构库.md#plot-library)；数据与复用记录沿用原卡入口。

## 一句话机制

一个自己也很困难的人先救助他人并离开；受助者追寻恩人，发现他未被看见的困境，再当面兑现回报。

## 完整骨架

旁观者冷漠形成救助缺口 → 英雄立即出手 → 因自己的家庭急事先行离开 → 被救者苏醒后寻找恩人 → 揭开恩人的经济与家庭困境 → 找到人后当面重述救助行为 → 提供能解决眼前困难的资源 → 恩人淡化付出、对方逐件回敬恩情账 → 承接带货 → 恩人确认这次行动值得并提出利他收束。

先救人、后发现英雄也需要帮助，使回报有明确来处。追踪把救人场与困境场接起来；不是主角临时遇到一个愿意送钱的陌生富人。

## 保留与换新

- 保留：救助行为真实、施助时不图后报、恩人先离开、受助者主动追寻，以及回报准确解决已经呈现的困难。
- 本版无传统反派、无强制惩罚环节；冷漠旁观者只承担救援对照，不自动扩写为待清算反派。
- 换新：事故与救助动作、必须离开的急事、追踪线索、家中困境、逐件重述的付出，以及可实际兑现的援助。救人和受助对象之间的关系须与所选来源同功能。
