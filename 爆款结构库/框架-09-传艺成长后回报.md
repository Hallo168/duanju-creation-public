# 剧情框架 · 09 传艺成长后回报

> 来源型复用卡。分类、归类边界与使用方式见[总索引](../爆款结构库.md#plot-library)；数据与复用记录沿用原卡入口。

## 一句话机制

落魄者获救助、收留和谋生技艺，靠真实成长获得回报能力，再回到恩人身边兑现恩情与关系选择。

## 完整骨架

救助落魄者 → 身世铺垫说明无处可去 → 收留争议与安顿 → 日常相处积累情感并有撮合线 → 手把手传授谋生技艺 → 出师离别时继续给予实际帮助 → 时间跳转、成长成果使身份改变 → 归来用同一技艺回馈恩人 → 承接带货 → 报恩转为求婚与团圆。

技艺把“当年收留”与“如今有能力报答”连在一起；时间经过使成长真实。归来目的由恩情和关系决定，不由虚构的复仇对象决定。

## 保留与换新

- 保留：真实落魄、救助收留、具体传艺、离别、时间成长、回归回报，以及原版婚恋承诺的落地。
- 原版无伪装、无测试、无反派打脸。收留过程中的争议或担心不等于必须建立一个恶人。
- 换新：失意遭遇、收留场所、传授的谋生技能、离别相助物件与回报方式；技能必须能解释之后的成长，不能把六年打拼改成“其实一直是富豪”。
- 原稿中产品承担传艺信物，这里只记录该结构功能；实际选品与植入仍走原有带货规则和产品事实源。
