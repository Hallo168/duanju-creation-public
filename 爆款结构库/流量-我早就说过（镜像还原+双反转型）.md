# 我早就说过（镜像还原+双反转型）｜原对标库01，可当原稿，原稿存 归档/对标库/01-我早就说过/

> 分类：流量剧本（爆款结构库卡片，索引见 ../爆款结构库.md）

- **核心机制**：高频指责型口头禅（"我早就说过"）遭镜像还原＋实物归位双打脸——第一反转用对方原话还原其自己犯过的同类错（动摇态度），第二反转实物证据揭示犯错的恰恰是指责者本人（摧毁立场），两层必须紧挨
- **人物配置**：指责者/被打脸者（父亲）、承压者（母亲，终极温柔打脸输出）、嘴替/镜像执行者（儿子）
- **结构链**：找钥匙冲突直给钩（0-3s"我早就说过"）→ 指责升级+范围扩大到儿子 → 危机中仍旁观指责（压迫顶峰）→ 儿子正面反驳 → 镜像还原昨日找遥控器场景以原话反击（打脸Ⅰ）→ 全家找到钥匙在父亲自己口袋（打脸Ⅱ）→ 母亲温柔反问"我要是也说我早就知道，你心里舒服吗"（终极爽点：有权力报复但选择不报复）→ 破壁选择题收尾（"互相指责还是先伸手帮一把？"）
- **可复用点**：镜像情景还原反击法（需对方有观众也知道的同类前科）；实物归位二次打脸（两层间隔>30秒则失力）；温柔反问式打脸（仅适用家庭/亲密关系且打脸者已握绝对优势）；打破第四面墙的二选一收尾（产出两派站队辩论，比"你们支持吗"互动强）
- **情绪路径**：愧疚共鸣（长期被"马后炮"压迫）→愤怒→解气（镜像）→爽感翻倍（实物）→温暖释然
- **注意**：钩子绑"我早就说过"式家庭话术，换职场/陌生人冲突不成立；温柔和解结局不适合狠爽点/带货题材；三代共鸣结构（儿子=年轻嘴替、母亲=中年隐忍、父亲=老年自省）
