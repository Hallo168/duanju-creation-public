## 剧本类型与观众抓手

- **类型**：带货；岗位竞争与专业碾压引擎。不是预先安排的装穷测人心局，也不是被偷作品的原创者认领局。

- **核心机制**：底层劳动者遭公开践踏 → 实力者出头而被连带剥夺机会 → 现场高位者身份公开、阻止滥权 → 保护伞仍以关系内定抗辩 → 同场同题产品考核 → 关系户先答暴露业务空白、实力者后答建立专业优势 → 高位者背书集中收单 → 兑现职位与现金 → 保护伞以资历反扑、两级清退 → 公平价值提问。

## 情绪路径与关键反转

**情绪路径**：受辱愤怒 → 出头也丢机会的憋屈峰 → 高位现身的第一拍解气 → 保护伞介入的再压迫 → 草包先答露短 → 真本事后答的专业爽 → 奖赏兑现 → 两级清退的终峰 → 公平站队互动。没有材料支持认亲、救命、婚恋或额外家庭危机支线。

**反转**：一是秘书问候确认裁决者身份，反转剧中权力关系；二是同题先后回答，暴露业务能力与岗位占有不匹配。清算不能提前到考核之前，身份揭晓也不能直接替代能力验真。来源把女孩称“真正创作者”、女主管称“冒名者”，但具体事件只支持“有实力的竞争者／关系户”，不支持作品遭盗用或专业证件造假。

## 可复用点、必须换新与换皮限制

**可复用五件**：一、护人先付机会成本，正面人物有行动；二、掌权者先被动显权，再以规则裁决；三、护短关系使考核成为必要；四、同题先后回答形成可见能力差，专业讲解接带货；五、利益兑现与两级清算都压在促单后。

**必须换新**：送件员／应聘女孩／主管外甥女／总监舅舅的人物组合，公司大厅和暴雨，合同与简历，岗位名与奖赏名目，踩物撕纸羞辱、秘书迎接和推车大讲堂的场面，以及剧情台词措辞。财力仍为经营组织＋十万元级重奖，不擅自升为亿万继承局。

**负向不变式**：
1. 主角知道高位身份才护人＝自证变投机，必须在未知权力时付出机会成本。
2. 删开场的另一名劳动者＝仗义出手失去触发器，主角退化为只替自己讨公道。
3. 高位者现身直接发职位＝专业考核失去必要性，回报退化为另一种内定；他可以目击恶行，但能力仍须现场验证。
4. 关系户只被一句“错了”判输＝看不到业务差距，必须先给具体的空泛或外行回答；不得借此暗示未核验的食品医疗功效。
5. 考核脱离产品或先讲工艺奇迹直接治好人＝原来的专业讲解验真被换掉；保持同题、公平条件与先弱后强对照。
6. 报价抢在真本事展示之前，或在此前把反派彻底清退＝商品段失去信任来源或未决强期待。
7. 只教训关系户、放过仍护短的上级，或奖赏只许诺不兑现＝双清算／好人得报的结局落点缺件。
