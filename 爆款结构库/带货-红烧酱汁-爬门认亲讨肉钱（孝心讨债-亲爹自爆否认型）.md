# 红烧酱汁 · 爬门认亲讨肉钱（孝心讨债 · 亲爹自爆否认型）｜原稿存 对标原稿/08-三十块钱的红烧肉.md

> 分类：带货剧本（爆款结构库卡片，索引见 ../爆款结构库.md）

- **核心机制**：**用最小的诉求撞最大的冷漠**——孩子进城只要三十块钱、只要一块爷爷咬得动的肉，而亲爹刚给宠物订了两千九的蛋糕。反转不靠工具人报身份，靠**反派自己开口否认亲女**（自爆式）；打脸执行者是**反派新家庭的自己人**（岳母＋妻子），不是外人——他攀附来的那个家反过来清算他，是本卡最值钱的设计。库内唯一"儿童当同情锚点＋隐形瘫痪老人做催泪发动机"的带货卡
- **信息差方向**：观众全知型——第一场孩子就报出父亲姓名，观众全知她是谁的女儿；拉力＝"他到底认不认"。底牌对**剧中人**保留到反派开口那一刻
- **人物功能配置**：同情锚点／视觉钩执行者（孙女，最小诉求的载体）、道德权威兼审判官兼带货主讲（岳母，前大厨＝与产品职业天然绑定，一人三职）、清算输出机兼带货捧哏（妻子）、自爆型反派（入赘女婿，靠"给狗订蛋糕"＋"管岳父叫爸"两处自己送上门）、**隐形受害者**（瘫痪爷爷，全程不出场——越不出场越催泪）
- **结构链**：孩子攀爬豪门大门＋喊报警（视觉钩）→ 开门盘问 → 手机录音实物证据＋"数了三年星星"催泪 → 妻子召丈夫 → 反派捧着宠物蛋糕进场自爆 → 当众否认亲女"哪来的小叫花子"（愤怒峰值）→ 孩子自我贬低"是我认错人了"（反向催泪引信）→ 两代女人逐条清算＋"忘本"审判 → 后厨教学式对话带货 → 给最后一次机会＋接爷爷 → 镜头求认同
- **情绪路径**：紧张（爬门）→心疼（血手／找爸）→催泪（录音）→**愤怒峰值·第3场"小叫花子"**→解气（清算＋审判）→暖（做肉）→**催泪二峰·"爷爷一年没吃过肉"**→释然团圆。双峰分居 3、4 场
- **关键反转**：非身份反转，是"**孩子的爸就在这屋里，而且当众否认自己女儿**"；由反派亲口完成，比工具人揭晓更冲。第二证据为手机录音（父亲当年的承诺）
- **产品切入**：生活痛点＋**主讲人职业绑定**（岳母下过大灶）。轻伏笔＝孩子布袋里死死护着的野蜂蜜（不是产品，是"孝心信物"）；正式带货在第4场、**打脸之后**、对话式，孩子问"真不烫手吗""真不放油啊"、妻子捧"这什么神仙味道"；话术链＝痛点（老人牙口／炒糖色烫手）→旧方案对比（饭店冷冻肉＋色素＋来回小三百／熟食店不放心／自己做怕做砸）→三步用法（焯水→倒酱→加水炖，牙口不好多炖二十分钟）→成分背书（盐生抽老抽冰糖全配好、天然红亮）→场景铺开（排骨鸡翅鱼一袋通吃）→三人接力试吃证言→算账（二十块鲜肉＋一包＝不到三十）→活动价（九块九到手七包）→包邮→渠道；返回主线＝给反派最后机会＋进山接爷爷
- **金句句式骨架**（原句措辞禁入二创稿）：数字对照定罪式（"两千九孝敬一条狗，你亲闺女要三十块"式）；忘本定性（"人活一辈子，最怕的就是忘本"式）；孝心非钱式（"孝心不在钱多钱少，在那份心意"式）
- **刺痛词位**：全在反派嘴里且集中一场——"这哪来的小叫花子？赶紧轰走啊"（最毒）、"不……不认识"；**反向刺痛引信在受害者嘴里**：孩子那句"对不起，是我认错人了"比任何反派台词都疼
- **可复用点**：最小诉求撞最大冷漠（三十块钱对两千九，金额差本身就是爆点）；反派自爆式否认（不用工具人揭晓）；**打脸执行者＝反派攀附来的新家庭**（他跪着求来的门，反过来把他扫地出门）；隐形受害老人（不出场，靠转述催泪）；受害者自我贬低做反向催泪引信；教学式后厨带货＋主讲人职业绑定；孩子提问替观众问出全部卖点
- **注意**：①**孩子对同一人先叫"奶奶"后叫"姥姥"——称呼漂移真实事故，事实一致性反面教材，绝不复制**；②"沈千金"疑为角色占位名而非真名，原稿人物命名不完整；③阿拉伯数字遍布（两千九／三百六十五／一一零／三十／九块九），须全转中文，"一一零"须去除；④"日本和牛""五星级酒店"须换泛称；⑤**爬铁门是生成灾难**（高空＋攀爬＋手部血伤），视觉钩借用时必须换手段；⑥后厨连续实操（焯水／撕袋／倒酱／揭盖／夹肉）密度极高，二创须压成"成品特写＋台词讲步骤"；⑦宠物（狗）入镜是一致性高危项，挥霍对照物建议换；⑧"入赘"设定与"岳母有权逐女婿出门"经不起现实推敲，靠爽感托住即可；⑨结尾"你们说，是不是这个理"为求认同式，撕不起来，二创宜换站队提问；⑩无来源方数据，骨架有效性未经我方验证
