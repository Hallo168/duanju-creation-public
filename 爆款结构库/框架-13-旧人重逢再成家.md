# 剧情框架 · 13 旧人重逢再成家

> 来源型复用卡。分类、归类边界与使用方式见[总索引](../爆款结构库.md#plot-library)；数据与复用记录沿用原卡入口。

## 一句话机制

第三方撮合把曾经错过的两人带到现场，高位者的低条件试探撞上旧人的真心接纳；穿帮后承担试探责任，再以家庭承诺重新成家。

## 完整骨架

撮合者先斩后奏约人 → 家庭缺口使高位者答应赴约 → 高位者自主伪装且观众获得原版程度的提示 → 现场打照面才认出旧人 → 旧人面对落难说法，先用具体行动接纳 → 善意家庭责任的话说到一半形成悬念 → 纯公务携样品到场使身份穿帮 → 对方亲自实测、反馈与报价带货 → 回到试探质问 → 本人认错并交代事前不知是旧人 → 揭开善意抚养责任 → 自主求婚与应允 → 撮合者见证、家庭团圆与祝福出口。

旧人接纳发生在知晓财富之前，身份揭晓才有情感意义；试探解释使接纳不等于默认被欺骗，家庭责任的坦白再支撑成家选择。两个悬念压住带货：真实身份怎么解释、未说完的家庭责任是什么。

## 保留与换新

- 保留：撮合者先约、高位者被动赴约且伪装自定、到现场才认出旧人、低条件下实际接纳、公务穿帮、认错回收及自主成家。
- 原对标42的善意身世属于完整版本：抚养亡兄遗孤，不换成恶意隐瞒；原卡中的供样实测承担穿帮与转化双功能，不能只报身份直接报价。
- 全片无反派、无新增打脸。关系重新成立是结局；辅助标签“装穷单测”不触发旧综合框架的三连测或清算模板。
- 换新依所选档位：人物身份、见面场景、旧恩账、低条件接纳的生活行动与撮合载体；角色功能、责任对后续选择的作用按具体版本锁定。
- 历史复用记录中的用户修改只对该版本生效：96集经用户审稿删去无效养妹血缘揭示，该改动不能倒写成42号原对标本来就没有身世节点。
