# 剧情框架 · 26 隐认守护后相认

> 来源型复用卡。归属为[相认重聚](../爆款结构库.md#plot-family-3)；具体机件与来源事实以对标54主卡为准。

## 一句话机制

低位者认出旧人却因自卑隐瞒，以岗位照料延续旧情；第三人用信物突破否认，身份相认后再由主动离开逼出高位者明确的关系选择。

## 完整骨架

入职接近旧人 → 信物触发共同往事并向观众交底 → 不相认、藏回岗位身份 → 超职责照料建立双向关心 → 旧事漏口遭追问、回避 → 籍贯与等待话题触发主动试探、再次否认 → 第三人意外目击可对照信物 → 同时报公私两消息但先讲公务带货 → 回问私事才把身份交给高位者 → 急召当面对质 → 承认却因身份自卑主动退出 → 高位者以旧约和奋斗目的回应、明确挽留 → 相拥并牵手报喜 → 同价复报收单。

身份揭晓解决“他知不知道”，辞职立刻续挂“她愿不愿留下”；两件事不能合成见面即拥抱。双消息针脚让男方在得知具体身份前讲品，避免把源剧情改成已知相认机会却无端拖延。

## 保留与换新

- 保留观众与女方先知、男方后知；隐瞒出于自卑，非伪装考验。
- 保留当下实际照料、漏口与试探被挡、第三人证据传达、身份确认后仍退出、关系选择回应顾虑。
- 换新人名、职业、旧关系表层、守护动作、试探与目击场景、信物及对白；年限和产品事实按定案核定。
- 与13“旧人重逢再成家”区别：无装穷试探、无试探认错；与10“线索认亲”区别：不是双方不知答案的逐项认亲，关键阻碍是知情者主动隐瞒及拒绝留下。
- 双位置带货是源差异，保留在资产中；不据此自动修改现行单段规则。
