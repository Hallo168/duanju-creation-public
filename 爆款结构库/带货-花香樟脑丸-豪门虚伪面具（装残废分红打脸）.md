# 花香樟脑丸 · 豪门虚伪面具（装残废分红打脸）

> 分类：带货剧本（爆款结构库卡片，索引见 ../爆款结构库.md）

- **核心机制**：憋屈值拉满（装残废受辱+极端偏心分配）+ 翻旧账式反击 + 双重反转（手没废+巨款到账）+ 断亲宣言
- **开场双钩归属**（2026-08-08 回填）：弱钩开场（首场为"夫妻密谋装残废"的动机交代）——真钩在第2场；画面＝分红会上装残废妻子被偏心分配当众羞辱，绷带后段揭晓为假（画面钩·异常特写，绷带兼回收信物）；台词＝奶奶当众宣判"两千三百万vs两万"式偏心数字对比（台词钩·数字翻账，推断，无原句可核实）
- **人物配置**：隐藏实力者/最终打脸执行者（丈夫）、正义代言人/中段反击者/带货主讲（妻子）、偏心反派/权力符号（奶奶）、受宠反派/嘲讽输出（弟弟）、帮凶反派/火上浇油（弟媳）、揭晓工具人/带货引入器（助理）
- **结构链**：夫妻密谋交代装残废前提 → 分红会上奶奶偏心分配（两千三百万vs两万）→ 弟弟+弟媳+奶奶三层递进羞辱 → 妻子爆发翻旧账（救命恩、抽血养弟弟）但被奶奶打断逐客（憋屈未解）→ 助理进场报喜（三千万欧元）+ 带产品 → 独白式带货 → 撕绷带双重反转 → 奶奶180度变脸暴露虚伪 → U盘铁证断后路 → 断亲宣言 → 站队提问
- **产品切入**：混合（身份任务+生活痛点），轻伏笔在助理带除湿香包，正式带货为独白式（妻子面对镜头），丈夫补一句背书
- **可复用点**：翻旧账式中段反击（不翻盘但把恩情债算清）；掌权者180度变脸（"激将法"式自圆其说暴露虚伪）；实物证据（U盘）封堵退路；三层递进羞辱（掌权者分配不公+受宠者嘲讽+帮凶加码）
- ⚠️ 与"装哑分红打脸"篇高度同构；独白式带货缺捧哏；"雾化公司"与"日化公司"前后矛盾为原片笔误
