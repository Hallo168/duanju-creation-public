# 樟脑丸 · 装哑分红打脸

> 分类：带货剧本（爆款结构库卡片，索引见 ../爆款结构库.md）

- **核心机制**：憋屈值拉满 + 双重反转（哑巴开口 + 巨款到账）
- **结构链**：夫妻密谋装哑装穷 → 分红会上被母亲/弟弟/弟媳三方羞辱（五千万 vs 一万块）→ 丈夫当场翻旧账（嗓子怎么毁的、每月六十五万）→ 助理进场报喜（八千万美金到账）+ 带产品请定价（身份任务切入）→ 长独白式带货（助理捧哏"赔本定价"）→ 返回剧情：断绝关系、弟弟跪地 → 对镜头提问"这种妈还有必要给她养老吗"
- **产品切入**：身份任务（助理请林总定上市价格）
- **可复用点**：翻旧账式反击（把恩情账目一笔笔报出来）；"当着所有人面定个颠覆认知的价"把打脸和带货合成一个动作
