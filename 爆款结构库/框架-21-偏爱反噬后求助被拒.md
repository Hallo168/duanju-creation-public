# 剧情框架 · 21 偏爱反噬后求助被拒

> 来源型复用卡。分类、归类边界与使用方式见[总索引](../爆款结构库.md#plot-library)；数据与复用记录沿用原卡入口。

## 一句话机制

施害者把资源与期待押给偏爱的一方，却被这份偏爱反伤；回头向旧受害者求助时，自己以前的话和行为变成拒绝依据。

## 完整骨架

偏心掠夺与羞辱 → 施害者亲口否认责任、选择投奔偏爱对象 → 偏爱对象驱逐的插叙预支报应 → 跳时间后旧受害者处境改变 → 施害者回头发现可获新利益 → 原版带货暂停在求收留期待上 → 施害者再次索取 → 清算者逐条回敬原话原事 → 裁决权交还当年被排除的人 → 拒绝结果与观众评判收束。

过去的选择造成眼前无处可去，过去的话又解释为何不能理所当然回来；两次因果回收共同完成反噬，不依赖临时补罪证。

## 保留与换新

- 保留：反派曾主动偏爱和排除、报应由被偏爱者造成、时间差、回头发现利益后的再次索取、原话原事回收与裁决权移交。
- 原版无人设局；受害者后来成老板是时间推移结果，不能改成一直装穷等待揭晓。
- 被偏爱的小女儿是缺席报应执行者，不必扩成新场景主角；具体呈现按原稿插叙与控诉保留。
- 换新：先前争夺的资源、偏爱对象的具体行为、离开时的话、回头求助事项与新生活场面。末段反击必须能回指前段确实说过或做过的事。
