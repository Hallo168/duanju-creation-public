# 剧情框架 · 03 逼测赌约反噬

> 来源型复用卡。分类、归类边界与使用方式见[总索引](../爆款结构库.md#plot-library)；数据与复用记录沿用原卡入口。

## 一句话机制

反派亲自设计考题并说出赌约，执行者被迫照办；被测者用行动回应，最后反派被自己认可的条款约束。

## 完整骨架

利益争夺逼宫 → 正方报出既有恩情事实 → 反派不服并提出考题 → 反派亲口约定结果与代价 → 执行者被迫传达困境 → 被测者筹措资源作答 → 本人携成果到场 → 生活关怀与带货承接 → 身世或恩情自白 → 执行者回收赌约清算 → 明确资源归属并求观众评判。

考题和赌约必须先于结果成立，否则最后处置失去来自反派自己的约束。来源存在“核心概括称超额、逐场写七万二并请求宽限”的记载差异：复用40号时按原稿具体表态与裁决保留，不擅自补成八万到账。

## 保留与换新

- 保留：谁提考题、谁被迫执行、反派亲口承诺的后果、被测者不知测试而作出有代价的行动，以及末段逐项回收。
- 本版本的试探道德成本来自反派设题；不得改成正方无故考验之后再套普通测试局的道歉补丁。
- 揭晓靠被测者本人携成果到场，不依赖额外豪车或秘书宣布其真心。
- 换新：争夺的具体资源、紧急求助的事件、筹措办法、恩情前史的生活细节与台词；期限、金额关系及裁决根据按具体对标功能锁定。
