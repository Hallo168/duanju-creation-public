# 花香樟脑丸 · 家中的旧照（凤凰男隐藏家人）

> 分类：带货剧本（爆款结构库卡片，索引见 ../爆款结构库.md）

- **核心机制**：旧照意外暴露 + 凤凰男隐藏家人 + 妻子反向站位替婆婆打脸丈夫
- **开场双钩归属**（2026-08-08 回填）：非弱钩，结构链第一环本身即具体开场画面；第一画面＝孩子发现的旧照片占满镜头（画面钩·异常特写，兼任全知底牌，全知型信息差标配开局）；第一句＝孩子发现照片后的追问/惊呼触发身世悬念（台词钩·孩子炸雷，概括，原稿未查得无法逐字引用）
- **人物配置**：正面主角/正义执行者（妻子）、反派（虚荣丈夫）、受害者/同情锚点（婆婆）、受害者补充（残疾大哥）、触发器/道德镜子（儿子）、捧哏/执行工具人（店长）
- **结构链**：孩子发现照片触发悬念 → 追问婆婆得知丈夫隐瞒出身 → 实地确认铁皮房（潮湿霉味+残疾大哥，憋屈拉满）→ 电话召丈夫 → 丈夫自爆"不是让你们藏好吗" → 耳光+痛骂打脸 → 叫店长送钱+樟脑丸（产品切入）→ 第一次带货（独白式+店长捧哏一句）→ 二十万交婆婆+接回家+罚丈夫住地下室 → 一个月后婆婆新生活 → 第二次带货（生活见证式）→ 镜头独白收价值观
- **产品切入**：生活痛点（铁皮房返潮→衣服霉味→大哥腿疼），产品作为"解救家人"的善良行动工具出现
- **可复用点**："偶然发现线索→追查→实地确认→召当事人对峙"的四步揭露链；反派"自爆"加速打脸（到场先骂家人暴露真实态度）；孩子做触发器+道德镜子（"零花钱给奶奶"）；双带货位（剧中一次+生活验证一次）；"替弱者做主+惩罚反派"的权力结构
- ⚠️ 开场是雨戏——现行规则已禁雨戏，此骨架复用时开场环境必须换；结尾偏标语（"婚姻不是靠掩盖出身来维持体面"），需口语化
