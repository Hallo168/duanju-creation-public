# 女婿的拒绝（善意误判型）

> 分类：流量剧本（爆款结构库卡片，索引见 ../爆款结构库.md）

- **核心机制**：善意被误判为冷漠——一方用否定回答制造误会，真实意图是比对方期望更好的方案
- **人物配置**：制造误会者（先否定后揭晓真意+金句输出）、替观众发问的承压者（误解→委屈→感动）
- **结构链**：提出请求 → 对方连续否定（误会建立）→ 排比式对比独白拉高情绪（维持误会）→ 反转重新定义否定词（"不同意"的对象不是事本身而是条件）→ 破壁对镜头喊话
- **可复用点**：极简二人对话制，全剧仅两人；"重新定义否定词"的反转手法（否定的不是你想的那个词）；排比对比拉情绪
- **情绪路径**：不满→委屈愤怒→心酸共鸣→恍然大悟暖感（峰值在反转揭晓）
- **注意**：原篇反转仅靠口头解释无实物证据，冲击力偏弱；中段独白过长近150字需拆成对白回合；第四句金句偏平铺
