# 剧情框架 · 02 单方验心

> 来源型复用卡。分类、归类边界与使用方式见[总索引](../爆款结构库.md#plot-library)；数据与复用记录沿用原卡入口。

## 一句话机制

以一个主要对象或同一家庭的选择作为结论，变化来自处境、压力维度或态度暴露，不以多个候选人的横向淘汰来成立。

## 完整骨架

立低条件处境与试探背景 → 单一对象面对困境作答 → 通过实际援助或逐层拒绝显出态度 → 揭晓处境或身份 → 回答试探缘由并按结果决定关系 → 用承诺、奖赏或分离落地。

同一家庭连续三关仍属单方验心：三次改变的是尊严、资源和生活保障，不是换三个候选人。单测通过与单测失败各自是一套版本，不能为了凑对照组给失败版本加真心人。

## 保留与换新

- 保留：被验证的一方、试探处境与其行动的因果、身份揭晓相对表态的先后，以及试探后的关系处理。
- 单测失败：《黑袋子里的试金石》只有拜金女友，没有善者对照；黑袋子的现金真相在后段回收。
- 单测通过：《工服相亲》的被测者先通过，后来路过的老同学夫妇是局外反派；不能把通过的人改成反派。
- 同家三关：《装穷认亲三关试孝局》认亲在前，同一家先后接受尊严、财力、居住降级的考验；取家底的短暂离场不得改成真实拒绝，揭晓后解释与重奖仍有待兑现。
- 换新：低条件的具体外观、求助事项、受测方可付出的资源与生活动作；财富真假、既有亲缘和被测者结局依选中的版本保留。

## 已有变体

| 版本 | 已有结构差异 |
|---|---|
| 集市阿婆试人心 | 隐藏权威处于弱者位置，善者在现场受压中出手；工作人员与监控揭晓，奖摊位后提出利他条件。不是逐户筛三人的版本。 |
| 工服相亲 | 单测通过且看破不说破；局外熟人羞辱并自曝有求于主角，秘书揭晓后合作资格受影响，感情线收尾。 |
| 黑袋子里的试金石 | 祖孙合谋；唯一被测者拒绝到底，无真心人；到账电话先翻转局面，现金真相随后回收，分手清算。 |
| 装穷认亲三关试孝局 | 先认亲再自施压三关；同一家倾囊反哺并接受生活降级；身份揭晓后带货，继而解释试探、重奖、团圆；不另增开场阻力的惩罚段。 |
