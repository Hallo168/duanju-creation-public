# 薄荷清凉油 · 车祸谋杀装死钓鱼局（豪门逼宫双反派型）

> 来源＝`对标原稿/27-假瘫后我看清了谁是真爱.md`（2026-08-07 导入，素材未附点赞/完播数据，按经验对标收录）。

- **观众抓手**：愿望型——总裁豪门场面（董事会/股权/千万级资产）拉满奇观感，观众看恩人总裁如何布局清算野心未婚妻与前女友，代入"看别人替自己活一遍"的复仇/救赎，不要求观众自身受辱代入。
- **核心机制**：车祸谋杀悬疑（撬石暗算）+ 祖孙合谋装死钓鱼引蛇出洞 + 双反派（未婚妻逼宫夺权／前女友转移财产）多轮试炼 + 恩人级真心测试 + 证据回放双杀打脸 + 表白团圆
- **信息差方向**：观众全知型——装死钓鱼计划第一场就向观众交底（沈老对沈屿安当面说明"放消息装瘫、看谁先露尾巴"），何曼/林清婉两个反派浑然不知，观众全程期待"看她们什么时候撞上、怎么被拆穿"
- **人物功能配置**：受害者兼设局者（沈屿安，装死躺平）、掌局长辈（沈老，权威裁决者兼带货主讲）、真心人／破局者（赵小棠，仓库女工，用行动通过测试）、反派一号（林清婉，逼宫夺权型未婚妻）、反派二号（何曼，卷款潜逃型前女友）、取证工具人（陈秘书，收尾一次性交出全部罪证）
- **场次节奏表**：
  1. 车祸悬疑铺底＋锁定三名嫌疑人＋祖孙定计装死（钩子+计谋）
  2. 反派二何曼率先露馅，偷拍资产、暗谋转移房产（第一层露尾）
  3. 反派一林清婉带人逼宫，抢股权托管书、羞辱高龄长辈（压迫顶点）
  4. 真心人赵小棠破门救场，撕毁协议＋掏出全部积蓄（真情反转/产品轻伏笔）
  5. 带货铺垫：赵小棠向沈老讲解产品，沈老拍板做贴钱活动（正式带货，身份揭晓之前）
  6. 沈屿安起身揭穿装死、陈秘书一次性交出两名反派全部罪证、带货加码收官、表白团圆
- **情绪路径**：悬疑警觉（第1场）→ 现实寒心（第2场）→ 极度嚣张压迫（第3场，峰值）→ 真情反转大快人心（第4场）→ 信任建立顺畅带货（第5场）→ 真相大白+双杀打脸+催泪表白（第6场，第二峰值）
- **关键反转**：①沈屿安"昏迷"实为装死钓鱼，靠他自己当众坐起身直接揭晓（人物登场式）；②两名反派罪证（何曼转移房产录音、林清婉后备箱撬棍监控）由陈秘书一次性集中呈交，双杀式回收，不分开打脸
- **产品切入**：
  - 切入方式：生活痛点（仓库高温环境日用）+ 恩人救场应急道具，产品本身不是反转钥匙——去掉产品，装死揭穿与双反派清算依旧成立，产品咬合档位中等（长在真心人日常里，但非"拿掉即反转不成立"级）
  - 轻伏笔位置：第4场，赵小棠用清凉油给沈老涂太阳穴应急提神，兼作救场道具首次登场
  - 正式带货位置：第5场，身份揭晓（第6场）之前，对话式（沈老提问＋赵小棠讲解，沈老捧哏"这个花多少钱"），带货穿插在压迫解除之后、揭晓之前
  - 主讲人选与口吻：沈老（渠道权威／决策者）主问促单，赵小棠（日常使用者／见证者）负责用法与体感描述
