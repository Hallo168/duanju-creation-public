- **核心机制**：测试者**主动自毁筹码**（当众砸掉象征财富之物＋给被测者做上可视化的残缺伪装）→ 带着被测者**逐户上门乞助**，同一套惨状、同一句求助台词连测三人 → 两恶一善极端对照 → 被测者**亲手撕掉伪装**自揭底牌 → 把反派押回**正面角色的场地**当众清算。看点是"一句求助台词，三张嘴脸"
- **信息差方向**：**观众全知型**——第1场就把局全亮（砸物＋贴假伤疤＋交代规则），观众明知是假，全程只等两件事兑现：反派什么时候撞上、好人什么时候得报；底牌对**剧中人**保留到第6场撕伪装。与库内多数"观众同惊型"测试卡相反，借骨架时要意识到压迫感来源不同：全知型的憋屈靠"看好人白白挨骂"，不靠悬念
- **开场双钩归属**（2026-08-08 回填，核对 对标原稿/07-落魄千金试婚局.md 第1场原文）：第一画面＝林宛如手持棒球棍当众砸碎名牌珠宝名表（画面钩·暴力/动作异常，与本库该模式锚例"老太持铁棍砸碎名表展柜"同源）；第一句＝"这些东西，从今天起跟林家没关系了，跟你没关系了！"，紧接"你给我换上这身破烂……装作被大火毁容，上街讨生活！"当场向女儿交底测试规则（台词钩·组局宣言，全知型标配，与卡内【信息差方向】"第1场就把局全亮"互证）
- **人物功能配置**：设局者/权力释放者/带货主讲（长辈，一人四职是全剧动力源）、诱饵兼承受者兼揭晓执行人（晚辈，亲手撕伪装＝反转动作）、反派一（体面型自私：怕丢脸、轰人）、反派二（羞辱型自私：动手扯伪装＋甩钱，角度不重复）、正面主角兼产品天然载体（职业＝产品使用场景）、执行工具人（把惩罚可视化的押送者）、第三方背书捧哏（回头客一句证言）
- **结构链**：自毁筹码开场钩（砸物＋交代测试规则）→ 上门一：从"体面"角度拒绝羞辱 → 上门二：从"人格"角度加码＋**物理羞辱**（动手扯掉伪装、甩钱驱逐，压迫峰值）→ 上门三：对照组**即时行动**兑现善意（不说漂亮话，直接关门做饭）→ 后厨餐桌**对话式带货**（长辈挑剔提问、主角答用法）＋食客回头客补背书 → 掏全部家底＋密码是她生日 → **撕伪装自揭** → 反派被押回场跪地 → 撤资封杀＋赠旗舰店（爽点全释放）→ 三人面向镜头金句收束 → 无缝切促销口播
- **情绪路径**：震惊→心疼→愤怒→**愤怒峰值·第3场物理羞辱**→松口气/暖→感动→**爽感峰值·第6场撕伪装＋清算**→信任→促单。双峰结构，中间第4-5场是暖场缓冲兼带货窗口
- **关键反转**：靠**当事人自己动手**（伸手撕掉伪装）做实物动作揭晓，比工具人报身份更有冲击力；第二段揭晓由押送者到场＋长辈报出集团身份完成——"打脸的资源一直在她手里"
- **产品切入**：生活痛点＋**人物职业双绑定**（主角本职就是做饭，产品出场零违和，是本卡最值钱的设计）；轻伏笔＝第4场只说菜不说酱（"给您做红烧肉，焖得烂烂的"）；正式带货在第5场、**位于揭晓与打脸之前**（库内第二例，靠"做饭"这个善良行动自然滑入，不靠身份权威）；对话式，日常使用者主讲用法、测试者以挑剔提问捧哏；话术链＝痛点（怕油腻/怕炒糖色麻烦）→旧方案对比（不炒糖色不放冰糖、不用看火候）→使用场景（焯水＋一包酱＋按电饭煲）→效果验证（长辈吃后评价）→价格锚定（"这酱不便宜吧"—"几块钱"）→第三方回头客背书→促销（九块九七包/包邮/卖完不补货）；返回主线＝吃完饭直接接"掏银行卡"
- **金句句式骨架**（原句措辞禁入二创稿）：顺境逆境对照＋具体动作意象（"站高处时身边全是笑脸，摔进泥里还有人为你点灶火"式）；递进否定式定性（"不是根子烂了，是心烂了"式）；否定施舍＋指认具体劳动物件（"这不是施舍，是你手里那把勺该得的"式）
- **刺痛词位**：反派一外貌羞辱＋物化（"让我接盘一个毁容的丑八怪"式）、把人当污染物（"别脏了我的红毯"式）；反派二**当众扯掉伪装＋夸张倒吸凉气**（本篇最狠一刀，物理羞辱强于任何台词）、连长辈打包羞辱（"一个丑八怪一个老太婆"式）、人格定性（"你就是个瘟神"式）、甩钞驱逐（"拿着钱打车滚回贫民窟"式）；反转后丑态推卸（"我那是被董事会逼的"式）
- **可复用点**：自毁筹码开场（当众砸掉象征财富之物作视觉钩子）；**双重伪装**（穷＋残缺）比单一装穷更狠且伪装可视化；**逐户上门**连测三人、同一句求助台词三种回应；两反派分角度补刀（怕丢脸型＋直接羞辱型）；对照组用即时行动而非漂亮话证明；掏全部家底＋具体数字＋"密码是她生日"的细节杀；被测者亲手撕伪装做揭晓动作；押反派回**正面角色的场地**执行惩罚（羞辱发生地反转）；产品与职业天然绑定、带货前置于打脸；第三方回头客一句背书
- **注意**：①第3场夜雨、第4场雨后积水双踩雨戏禁区，两处环境全换；②阿拉伯数字遍布须全转中文；③原稿含真实品牌名须删；④第5场长辈品评菜品一口气约八十字连续独白，严重破单句≤15字/单人连续≤3句红线，必须拆成一问一答；⑤绝对化用语（"保证不齁不腻""没几个大厨能烧出这个水准"）须改主观体验表述；⑥"血糖高不敢碰"把食品往健康功效上引，平台风险，改"怕油腻/怕烧心"类口感表述；⑦暴力元素（棒球棍砸物、"鼻青脸肿""像死狗一样扔进来"）生成端与平台双重风险，建议降级为非暴力控场；⑧第6场六人以上同屏破"同屏≤3人"，分镜层须拆镜头；⑨**结尾无互动钩子、纯促单**，二创须补一句破壁提问再切口播；⑩伪装的合理性缺口——上门三家都没人识破假伤疤，二创可加一句"绷带没敢揭"类台词兜住；⑪原稿多处错别字与断句错误（口播转录稿痕迹），不影响结构判断；⑫无来源方数据，骨架有效性未经我方验证
