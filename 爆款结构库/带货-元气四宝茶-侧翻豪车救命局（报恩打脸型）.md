# 元气四宝茶 · 侧翻豪车救命局（报恩打脸型）

> 分类：带货剧本（爆款结构库卡片，索引见 ../爆款结构库.md）

- **核心机制**：路见义举救车祸富豪 + 恩人本人反被职权者迫害（因救人被砸摊查封）+ 被救者身份揭晓亲临撑腰当众打脸反派 + 双重报恩（现金+长期营生）+ 对症带货。观众全知型——开场即点破被救者是大老板，反派迫害的是**英雄本人**而非其亲属，区别于库内其他救人型卡片
- **人物配置**：正面主角/英雄执行者/受迫害者/带货主讲（摊贩父亲）、受助者→知恩图报者/正义裁决者/带货捧哏（被救大老板）、反派/职权滥用者/打脸承受体（管理经理）、催泪辅助/道德加分项（懂事儿子）、催泪发动机/经济压力源（重病妻子）、群众证人（工友）、信息传递工具人（助理）
- **结构链**：危险救援钩子（路人劝阻式反讽）→ 赤脚砸窗救人（牺牲精神展示）→ 拒收报酬+透露经济困境（骨气立住，悬念埋下）→ 家中催泪（攒钱铁盒）+ 反派微信封杀摊位同期来袭（压迫叠加）→ 反派办公室羞辱刻毒台词多轮递进（冲突升级）→ 双线并进：恩人得知真相愤怒 + 市场现场反派变本加厉踢翻铁盒（蓄势顶点）→ 恩人亲临身份揭晓+工友联名作证+当场停职查办（反转爽点）→ 报恩双件套（现金+长期营生）→ 身份任务式话题过渡带货 → 站队提问式互动钩子
- **产品切入**：生活痛点（老人腿软手脚凉精气神差），混合身份任务余韵（报恩后借"孝道话题"自然过渡）；话术链＝痛点场景化→来源背书（老工友配方经验）→成分报菜名→使用场景→边界声明→价格锚定+活动价+数量强化→渠道指引→退换承诺→情感号召；⚠️对标原文产品**无轻伏笔**，直到收尾场才首次出现，未按通用公式提前埋设
- **可复用点**："救人不图报→事后遭报复→被救者回归撑腰"三段式主线；经济压迫叠加法（手术费缺口+攒钱铁盒+反派封杀同期爆发）；被救者亲临+工友联名作证的反转打脸方式（不靠证据回放、不靠工具人代揭）；报恩双件套（现金+长期营生保障）；身份任务式带货桥接；站队提问式结尾钩子
- ⚠️ 产品轻伏笔缺位（二创建议补，非原文自带）；开场为雨戏车祸，二创须去雨；含真实品牌名（劳斯莱斯/迈巴赫）；含未成年角色（职校学生儿子），二创按去龄化规则处理叙述层
