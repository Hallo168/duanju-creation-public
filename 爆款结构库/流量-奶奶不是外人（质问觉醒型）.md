# 奶奶不是外人（质问觉醒型）

> 分类：流量剧本（爆款结构库卡片，索引见 ../爆款结构库.md）

- **核心机制**：孩子当道德镜子质问父母 + 四层递进质问（空间→照护→旧账→因果预言）+ 隐形角色的纸条完成情绪核弹
- **人物配置**：真相翻译者/道德镜子（孙子）、被教育者（爸爸，敷衍→回避→暴怒→崩溃→赎罪）、和事佬→被感化者（妈妈）、隐形角色（奶奶，仅存在于回忆和纸条画外音）
- **结构链**：放学回家发现奶奶被送走（震惊钩子）→ 空间对比质问打脸（物件都有位置奶奶没有）→ 四层递进主战场（习惯细节→护工vs家人→翻恩情旧账→因果预言"你怎样对她就是教我将来怎样对你"）→ 递出纸条 → 纸条画外音揭示奶奶主动背锅保护儿子（情绪核弹）→ 爸爸崩溃+儿子收尾金句 → 全员行动赎罪
- **可复用点**：孩子当道德镜子的整体框架；四层递进质问结构；隐形角色通过纸条/遗物完成情绪核弹；"位置"式物象双关（物理空间=心理位置）；被教育者五段情绪弧；妈妈从帮腔到转向的立场变化
- **情绪路径**：震惊心疼→愤怒共鸣（空间对比）→越来越疼的心酸（逐层揭旧账）→**催泪峰值（纸条内容）**→释然暖感（接回来）
- **注意**：第三场偏长接近独白，二创时需拆成更多对白回合；黑屏字幕"别让等待成为永远的遗憾"偏标语，结尾需口语化；参考文案第41行有代词错误（"他怕打雷"应为"她"）
