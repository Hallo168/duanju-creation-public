# 剧情框架 · 18 技艺应战

> 来源型复用卡。分类、归类边界与使用方式见[总索引](../爆款结构库.md#plot-library)；数据与复用记录沿用原卡入口。

## 一句话机制

被地位或器具鄙视的人接受实操挑战，用看得见的成果推倒对方的判断，随后兑现赌注、道歉与后续结果。

## 完整骨架

客诉暴露作品问题 → 掌权者甩锅并迷信昂贵条件 → 低位者指出问题 → 对方用身份羞辱并立双向赌约 → 改变场地后继续遭器具轻视 → 公开专业身份但仍须动手 → 实操过程逐步推翻“不可能” → 成品出场与多方验货 → 对手亲自验证后认输 → 道歉和约定结果落地 → 后续经营变化再验证。

专业身份不是结论；身份揭晓后仍必须做出东西、让对手确认，才能同时推翻身份、器具和配方价格三条鄙视链。

## 保留与换新

- 保留：真实问题、谁发现问题、双向赌注、器具或条件反差、完整实操与成品验货、认输道歉。
- 原版是本事碾压，不是伪装穷人考验人品；被测的是能力判断，不是对方愿不愿接受穷亲人。
- 换新：被投诉的作品、职业、器具限制、技艺展示与验货标准；普通器具为何能完成任务须在原版本的功能位上解释，不能靠旁白宣告赢了。
