# 樟脑丸 · 修车厂装穷测试

> 分类：带货剧本（爆款结构库卡片，索引见 ../爆款结构库.md）

- **核心机制**：救人恩情 + 装穷三连测（拜金型 / 精算型 / 真心型）
- **结构链**：车祸救人立恩情 → 婆婆约修车厂装穷 → 反派一（嫌脏怕穷暴走）→ 反派二（算赡养成本谈并购式婚姻）→ 真女主送画顺带樟脑丸（解决板房返潮）→ 反派折返冷嘲 → 豪车助理揭晓周董身份 → 打脸 → 女主提利他条件（给修车师傅每人备两袋+改板房通风）→ 镜头带货+提问
- **产品切入**：生活痛点（板房潮、衣服霉味）
- **可复用点**：三人递进测试（一个比一个"高级"的自私）；"你可以提一个条件"→利他条件的收束
- ⚠️ 开场是雨天车祸——现行规则已禁雨戏，此骨架复用时开场事件必须换
- 🔁 **同家族另一卡**：《松茸红烧酱汁 · 落魄千金试婚局》也是三连测，但改"测试者带被测者逐户上门乞助"，且带货位前置于打脸、产品与正面角色职业天然绑定——要"约到一个地方等对方来"取本卡，要"三个场景递进上门"取那张
