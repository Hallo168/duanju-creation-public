# 家门的钥匙（象征物点破催泪型）｜原稿存 对标原稿/02-家门的钥匙.md

> 分类：流量剧本（爆款结构库卡片，索引见 ../爆款结构库.md）

- **核心机制**：老人主动交还象征归属感的物件（钥匙）=自我边缘化信号 → 儿媳类比反问（"儿子出差交钥匙吗"）让老人**亲口说出反驳自己的论据**（"办完事还得回来呀"）→ 借她自己的逻辑重新定义行为（交钥匙=把家当酒店）→ 塞回物件+排比宣言催泪释放。爽点不是打脸，是"替天下老人把没说出口的委屈说破"
- **信息差方向**：认知重定义型全知——老人的卑微观众从第一句全见，反转不揭新信息，只把观众"说不清哪里难受"的感觉一句话定性（与"长辈的尊严"的细节反杀近亲，但那篇靠隐藏细节引爆，这篇靠类比定性引爆）
- **人物配置**：同情锚点/情绪压迫源（母亲，卑微借口三连）、反转推动者/观众嘴替/金句输出机（儿媳，约七成情绪台词）、观众常态代表/无恶意冷漠反衬→醒悟者（儿子，"行，放茶几上吧"比反派更扎心因为观众就是他）、隐形角色（孙子，一句"放学叫一声奶奶"立起不出场）
- **结构链**：深夜交钥匙+儿子头也不抬（台词钩+钥匙落茶几视觉信物，双钩）→ 儿媳截停追问 → 老人卑微借口三连（不能长住/怕弄丢添麻烦/钥匙是摆设）压迫到极致 → 类比反问反转（峰值一：老人自己说出答案→儿媳借力定罪）→ 儿子认错+老人哭诉真实顾虑（怕踩脏地板，催泪峰值二）→ 塞回钥匙+红绳贴身嘱咐+"三个不需要"排比拆除客人待遇+三人相拥+旁白升华
- **情绪路径**：心酸压抑→微怒（儿子刷手机）→心疼加深（借口三连）→恍然鼻酸（类比反转，第3场峰值一）→催泪爆发（老人自白，第4场峰值二）→温暖释然+愧疚联想自家父母。双峰值分居3、4场，结尾回暖
- **金句句式骨架**（原句措辞禁入二创稿）：重定义物件式"不是X不是Y，而是Z"（"不是出入证，不是客房卡"式）；归属重定义（"他在哪您的家就在哪"式）；存在即价值（"什么都不干只要坐在那就踏实"式）；三连排比否定拆客人待遇（"不需要…不需要…更不需要…"式）；旁白"不是X而是Y"（"最怕的不是粗茶淡饭，而是成了外人"式）
- **刺痛词位**：无反派，刺痛引信全在老人自我贬低台词（"也就是个摆设""怕踩脏地板""怪麻烦的"——观众气的是"我爸妈也说过一样的话"）；儿子的无恶意冷漠（"放茶几上吧"）承担微怒引信
- **可复用点**：象征物交还开局（物件可换：门禁卡/存折/饭卡/自己的碗）；类比反问反转法（拿家中另一成员同类行为作镜子，让被劝者亲口反驳自己）；卑微借口三连铺垫；"同情锚点+嘴替儿媳+无恶意冷漠丈夫"三角；塞回物件+贴身收好嘱咐的动作收尾
- **注意**：①第3场儿媳近九十字连续独白超我方独白红线，二创必拆对白回合；②原稿镜头表特写密集+慢动作推镜头，我方默认中景、禁慢动作，分镜层不复刻；③旁白升华偏标语且长，宜改人物说出或大幅压缩；④儿子全剧仅3句，二创需加辩解/醒悟回合；⑤原稿自带【合理补全台词】标注（"那您呢？"为整理者补全）；⑥无破壁提问互动偏弱，二创可补；⑦"来源方经验"：单集独立剧情用共鸣旁白代替追更钩引导评论区分享
