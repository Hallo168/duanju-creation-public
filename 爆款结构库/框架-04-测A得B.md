# 剧情框架 · 04 测A得B

> 来源型复用卡。分类、归类边界与使用方式见[总索引](../爆款结构库.md#plot-library)；数据与复用记录沿用原卡入口。

## 一句话机制

原本隐藏身份与A相亲或验人，选择却转向不在候选池、未知底牌时便已展现品格的B。41靠冒险护人后清算，56靠观念相合后约定本人劳动；不把41的反派与清算当成56的必经节点。

57由救人意外换装后暂不公开身份，并非预设验人；B以保体面助人与经营底线被看见，男方主动提出劳动追求。同归A退出后与池外B结缘，不把分类名反套为人为考题。

## 完整骨架

**41·护人清算版**：亮出测试计划 → 用日常小事先立B的行为基准 → A按外表误认人并入局 → A逐层羞辱、把威胁扩大到B → B冒着代价护人 → 公务闯入揭晓身份 → 主角以行动推翻羞辱判词并承接带货 → A的利益资格被撤销 → 原为A准备的信物转送B → 新关系开启。

41中B的出现和善意须先有出处；B护人时不知道隐藏身份，事后转赠信物才是选择结果的兑现。A被测、B被选的错位不可抹成两个普通候选人先后考试。

**56·观念相合版**：隐身份相亲 → A因婚后安排不合礼貌退出 → B以点餐玩笑接近 → 有代价的照护经历与专业识货促成互相欣赏 → 公务揭身份并拍板降价 → 品质答疑、集中收单 → B因阶层差距退缩 → 隐瞒者认错并接受本人劳动约定 → 从朋友开始。没有冒险护人、A返场或信物转赠；履行劳动尚未拍出，不等于已兑现婚姻或解决医疗危机。

**57·意外换装良心账本版**：救人泼脏西装 → 借B的工服赴约、助理先向观众亮地位线索 → A因风险观不合退出 → B保体面助老人，双方以突发时的选择互认 → 请饭、男方识油、女方讲常用配料与经营底线 → 公务揭身份、拍板降价、品质答疑及集中收单 → B退缩 → 男方主动提收桌洗碗、B设三天试用 → 工服回收为再见理由。无预设测试、A清算或正式求婚；扫地已有动作，长期劳动仍是承诺。

## 保留与换新

- 共同保留：原定对象A与最终相识者B分离，B在不知道身份时已被欣赏，公务揭晓后仍须兑现新关系。不能套到对标42：42是相亲对象本人即旧爱和真心人，主归相认重聚。
- 41保留：B不知底牌仍护人；反派自己说出有求于主角的利益接口；信物最后改道。换新关系场、职业、误认线索、威胁代价、可撤销利益与信物，B承担的风险须从新场景自然长出。
- 56保留：A礼貌退出、B有代价的照护经历与识货能力、揭身份后追责与本人劳动约定；换新职业场景、生活经历、专业凭据和劳动内容。具体负向不变式见56附属拆解，不套用41的羞辱清算。
- 57保留：意外换装而非预设测试、第三人受助让B的善意可见、女方也用男方救人反应识人、经营底线及借物回收；换新事故与道具、助人事件、经营物证及劳动内容，具体限制见57附属拆解。不能移入56的认错台词或混用两版商品原价。
