# 剧情框架 · 08 报恩救困

> 来源型复用卡。分类、归类边界与使用方式见[总索引](../爆款结构库.md#plot-library)；数据与复用记录沿用原卡入口。

## 一句话机制

救助建立的恩情促使有能力的受助者介入恩人的困境，报恩同时完成救场、追责与生活安置。

## 完整骨架

救助事件建立具体恩情 → 恩人拒绝或淡化回报 → 恩人自己遭受迫害、危险升级 → 受助者获知真相并准备处置资源 → 恩人被逼到危急节点 → 受助者带证据或权力介入 → 逐项拆除反派的控制手段 → 兑现现金、营生或关系安置 → 依原卡位置承接带货 → 新生活落地。

受助者为何出手，须由前面的恩情解释；为何能解决问题，须由已经到场的证据或权力解释。两条因果共同使救场成立。

## 保留与换新

- 保留：恩情来源、恩人仍处危境、受助者知情并行动的接点、救场卡点、处置依据和最终安置；不能只留“富豪出现替我打脸”。
- 外部职权迫害和家庭内部虐待是不同版本：前者查办滥权者，后者解除恩人家人的控制与伤害。照选中原稿保留各自证据链。
- 换新：救助事件、恩人营生、迫害具体方式、得知真相的渠道、处置权来源与回报载体。法律或商业处置不混拼成来源未有的一条万能清算链。
