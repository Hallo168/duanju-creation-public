# 驱蚊蜡烛 · 工服相亲

> 分类：带货剧本（爆款结构库卡片，索引见 ../爆款结构库.md）

- **核心机制**：董事长穿工服相亲 + 反派自己撞上来
- **开场双钩归属**（2026-08-08 回填）：弱钩开场（首场为"借工服点题"的动机交代）——真钩在第3场；画面＝董事长着廉价工服与老同学夫妇在相亲局同框、寒酸对体面（画面钩·阶层反差同框）；台词＝老同学炫耀"即将和盛华合作"（卡内未存原句、无对应对标原稿可核实，台词钩模式暂无法判定）
- **结构链**：借工服点题（王姐对话交代动机）→ 相亲对象真诚通过测试（长对白立人设，还观察到"工服不合身"但尊重隐私）→ 老同学夫妇路过羞辱、炫耀"即将和盛华合作" → 秘书登场揭晓她就是盛华董事长 + 带产品请定价 → 带货（独白+秘书捧哏）→ 教育反派（重新评估合作资格）→ 感情线收尾（电动车接下班）→ 镜头总结提问
- **产品切入**：身份任务
- **可复用点**：反派同时是有求于主角的人，打脸自带利益后果；男主"看破不说破"的细节（发现工服不合身）让通过测试显得聪明而非幸运
