# 剧情框架 · 05 伪装诱敌取证

> 来源型复用卡。分类、归类边界与使用方式见[总索引](../爆款结构库.md#plot-library)；数据与复用记录沿用原卡入口。

## 一句话机制

利用反派相信主角失去反抗或感知能力的假象，引出原本不会公开的恶行与罪证，再集中揭穿清算。

## 完整骨架

真实异常或旧疑点触发设局 → 向观众交代伪装计划 → 反派误以为可以肆意夺利 → 不同反派露出不同罪行并留下可回收证据 → 真心方护持形成反差 → 主角恢复正常行动或声音揭底 → 罪证集中回收 → 分别处置反派 → 按原版完成恩情或关系结果。

伪装必须确实改变反派的行为：装失能让其以为听不懂，装死或装瘫让其以为不能掌权。揭晓只能说明“他在装”，具体清算仍须回收前面已经出现或由取证人物交出的证据。

## 保留与换新

- 保留：伪装造成的误判、因此新增的暴露、两种恶行之间的维度差别、取证与揭穿方式。
- 装疯版：当面自曝商业罪证、主角幼儿语到威严声音的反差、真心人误以为来人加害而张臂护人，各有独立功能。
- 装死版：真实暗算在前、祖孙合谋、夺权与夺产两条恶线、秘书最后集中呈证双杀；真心人先撕协议护人，主角再起身揭晓。
- 换新：失能假象的可见载体、谋害或夺利事件、取证实物、各反派利益及护人动作。只换成普通穷人而不能诱出罪证，会改变本子框架。
