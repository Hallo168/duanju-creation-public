# 薄荷滚珠油 · 颠勺定儿媳

> 分类：带货剧本（爆款结构库卡片，索引见 ../爆款结构库.md）

- **核心机制**：隐藏身份 + 三连测试（嫌脏型 / 精算型 / 真心型）+ 豪车揭晓打脸
- **人物配置**：测试设计者（董事长→大排档老板娘）、配合者（儿子）、观察者/捧哏（特助→传菜员）、反派一（嫌脏嫌穷型）、反派二（精算查账型）、正面主角/被测者（真心善良型）、旁人背书（回头客大叔/维修工）、揭晓工具人（女助理+保镖车队）
- **结构链**：灶台前交代装穷计划 → 反派一嫌脏辱母踹凳离场 → 过渡缓冲 → 反派二精算盘账骂凤凰男离场 → 真女主问吃没吃饭+发现蚊子包→掏薄荷油涂太阳穴（产品伏笔=善良动作）→ 对话式多人接力带货 → 真女主掏六万积蓄银行卡（情感加码）→ 豪车车队+助理揭晓身份+换高级外套 → 被测者生气质问"感情是拿来过的不是拿来出考题的" → 和解+一千万投资+叫妈 → 破壁求评价+二次促单
- **产品切入**：生活痛点（蚊虫叮+油烟熏头昏），轻伏笔在善良行动中（给大妈涂太阳穴），正式带货为对话式多人接力（大叔回头客背书+维修工价格惊叹+特助体验背书+大妈用量场景），产品在收束段二次出场（塞回怀里）
- **可复用点**：三连测递进（感性嫌弃→理性算账→真心关怀）；产品伏笔嵌入善良动作；被测者生气再和解（不工具化）；对话式多人接力带货；利他条件收束（掏积蓄）+产品二次出场；破壁求评价式结尾+二次促单
