# 鲍汁红烧酱料 · 保姆自证真香局（好事被当坏事指控型）｜原稿存 对标原稿/05-金牌保姆的真香反击.md

> 分类：带货剧本（爆款结构库卡片，索引见 ../爆款结构库.md）

- **核心机制**："好事被当坏事指控 → 自证赌局 → 现场实操自证 → 真香转化"。核心创意是把产品夸奖伪装成罪名——"做得太好吃，好吃到被认定是外卖"，指控本身＝产品力的戏剧化表达；自证过程（当场再做一遍）与带货演示完全同体，剧情没有一秒离开产品——库内唯一"剧情即带货"的卡（其余卡带货都是剧情后切入）
- **信息差方向**：观众全知·期待兑现型变体——第1场只亮"无预警辞退"悬念钩，第2场亮罪名与真相（观众站定主角清白），底牌以"自证赌局"（做不出来打包走人）在第2场末亮出，后半程拉力＝看她做出来打脸质疑＋看盯梢者几时真香
- **人物功能配置**：质疑者/审讯官/压迫输出机（老板：先施恩情清单再落指控，压迫功能完成即退场不进厨房）、被冤者/自证者/带货主讲（保姆：日常使用者亲历背书，教程口吻）、**三段式转化样板**（老板娘：盯梢监工→捧哏替观众发问→第一个下单顾客当场跑去买，示范购买行为）、隐形长辈（老爷子：不出场靠电话转述立起，一人兼产品第一好评来源＋冲突触发器——电话轰炸要求给保姆加薪引爆疑云）
- **结构链**：塞钱辞退不给理由（悬念钩）→ 恩情清单铺垫抬高道德压迫 → 指控揭晓（外卖疑云）→ 申辩无效 → 主角主动提自证＋对方加赌注（做不出就走人）→ 教程式带货主体（干货步骤建立专业信任，中段两个"颠覆认知"小反转顶节奏：电饭锅做菜/不放酱油，产品在干货中段自然亮相）→ 开盖香气→试吃真香 → 完整话术链（万能场景/配料表干净/价格锚定→活动价折算/试吃可退）→ 监工跑去下单 → 主讲破壁口播促单
- **产品切入**：混合特殊型——冲突核心本身＝产品效果（好吃到像外卖）；轻伏笔在第2场口述（"给他做了道菜他可喜欢了"，产品未露面效果先行）；正式带货为对话式，捧哏问出全部卖点（要焯水啊/电饭锅?!/酱油都不放?!/贵不贵）；无传统打脸位——自证即打脸，带货贯穿自证全程；无返回主线（监工跑去下单即收）
- **情绪路径**：错愕悬念→憋屈愤怒（**情绪峰值＝第2场指控顶点"你要勇敢承认"**）→紧张期待（赌局成立）→专业叹服（干货）→真香满足（试吃）→占便宜冲动（**转化峰值＝活动价揭晓**）。双峰分居2、4场，中间靠教程干货＋小反转托底
- **刺痛词位**：全在老板嘴里集中第2场——无预警辞退令（"你下户吧"）、"我看是外卖吧""你就是点外卖忽悠老爷子""你要勇敢承认"；恩情绑架清单（进口零食/头等舱/十五薪"我们问心无愧你怎么就变了"）用"施恩"做审判筹码，观众气到复述的是这套道德账
- **可复用点**："好事被当坏事指控"机制（太好吃→疑外卖；可换：太干净→疑没干活、太快→疑偷工减料）；自证赌局（自证失败代价钉死）；教程式带货（干货建立信任、产品干货中段亮相）；监工→捧哏→第一个顾客三段转化弧；隐形长辈＝好评来源＋冲突触发器；恩情清单反衬指控的道德压迫法；颠覆认知小反转顶中段；价格三连（原价→活动价→折单价换算）＋试吃可退
