# 家务的背后（体验教育型）

> 分类：流量剧本（爆款结构库卡片，索引见 ../爆款结构库.md）

- **核心机制**：日常劳动隐形化 + 被迫离场一天 + 连环家务事故逐步打脸 + 三方认知归位
- **人物配置**：承压者/验收方（妻子）、被教育者（丈夫）、帮腔者→共同被教育者→金句输出者（婆婆）
- **结构链**：妻子提家务被丈夫+婆婆双重否定 → 妻子宣布离场（手腕复查）→ 停水暴露信息盲区（平时谁看群通知）→ 垃圾漏水体验不便 → 灶台+泡衣服累积瓦解"不难"认知 → 妻子回来，婆婆先道歉、丈夫承诺分担、妻子提验收条件
- **可复用点**："劳动隐形化→被迫离场→体验打脸→认知归位"四段式；婆婆立场转弯（从帮腔到金句输出）；验收方不轻易接受（"你能坚持吗？"）
- **情绪路径**：共鸣不满→期待看好戏→解气好笑→触动→温暖释然，峰值在婆婆道歉和丈夫表态
- **注意**：原篇缺少前三秒强钩子（温吞入戏），中段缺单一强爆点靠累积推节奏偏平，金句集中在末场需分散排布
- **已二创**：《当着孩子的面》26集（2026-07-28，带货·桑叶苦瓜芹菜面）——借四段式主干（劳动隐形化→被迫离场→连环事故→认知归位），改了三个结构件：①开场换成"婆婆当着孙子的面抽儿子一巴掌"补本卡缺的强钩子；②离场动机换手，由丈夫盛怒中亲口撵人（不是妻子自己提）；③婆婆立场不转弯，从头就是打脸执行者，新增"外人上门撞见塌房＋当面清算"的当众打脸位。带货技法另借《松茸红烧酱汁·落魄千金试婚局》与《绿豆沙·保洁母亲试儿媳》
