**【剧名】** 《绝杀十八分钟：她的顶层猎场》
**【题材】** 悬疑／爽剧／都市职场／风控逆袭
**【人物】** 程雨薇、卫决、关澈、神秘来电者（纯声音）
**【场景】** 薇选大厦顶层露台、贵宾卫生间、董事长会客厅、数据安全中控室

---

### 第1场：薇选大厦52层露台庆功酒会（夜）

**画面：** 摩天大厦顶层露台，夜色下灯河璀璨，香槟塔折射着城市霓虹。程雨薇一袭剪裁凌厉的墨绿西装裙，妆容精致，眼神却冷得像刀。一名穿深色修身西装、气质撩人的男子端着酒杯，笑意暧昧地朝她的方向靠近。
**人物动作：** 男子（关澈）"不慎"被身后人群挤了一下，整个人踉跄扑来，手里的香槟"哗"地泼在程雨薇的裙摆和西装上。他慌忙道歉，从西装内袋抽出一方真丝口袋巾，说要帮她按掉溅在衣襟上的酒渍，说话间俯身用口袋巾角上缝着的金属压角贴着她西装内袋轻轻按了一下，压角边缘一点暗光悄然一闪。
**台词：**
关澈：（惊呼、讨好）哎呀，对不起程总！人太多，没扶稳……
程雨薇：（声音发冷，一把甩开他的手，语气强硬）没眼力见儿？往哪儿撞。
关澈：（讨巧凑近，递上口袋巾）都怪我，先拿这个按一按，别渗进衣料里……
程雨薇：（嫌恶后退，整理衣领）不必，离我远点。
**情绪：** 撩拨试探后骤然翻脸的强弱反差。
**镜头：** 大远景铺开露台夜宴 → 中景记录两人贴近与推拒 → 微距捕捉酒液泼溅与口袋巾金属压角贴上内袋的瞬间 → 特写程雨薇眼底的厌弃。

### 第2场：贵宾卫生间（夜）

**画面：** 大理石台面配无边框镜灯，程雨薇独自站在镜前。
**人物动作：** 她扯了几张纸巾用力擦拭裙摆的酒渍，随手团成一团丢进垃圾桶，对着镜子理了理耳边碎发，嘴角浮起一丝轻蔑的笑。
**台词：**
程雨薇：（自语、讥讽）这种半推半就的老套路，也就哄哄没见过世面的实习生。也不看看这是什么场合，也敢在我面前卖弄。真是不知天高地厚。
**情绪：** 自视甚高，毫不自知的得意。
**镜头：** 画面从她擦拭裙摆的手部缓缓上移至镜中面容 → 最终停在那抹自得的冷笑上。

### 第3场：董事长会客厅（夜）

**画面：** 真皮沙发，整面落地窗外是万家灯火，吧台上摆着开封的香槟。
**人物动作：** 程雨薇陷在沙发里，姿态松弛地给自己倒了杯香槟。搁在茶几上的工作终端骤然震动，屏幕炸开刺目的红色警示与滚动的数据流。
**台词：**
程雨薇：（悠然）今晚这批选品基金的审批明天再说吧，反正额度早锁死了，谁也动不了。
终端系统音：（尖锐警报）警告——警告——生物核验异常，供应链保证金二千四百万，已分批转出。
程雨薇：（脸色骤变，猛地扑过去抓起终端）什么核验异常？二千四百万，转……转哪儿去了？！
程雨薇：（环顾四周，声音发颤）我那张密钥卡明明一直放在西装内袋里，根本没离过身，怎么会……
**情绪：** 由闲适骤然坠入惊惧的心理落差。
**镜头：** 中近景记录斟酒的悠闲 → 屏幕红光警示特写 → 程雨薇面颊骤然绷紧的近景。

### 第4场：董事长会客厅（夜）

**画面：** 同上。终端屏幕切换为"加密专线"来电。
**人物动作：** 程雨薇（颤抖着接通电话，怒意瞬间盖过惊惧，眼底泛红，鬓角青筋隐隐跳动）
**台词：**
神秘来电者（电话音）：程总，二千四百万已经拆分上账。十八分钟内，三百万清算保证金不到账，这笔烂账就得算你自己头上。
程雨薇：（咬牙、面容扭曲）活得不耐烦了？也敢打我的主意？！
神秘来电者（电话音）：要不要我把你的选品基金密钥、核心仓位、私户流水挨个念给你听？不给，也行。十八分钟一过，你名下挂靠的每一个账户都别想跑，统统冻结清算。
程雨薇：（彻底破防，尖声咆哮）清算我？！你们有那个本事吗？！
**人物动作：** 她猛地将手中的香槟杯砸向地面，玻璃碎裂四溅。
**情绪：** 被逼到墙角后的失控爆发。
**镜头：** 双眼血丝的极近特写 → 摔杯瞬间的低速运镜。

### 第5场：数据安全中控室通道／数据安全中控室（夜）

**画面：** 地下通道里灯光森冷，橙色警示灯有规律地明灭闪烁。中控室内布满蓝色数据屏、拓扑图以及各路摄像头传回的画面。
**人物动作：** 程雨薇一边狂奔一边对讲机怒吼，猛地推开厚重的防火门冲进中控室。中控室正中央，一身深色制服、留着利落短发的卫决正冷静地盯着主屏。
**台词：**
程雨薇：（对讲机嘶吼）把露台所有出入口给我封死！那个穿深色西装的男的，三十秒内把脸给我截出来！
对讲机音：程总，那个人已经从消防通道下楼，监控跟丢了……
程雨薇：（一脚踹向墙面，暴怒）跟丢了？！你们是干什么吃的？！
程雨薇：（冲向卫决）出事了！有人盗了我的密钥，我的钱正在被人卷空！
卫决：（面无表情，猛地起身，眼神如刀，气场瞬间压过程雨薇）吵什么！把你那套大小姐脾气收起来！什么时候的事，具体位置，报给我，别在这儿嚎！
**情绪：** 失控躁动骤然撞上强压场域的冷静。
**镜头：** 跟拍程雨薇的狂奔步伐 → 中控室整体空间感呈现 → 卫决起身时的低角度镜头，凸显压迫气场。

### 第6场：数据安全中控室（夜）

**画面：** 主屏快速回放露台监控，画面定格在关澈"扑向"程雨薇的瞬间，并对那方真丝口袋巾角上的金属压角做了逐帧比对与局部放大处理。
**人物动作：** 卫决十指在键盘上飞速敲击，程雨薇死死盯着屏幕，渐渐反应过来。
**台词：**
程雨薇：（指着屏幕，呼吸急促）就是他！递口袋巾帮我按酒渍的时候，那个压角死死贴着我的口袋！
卫决：（冷笑）那哪是什么压角，金属壳里塞的是感应读卡模块，贴靠零点一秒，你那张密钥卡里的东西就被扫了个干净！
卫决：（滑动屏幕，调出后台数据流转记录，画面锁定在后台一名戴着工作证、正在拆卸调音设备的音响技师）他负责贴身下手，那个假冒的临时音响技师负责在后台接手数据、秒进洗钱通道。你以为是搭讪套近乎？你早就是别人计划里的猎物了！
**画面展示：** 大屏上浮现芯片电磁波隔空读取数据的特效动画。
程雨薇：（脸色发白，倒退靠住操作台）一块口袋巾……能隔空偷数据？！
卫决：（步步紧逼）这叫近场感应窃取！你身上一点物理屏蔽都没有，信号全裸露在外面。这二千四百万怎么没的，现在应该想明白了——是你自己的信息把你卖了！
**情绪：** 谜底揭穿后认知被彻底碾碎。
**镜头：** 数据可视化特效的局部特写 → 卫决步步靠近的低位近景 → 程雨薇僵在原地、脸色发白的定格画面。

### 第7场：数据安全中控室（夜）

**画面：** 大屏上，红色的资金曲线断崖下跌。突然整个中控室拉响警报，屏幕弹出"账户遭入侵，风险等级：致命"。
**人物动作：** 程雨薇双手撑在操作台上几近瘫软。卫决眼神一冷，抬手就是一拳，狠狠砸在操作台正中央那颗橙色的熔断按钮上。
**台词：**
程雨薇：（带着哭腔）刚……刚才是不是把清算保证金转过去就没事了？
卫决：（厉声）转过去？你不但保不住本金，还会被平台判定为洗钱链条的一环，公司资质、融资信用一并清零，这辈子都翻不了身！
**人物动作：** 卫决那一拳结结实实砸了下去！大屏骤然转绿，弹出"熔断成功，账户已隔离"。
程雨薇：（大口喘气，冷汗直冒）那现在……我账户里还剩多少，能保住吗？！
卫决：（斜眼看她，伸手弹了一下她的额头）长点心吧。出门不带物理防护，你身上那些卡在骗子眼里跟没穿一样。
**情绪：** 悬于生死线上的窒息压迫，熔断落定瞬间的极致舒压。
**镜头：** 熔断按钮的特写定格 → 卫决出拳的低速运镜 → 屏幕由红转绿的特效切换 → 弹指点额的近景收尾。

### 第8场：数据安全中控室（夜）— 带货转化段落

**画面：** 卫决站在中控台中央，程雨薇乖乖站在一旁，两人神情肃穆直视镜头。
**人物动作：** 卫决在台面上摆开三款（曜黑、香槟金、雾感灰）金属质感卡包，拿起曜黑那款利落展开多卡位内衬，用指关节重重敲了敲外壳。
**台词：**
卫决：都看仔细了，这叫"帧盾防盗刷卡包"，一共三款配色任你挑。内衬是一整层航天级钛合金隔离膜，专治各种隔空扫描！骗子的设备就算贴脸怼上来，也别想从你身上读出一个数字！价钱不到一顿快餐，护住的却是你的全部家底，给我老老实实随身带着！
程雨薇：（立刻接话，举着卡包，神情后怕）今天算我捡回一条命！天天混酒局、见资方的各位老板，千万别当这种事跟自己没关系，如今这帮人玩的花样一茬比一茬新，你压根没反应过来就已经被掏空了！这点钱真别省，赶紧给自己配上"帧盾防盗刷卡包"！
程雨薇：（语气诚恳）那通电话打过来的时候，我整只手都在发抖，杯子都端不住。要不是卫决出手够快，我那二千四百万明天就彻底打了水漂。她把这卡包递到我手上那一刻，我才真正明白什么叫做贴身的护身符！
卫决：（拿过卡包演示开合）内部卡槽是彼此隔开的独立分层，凡是带芯片的证件、银行卡都能一起收进去，核心就靠这层钛合金隔离膜，从物理上封死一切远程读取的可能。外壳是拉丝工艺，耐刮抗压，车轮碾过都不带坏的。配置拉满，价格却压得很低。
**情绪：** 专业权威碾压带来的强安利效应。
**镜头：** 三款卡包一字排开的特写 → 卫决拆解内衬结构的近景 → 程雨薇心有余悸的面部特写。

### 第9场：数据安全中控室（夜）— 结尾收尾

**画面：** 两人并肩而立，背景是转绿的风控雷达图。
**人物动作：** 卫决神情严肃指向镜头，程雨薇在一旁郑重点头，最后两人同时抬手做出"拒绝"的手势，画面停在三款卡包的高清定妆照上。
**台词：**
卫决：别觉得这种倒霉事轮不到你！卡只要还揣在兜里出门，你就是长了两条腿的自动取款机！出差的、坐飞机的、见客户的，谁敢赌这个概率？真栽进去了，哭都没地方哭！送爹妈、送对象、送自己，掏最少的预算，把全家的安全都焊死！
程雨薇：三十九块九，还不够一顿快餐钱，可能替你挡下几万块甚至十几万的窟窿！
卫决：确实这样，防患于未然永远比事后收拾强，别真踩了坑才追悔莫及！就这一款"帧盾防盗刷卡包"，三种配色，超薄便携，全家人都用得上！
程雨薇：点击视频下方链接就能直接下单。
卫决 / 程雨薇：（合）今天不安排，明天被盗了可别来找我们哭！
**情绪：** 威吓式催单后的畅快收官。
**镜头：** 双人并肩的近景镜头 → 同步扬手的动作特写 → 三款卡包的定妆图收尾定格。
