**【剧名】** 《住院日惊魂：手术押金一夜清零》
**【题材】** 都市、正能量、反诈、社会热点
**【人物】** 男主（进城务工青年，工地受伤住院）、周队（医院警务室老警官）、孙芸（假陪诊志愿者）、辅警（小马）、刘护士（住院收费处）
**【场景】** 医院住院收费大厅、警务室办公室、住院部入院登记大厅（回忆）、长途客运站检票口

#### 【完整剧本】

**第1场：医院住院收费大厅（室内、白天）**

* **画面：** 自助缴费机前，男主脸色发白，紧紧攥着银行卡，眼神里全是慌乱。收费窗口里，护士正低头核对电脑。背景是排队等着办住院的家属人潮。
* **人物动作：** 男主左臂吊着石膏绷带，右手焦急地连戳几下屏幕，屏幕纹丝不动。他一把扯出银行卡，踉跄着挤到人工窗口前递过去，指节攥得发白。
* **台词：**
* **男主：** 护士姐，这自助缴费机是不是卡壳了？我押金卡里明明有2万1，咋显示不够？
* **刘护士：** （接过卡，插进人工划价机）你先别急，我拿收费处的机子再刷一遍看看。
* **【音效】：** 收费机连续两声短促的"滴滴"报错音。
* **刘护士：** （神情认真，把屏幕转向男主）小伙子，机子真没卡壳，你自己瞅——余额确实是0。
* **男主：** （后退一步，死死攥住背包带，声音发颤）不能吧！不能吧！这是我爸把家里盖房子的钱全取出来给我的手术押金啊！2万1千6！他去镇上跑了三趟银行才凑齐的，咋能一分不剩？！
* **刘护士：** （皱眉）小伙子你再核实一下，是不是记错卡了？
* **男主：** （猛地掏出背包里的存折，摊在窗台上）就这一张卡！我连第二张都没有！

* **情绪：** 极度慌乱、难以置信、濒临崩溃。
* **镜头：** 收费大厅全景 -> 男主面部惊愕特写 -> 快速推近至屏幕"0.00"数字特写 -> 存折被摊开的手部特写 -> 男主哽咽的中景。

**第2场：收费大厅走廊角落 / 警务室办案区（空间蒙太奇切换）**

* **画面：** 男主蹲在走廊角落，摸出一部屏幕裂了角的手机拨号，随后镜头切入警务室办公室。
* **人物动作：** 男主蹲在地上，额头抵着膝盖，手机贴在耳边，肩膀一抽一抽地哽咽。电话那头传来父亲苍老又急切的声音。
* **台词：**
* **男主：** （哽咽）爸……出事了……押金没了！手术的押金一分都摸不着了……
* **父亲（电话音）：** 儿啊，咋回事？先别哭，慢慢说！卡是不是丢了？你翻出来数过没？
* **男主：** 一直揣在我贴身的内兜里，压根没掏出来过！
* **父亲（电话音）：** 那密码是不是跟谁说漏嘴了？
* **男主：** 绝对没有！钱就跟凭空蒸发了一样！
* **父亲（电话音）：** （声音又急又稳）听我说，兜里别再翻了，别的东西看紧了！马上去住院部找警务室报案！爸这就找老乡搭车，连夜往医院赶！
* **男主：** （哽咽得说不出整句）爸你别来了……路费……
* **父亲（电话音）：** 少废话！你手术的钱爸一分都不会让它打水漂！先报案，爸在路上！
* **男主：** （用力抹了把脸）好，我这就去找驻院的警官！

* **情绪：** 委屈无助、父子连心的焦灼。
* **镜头：** 手机通话界面特写 -> 男主泪流满面的侧脸特写 -> 快速切至男主奔跑的双脚特写。

**第3场：医院警务室（室内、白天）**

* **画面：** 周队身穿警服，面容严肃地站在办公桌前，把一张打印出来的账户记录重重拍在桌上。
* **人物动作：** 周队一手撑着桌沿，上身微微压低，目光死死钉在坐在椅子上、双臂紧箍着背包的男主身上。
* **台词：**
* **周队：** 你先坐下，别慌。刚查了账户记录，这笔钱是十几分钟前被人清空的，转出去的手法很利索，不像是你自己操作的。老实告诉我，卡有没有弄丢过？取款密码告诉谁了？
* **男主：** （拼命摇头）绝对没丢！卡一直揣在贴身内兜里，我压根没掏出来过。
* **周队：** 手机上是不是扫过来路不明的二维码，或者哪个陌生链接手滑点开过？
* **男主：** 真没有！我手机就存了俩号码，一个我爸一个工头，连上网都很少！
* **周队：** （手指敲了敲桌面，眼神一沉）卡一直在你身上，密码也没跟人讲……那大概率是碰上"隔空盗刷"了。你好好想想，从你进医院大门到缴费，谁在你身边待得最久，谁碰过你这个包？

* **情绪：** 悬疑紧绷、抽丝剥茧。
* **镜头：** 账户记录特写 -> 周队锐利的眼神近景 -> 男主攥紧背包带的手部特写 -> 慢镜头推向男主瞳孔（闪回开始）。

**第4场：住院部入院登记大厅（室内、白天、回忆杀）**

* **画面：** 灯光晃眼，人头攒动。男主吃力地拖着一个旧行李包，背着双肩包在挂号人群里晃悠，一脸迷茫。
* **人物动作：** 一个扎马尾、胸前别着"爱心陪诊·孙芸"胸牌的女人热络地迎上来。
* **台词：**
* **孙芸：** 小伙子，看你抱着病历转了半天，是来几楼办住院的？咋一个人呢？
* **男主：** 志愿者姐姐好，我是来骨科办住院的，工地上摔的，家里人还没到。
* **孙芸：** 那可太巧了，我正好是骨科这层的陪诊志愿者，正要去那边交接班，走，我带你去！
* **男主：** 谢谢姐，就是这大厅人也太多了……
* **孙芸：** （突然拉高声音，把男主往前拽）当心！后面推平车过来了！你先往前走，我用消毒仪替你护着后背，别叫人碰到你伤的地方！

* **画面核心呈现：** 孙芸手里那台消毒仪泛着幽微的蓝光，被她整个扣在男主双肩包背面，看似只是随手一挡。虚线特效浮现：仪器内部悄悄射出的信号穿透包身，把里面银行卡的信息隔空复制了一份，卡面在特效渲染下亮起被扫描的纹路。
* **情绪：** 伪装出的善意，暗藏杀机。
* **镜头：** 孙芸热络的笑脸特写 -> 平车穿行的中景 -> 关键特写：消毒仪紧贴双肩包，特效亮起，卡号信息被读取。

**第5场：医院警务室（室内、白天）**

* **画面：** 男主猛地从回忆中惊醒，脸色发白地站起来。
* **人物动作：** 男主死死抱住怀里的包，大声向周队描述细节。周队眼神一变，径直摘下对讲机。
* **台词：**
* **男主：** 入院登记大厅！有个挂着志愿者牌子的女的，说怕我被平车撞着，拿个消毒仪一直死死贴着我的背包！
* **周队：** 啥模样？叫啥名字？
* **男主：** 三十岁上下，马尾辫，牌子上写着孙芸！
* **周队：** （猛地摘下腰间对讲机，摁住通话键）呼叫监控室，调今早登记大厅的录像！锁定一个拿消毒仪的马尾女人！
* **【音效】：** 对讲机里传来一阵电流杂音。
* **辅警小马：** （推门冲进来，举着平板）周队！查清楚了！医院志愿者登记表里根本没这个人！监控拍到她刚出住院部，打车往客运站方向去了！
* **周队：** （掌心狠狠拍在桌面上）马上联系客运站值班所，堵住检票通道！

* **情绪：** 争分夺秒、雷厉风行。
* **镜头：** 男主面部特写 -> 周队抓起对讲机的中景 -> 门被推开、平板追踪画面特写 -> 周队侧身部署的远景。

**第6场：医院警务室 / 长途客运站检票口（双时空交错）**

* **画面：** 周队走到铁柜前取出一件物证。同时插入客运站画面：孙芸在检票通道里被两名执勤民警拦下按倒，挎包被当场扣押。
* **人物动作：** 周队把伪装消毒仪摆在桌上给男主看，随后拉开身旁柜门取出一只亮银色金属卡包。
* **台词：**
* **周队：** 你看，这哪是什么消毒仪，拆开里面全是改装过的高频读卡器！往你包上一贴，没几秒工夫，卡里的钱和绑定的支付信息全叫人隔空偷走了！
* **男主：** （难以置信，攥着背包带）我那双肩包是加厚防泼水料子的，挺结实啊！这也能穿透？
* **周队：** 料子再厚也就防个磕碰淋雨，挡不住这种信号！布、皮、尼龙，在这种读卡器跟前跟一层纸没区别！对付隔空盗刷，眼下最实在的办法是这个——不锈钢防盗刷卡包。卡往里一放，合盖一扣，外头信号再强也很难钻进来！薄薄一只，银行卡、社保卡、门禁卡全塞得下，你拿着，回去也让你工友们都备一个！
* **男主：** （双手捧住卡包，牙关紧咬，眼眶又红了）我爸盖房子攒的钱他也下得去手……我跟他没完！
* **【音效】：** 对讲机的呼叫声又一次响起。
* **辅警小马（对讲机音）：** 周队，人在检票口按住了！包里翻出两台改装消毒仪！

* **情绪：** 真相揭穿的痛快、隔空盗刷原理的冲击。
* **镜头：** 客运站抓捕孙芸的快切画面 -> 周队掰开消毒仪外壳的近景 -> 卡包在灯光下的质感特写 -> 男主牙关紧咬的特写。

**第7场：医院警务室（正对镜头，宣教定格）**

* **画面：** 周队神情严厉，单手举着金属卡包，正面朝向镜头站定。男主在身后垂着头站着。
* **人物动作：** 周队拉开卡包，把银行卡逐张塞进风琴卡位，末了掌心一压，卡扣"嗒"地扣死。他攥着卡包朝镜头伸过来，目光沉沉。
* **台词：**
* **周队：** 家里有住院陪护经历的都听清楚！现在这帮人专挑医院这种人多手杂的地方下手，手里随便一个消毒仪、体温枪、宣传单夹子，掰开看都可能是改装读卡器！家属们挤在缴费窗口前排长队，谁凑近你身边站了几秒根本没工夫留意，等你回过神，押金已经被掏空了！卡好端端揣在兜里密码谁都没讲，你找谁喊冤去？！
* **周队：** （攥着卡包往桌面重重一拍，盖子啪地弹合）今天这个东西我直接交给你们！不锈钢外壳整个包住卡片，隔空那一套在它跟前不太灵，普通扫描信号很难穿透进去；里面是PVC风琴卡位，一张卡一格，谁也不挤谁，取用照样方便。牢牢记住一点——合盖必须扣到底，没扣严实它就是块铁皮，中看不中用！十九块九一只，五个颜色随你挑：金色、镜面银、宝蓝、枪灰、拉丝银，哪个顺眼选哪个！
* **周队：** （卡包推向镜头）家里有住院陪护的、常年在外奔波的，人手备一只！你们算算账，随便一顿外卖都不止十九块九，可你护住的是家里人的救命钱、买药钱！多裹一层金属壳子，就多一份安稳。我案子办得多了太清楚了，钱一旦被洗出去，十笔里九笔追不回来！你舍得让老人攒了大半辈子的钱，就这么被人隔着包面偷个干净？今天这小伙算是运气好截住了，但我从来不赌运气！与其等着对着空账户干瞪眼，不如现在就把口子堵上！点下方链接，把卡包用起来，护住你和家里人的救命钱！

* **情绪：** 情绪爆发、正义宣讲、极具说服力。
* **镜头：** 周队正面特写 -> 卡包合盖与信号被阻挡的特效画面 -> 周队目光直逼镜头的缓推特写 -> 定格在周队手中的卡包。
