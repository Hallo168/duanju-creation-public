## 组1：即梦官方语法（A/B/E/F）

**A 权重百分比语法 → 证伪知乎漫剧手册**
官方指南无任何百分比权重语法。官方一致性三件套：
① 主体定义句式：`将<图片N>中的[主体核心特征]定义为<主体N>`（2-3个静态特征）
② 素材前置权重控制："越需要精准参考的素材，放在提示词中越靠前的位置"
③ 独立人脸特写图＋全身照分开引用："主体1的面部特征参考图片1（大头照），妆造参考图片2（全身照）"
"外观权重90%/默认80%/一致性95%"仅知乎漫剧手册单源，无出处。

**B @编号机制 → 证实红队（当次顺序编号）**
官方 2.1 节："使用素材库（Asset ID）时，仍需使用<图片/视频N>指代主体。因模型无法直接关联 Asset ID 与参考内容，故不得直接以 Asset ID 替代<图片/视频N>"；7.3 节 API 示例 `"图1是李武，图2是苏银汐"`＋按序排列的 image_url。@编号=当次请求素材顺序。→ 每单元挂载清单是必须项。

**E 词数口径 → 官方无数字；官方多镜示例约340-350字**
官方只有定性要求："描述尽量简洁""请勿直接将完整剧本作为提示词使用"。官方3镜头示例全文≈340-350汉字，直接推翻漫剧手册"30-100词一刀切"。v3 锚点：3镜单元 300–350 字，单镜 60–100 词。
官方每镜四要素组织顺序：运镜/切换方式 → 主体动作表情 → 空间位置 → 音频信息。

**F 分时段写法 → "支持不稳定"是官方原文**
官方 2.2 节原文："使用镜头1、镜头2、镜头3等标识……不强制限制每段时长，优先让模型根据剧情自然生成节奏。💡模型对精确时间（如0-3秒）的支持不稳定，强行限制时长可能导致生成结果异常"。GitHub skill 的分时段模板是社区用法，抽卡概率性成功。→ v3 纯"镜头N"标签；秒数预算仅存在于分镜表内部（台词核算用），不进提示词。例外仅视频延长/卡点任务。

**附带发现（评审全体遗漏）：**
1. 官方特殊符号体系：音乐用（）、音效用<>、**台词用{}**、字幕用【】。官方示例：`笑着问 {考得怎么样呀，过了吗}`。→ 台词写法全面改用 {} 包裹，语气标注放在{}外。
2. **官方不建议使用人物三视图/多视图单图**（易被识别为多个主体，加剧ID漂移和"双胞胎"问题）。→ 用单角度分图：人脸大头照＋全身照为官方推荐组合。
3. 官方推荐素材总计4-5个（角色图1-2＋场景图1＋运镜视频1＋音频1），不建议用满上限。

## 组2：合规与实操（C/D/G/H/I/J）

**C AIGC标识 → 证实（硬合规，唯一法定义务项）**
《人工智能生成合成内容标识办法》2025-09-01 施行（网信办等四部门，cac.gov.cn），配套强制性国标同步实施。创作者须主动声明＋使用平台标识功能，不得删改隐匿平台标识。抖音细则（2025-09-01公告）：未主动标→平台强制加"疑似使用了AI生成技术"标识；后果分层：单纯不标→强打疑似标＋可能限流；AI＋违规内容→下架封号（抖音已下架AI侵权视频53.8万条）。→ v3 写为发布流程强制项，不是"建议"。

**D 音轨 → 部分证实-建议实测**
Seedance 2.0 为音视频联合生成一体化架构，无官方分轨导出说明；社区工作流默认混轨（"BGM在剪辑阶段统一铺一层"）；剪映人声分离只能粗分人声/背景两层。→ v3 按单混合音轨设计：需干净对白时提示词端控制（如声明"无背景音乐"），分轨能力以实测为准。

**G 双人对白高风险 → 部分证实（方向多源，量化无数据）**
"多人对口型是最大瓶颈"（woshipm评Seko）＋学术界公认难题（Bind-Your-Avatar论文）＋教程侧面印证。但 Seedance 2.0 主打对话口型同步，可能已改善，无量化重跑率数据。→ v3 保留"高风险＋预案"（正反打拆单人、口型近景只给说话者），重跑成本本项目实测校准。

**H 全景工作流痛点 → 无法确认-建议实测**
未找到独立社区反馈证实"截图分辨率低/光照失配是著名坑位"，属红队合理推断。→ v3 写为"待验证风险＋缓解措施"（4K底图、截图超分、融合提示词显式声明光源方向）。

**I 语速 → 证实为上限，写成区间**
播音行业 250-260字/分（≈4.2字/秒，新闻播报口径）；人耳舒适接受 240-250字/分。带情绪台词低于播报值。→ v3 按 3–4字/秒（180–240字/分）区间预算；10秒镜头台词 ≤30–40字。

**J 爆点密度 → 部分证实（出处=付费长篇个案）**
"每分钟3-4爆点"出自《我在80年代当后妈》（付费投流长剧浓缩版）个案拆解，非行业通用标准。免费生态口径（红果官方编剧教程）：单集三段式——前30秒钩住/中段推进注入干货/结尾留伏笔；"三五集一个小高潮"；明确反对匀速堆爆点（"紧张—放松—期待"循环）。→ v3 以结构性检查为主（三段式＋编剧顾问节点制），"间隔≤20s"降为参考项，注明出处语境，用发布数据校准。
