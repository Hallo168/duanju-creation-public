## 1. 知识库加载策略：三级分层

| 层级 | 位置 | 判据 | 例子 |
|---|---|---|---|
| L1 硬规则内嵌 | 写死在命令.md里 | 违反即翻车且<300字 | 单句≤15字；禁"快速"；正面约束句；单元≤15s/2–4镜 |
| L2 全文加载 | 命令第一步显式Read | 每次执行都要对照的字典/表 | 情绪外化字典、运镜光影速查 |
| L3 按需加载 | "仅当…时读取" | 特定分支才用 | 全景图工作流（/zichan遇新场景才读） |

- 不用 `@file` 内联（无条件全文注入不可裁剪），统一显式 Read
- 知识文件规划：爆点知识库 / 提示词规范 / 情绪外化字典 / 运镜与光影速查 / 资产生产规范（吸收旧人物卡模板）
- **防膨胀**：单知识文件>400行必须拆"核心版（命令必读）+完整版（按需查阅）"

## 2. 命令间数据传递：文件契约

**总约定**：产物 = YAML frontmatter（机器状态）+ 固定H2标题（接口，一字不可改）；需逐字复用的块一律放独立代码块（代码块即复制单元）。

### 二创稿.md 契约
frontmatter（story/status/总时长）+ H2：标题候选 / 一句话梗概 / 换壳对照表 / **角色表**（ID列：R1/R2…）/ **场景表**（S1/S2…）/ 正文（每段落：场景ID、角色ID、台词带声音标注、情绪、秒数）/ 爆点分布图。
**R/S ID 在此出生，贯穿全流程**——/zichan 直接消费两张表，不从正文猜角色。

### 资产清单.md 契约（用户唯一手填文件→三重防错）
1. **/zichan 预填建议编号**：按推荐上传顺序填好"图片1、图片2…"，用户只要按清单顺序上传即零修改
2. **文件名建议列**：`R1-女主-正面半身.png`——本地文件名↔清单行↔@编号三方自解释
3. **/fenjing 入口校验**：编号无重复、无"待生成"残留、正文引用的R/S ID全覆盖；校验后回显映射表一行再继续
- frontmatter：`assets_ready: false`（用户生成完并填好编号后改true）
- 表列：即梦编号 | 资产ID | 内容 | 建议文件名 | 来源 | 状态
- 附「每单元挂载建议」表

### 分镜提示词.md 契约
每单元固定：`## 单元N（段落x–y | 镜头a–b | Ns）` → 挂载行 → 提示词代码块 → `修复记录：`行（/xiufu追加）。**"单元N"标题是/xiufu寻址键。**

## 3. 跨集资产复用

```
assets/
├── 角色库/R-角色名/人物卡.md + 六视图png   # 文件夹名全库唯一
├── 场景库/S-场景名/场景卡.md + 底图/机位png
└── 风格预设.md
```
- story内 R1/R2 只是本集局部别名，资产清单"来源"列绑定到库路径
- **单一来源原则**：人物描述块只存在于人物卡.md；下游全部"读取后逐字复制"，不得改写复制品；修改=升版本（frontmatter `version: 2`，旧版移入卡内"历史"节，因旧集提示词还依赖）
- 换装=卡内"服装B"变体块，不新建角色
- /zichan 复用流程：提取角色表 → Glob `assets/角色库/R-*` → 问用户是否复用 → 复用则状态标`已有`跳过生成；新角色人物卡**直接写入角色库**（story文件夹只放引用不放定义）

## 4. /xiufu 会话设计

调用形态：`/xiufu 3 第二镜女主换脸了`（单元号+翻车描述；只给单元号则追问）
流程：定位最新故事 → Grep `## 单元3` 局部读取（提示词+挂载+既往修复记录）→ 涉一致性问题加读人物卡 → 按内嵌修复阶梯诊断 → 输出原因判断(1–2句)+单元v2完整提示词 → **Edit原地写回**分镜提示词.md并追加 `修复记录：v2 | 日期 | 现象→阶梯①+②：具体改法`（多轮翻车v3能看到v2试过什么，避免重复开药）。
支持用户直接粘即梦翻车截图：命令写明"如附截图，先描述看到的失真类型再诊断"。

## 5. 状态追踪：产物存在性推导（零维护）

不建独立status文件（双写不一致风险）。状态=文件夹里有什么：
仅原稿→待二创；+二创稿→待资产；+资产清单(含待生成)→生成资产中；清单无残留或assets_ready→待分镜；+分镜提示词→生成/修复中；+数据.md→已发布。
**定位规则（各命令共用）**：取stories/下编号最大文件夹；命令检查"我的输入存在且我的输出不存在"→是则默认操作，否则报告状态问用户。唯一显式标记：assets_ready（"用户在即梦生成完"不产生新文件，是存在性覆盖不到的死角）。
