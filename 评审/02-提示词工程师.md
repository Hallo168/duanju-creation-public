## ① 修订/新增规范条目

### R1 镜头N标签 与 分时段写法：两级结构
- 两者不是二选一：**镜头N管"机位切换"，时段管"节拍落点"**
- 必须用〖镜头N〗：凡机位/景别/视角变化，以及有对白需对口型的单元
- 可用分时段：单镜内部连续动作节拍，或无对白纯动作单元
- 推荐嵌套写法：`〖镜头1｜0-5秒〗`——明确每镜时长、倒逼台词不超载、尾帧衔接可指定截图时刻
- **禁止平级混用**："镜头1"和"0-5秒"作并列小节标题会被模型理解为4个片段

### R2 多角色同框的组织
- **@绑定只在〖素材声明〗层做一次**（`@图片1=女主苏晚外观基准`），正文一律用角色名——正文里的@会被部分模型理解为"把图插入画面"
- 一人一句、主语必须是角色名；动作句禁止"他/她"跨句指代
- **空间锁定句**：双人镜头必须有一句纯位置关系描述，写在描述块后、动作前
- 台词行以角色名开头，与声音层标注合并：`陆承（急切，语速加快）说出台词："……"`

### R3 锚点递减制（修正"每镜全量重复"硬矛盾）★
- 原规则数学上不可能满足词数上限（60字×2角色×3镜=360字）
- **首镜全量**：出场镜头写完整描述块（≤60字）
- **后续镜头锚点简写**：`角色名（2个硬锚点）`如"陆承（右眉浅疤，深灰西装）"；特写镜头锚点换五官级
- 外观一致性主承重墙是@参考图，文字是冗余锚定
- **词数统计口径**：200–300词按描述性正文计；素材声明、约束尾固定句、台词引号内内容不计入。仍超限先减镜数（3→2），不删外化动作

### R4 台词长度换算
- 中文短剧带情绪语速 ≈ **4字/秒**（对峙/哭戏3–3.5）
- 台词占时(秒) ≈ 字数÷4 ＋ 停顿数×0.7（省略号/破折号/句间换气各算一个）
- **留白硬规则**：台词总占时 ≤ 单元时长60%；每镜至少1秒无台词反应时间（张力核心+对口型出错的剪辑余量）
- 速查：5秒镜≤12字；15秒单元台词总量≤35字

### R5 对白密集单元 vs 纯画面单元
| | 对白密集单元 | 纯画面单元 |
|---|---|---|
| 切分 | 必用〖镜头N〗 | 可用分时段 |
| 镜数 | 2–3镜 | 3–4镜 |
| 词数重心 | 声音层标注+**听者的反应动作**（比说者的嘴更重要） | 动作幅度/物理细节+运镜 |
| 运镜 | 保守：固定/缓推/移焦（剧烈运镜毁口型） | 可上跟拍/环绕/甩镜 |
| 音效 | 对白为主，音效只做重音标点（拍桌/椅响） | 环境音+动作音效全铺 |

### R6 @引用强调：自然语言三档（删除权重百分比）
- "权重90%"非官方语法，最好被忽略、最坏数字进画面
- 强（角色脸）："严格保持与@图片1完全一致的五官、发型、服装，此项为最高优先级"
- 中（场景）："以@图片3为场景基准，直接使用该环境"
- 弱（风格）："画面风格参考@图片N"
- 百分比可作分镜总表的内部质检标注，**不进提示词正文**

## ② 示范提示词（15秒对峙单元·亲子鉴定场景）

```
〖素材声明〗@图片1=女主苏晚外观基准，@图片2=男主陆承外观基准，严格保持
五官、发型、服装与参考图完全一致，此项为最高优先级；@图片3=场景基准，
直接使用该办公室环境。

〖镜头1｜0-5秒〗中景。深夜总裁办公室。
苏晚：28岁女性，鹅蛋脸，黑色低马尾，米白色西装套装，左腕细银手镯。
陆承：32岁男性，剑眉方脸，右眉尾一道浅疤，深灰色三件套西装。
苏晚立于桌前，陆承坐于桌后，两人隔桌相对。
苏晚将牛皮纸文件袋狠狠拍在桌面，指尖压住文件不动，下颚线绷紧，
胸口缓慢起伏一次。固定镜头(fixed)。
苏晚（冷声，句号切成短句，字字压着）说出台词："亲子鉴定。你自己看。"
音效：文件拍桌闷响，纸张散落声。

〖镜头2｜5-11秒〗过肩近景，越过苏晚右肩拍陆承（右眉浅疤，深灰西装）。
陆承猛地站起，椅子向后滑出，双手撑住桌沿，喉结滚动，目光闪躲不敢与她对视。
缓慢推镜(push in)。
陆承（急切辩解，语速加快，尾音发虚）说出台词："晚晚，你听我解释，不是——"
苏晚（打断，音量陡然提高又骤然压低）说出台词："三年了，陆承。"
音效：椅腿刮地声，一记急促钢琴单音。

〖镜头3｜11-15秒〗苏晚面部特写（鹅蛋脸，黑色低马尾）。
眼眶泛红却不眨眼，一滴泪滑过颧骨，嘴角缓缓扯出一个极淡的笑，
眼神从灼热冷却成空。移焦(rack focus)从她的面部缓慢转至桌上文件。
苏晚（气声，一字一顿，平静得没有任何起伏）说出台词："不用了。到此为止。"
音效：环境音骤然收静，只剩挂钟秒针声。

〖场景光影〗桌面暖黄台灯(3000K)自左下方打亮两人面部，窗外冷蓝城市灯光
(6500K)作逆光勾勒轮廓，明暗比1:4，冷暖对峙氛围。

〖全局收尾〗写实电影质感短剧风格。保持两人面部与参考图完全一致，无变形，
服装全程不变，不生成字幕，不生成水印。
结束帧定格：苏晚特写，含泪浅笑，视线落在文件上。
```

自检：描述性正文≈270词（R3口径）；逐镜台词核算全部通过（镜1：8字≈3s/5s ✓ 镜2：15字≈4.8s/6s ✓ 镜3：8字≈3.5s/4s ✓）。按原方案"全量重复"写法此单元≈620字，直接爆掉上限——R3 的由来。

## ③ 单元衔接三级策略

核心思想：**能用剪辑逻辑掩盖的不连续，不要用像素连续硬扛。**

- **A级·首尾帧硬衔接**（同机位连续动作跨单元，成本最高）：上单元约束尾写"结束帧定格：……"句 → 生成后取倒数第2–3秒清晰帧（尾帧常有运动模糊/口型半开）作@图片挂入下单元，声明"以@图片N为起始画面，人物从该姿势继续动作"；光影层逐字复制，色温差500K就跳灯
- **B级·剪辑点软衔接**（默认，80%交界用）：主动换景别制造剪辑点——上单元收特写、下单元开全景（或反之），景别跳变天然掩盖不连续；只需三样文字连续：服装描述块逐字复用、光影层逐字复用、**情绪残留交代**（下单元首镜第一句动作承接上单元情绪终点）
- **C级·转场遮断**（时间/地点跳跃）：甩镜收尾、黑场、或插1秒空镜（场景机位截图直接当空镜），豁免连续性
- **配套：情绪接力表**——分镜总表加两列 `单元情绪终点 | 下单元情绪起点`，QA逐行核对，防"动作接上了但情绪断裂"

## ④ 情绪外化字典补充（7组）

**身体层**：
| 情绪 | 外化写法 |
|---|---|
| 震惊 | 瞳孔骤缩，整个人僵在原地，手中物品脱手坠地，嘴唇半张发不出声，后退半步扶住桌沿才站稳 |
| 羞辱 | 脸颊到耳根迅速涨红，头低下又强行抬起，指甲掐进掌心，眼眶发热却死死瞪着对方，嘴唇抿成发抖的直线 |
| 得意 | 下巴微抬，单边嘴角上挑，慢条斯理整理袖口，脚步不紧不慢踱近，居高临下俯视 |
| 恐惧 | 肩膀瑟缩，连连后退直到背抵墙壁，双手护胸，指尖发抖，急促浅喘，视线死锁威胁源 |
| 心死 | 所有表情从脸上褪去，肩膀垂落，目光失焦望向虚空，缓慢摇一次头，转身动作轻得像被抽走力气 |
| 嫉妒 | 目光在两人之间来回扫，笑容维持但眼神发冷，握杯手指收紧至指节泛白 |
