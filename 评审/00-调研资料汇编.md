## 一、Seedance 2.0 基础参数（来源：苏米客 xmsumi.com/detail/2432 实测文 + GitHub dexhunter/seedance2-skill）

- 【多源】输入上限：图片≤9张（每张<30MB）、视频≤3个（总时长2–15s）、音频≤3个（MP3，≤15s）、总文件数≤12
- 【多源】生成时长 4–15 秒可选；支持 16:9/9:16/4:3/3:4/1:1/21:9
- 【多源】原生音视频联合生成、对话口型同步、文字叠加、视频延伸（延长时生成时长选"新增部分"长度）
- 【多源】不支持上传写实真人清晰人脸素材，系统拦截（用户表示自己有办法，此项不影响方案）
- 【单源·苏米客】两种入口：首尾帧模式（首帧图+文本）与全能参考模式（图/视频/音频/文本混合，需@指认用途）
- 【单源·苏米客】引用视频素材会明显提高生成费用
- 官方手册（未能直接读取，需核查）：bytedance.larkoffice.com/wiki/A5RHwWhoBiOnjukIIw6cu5ybnXQ；火山引擎提示词指南：volcengine.com/docs/82379/2222480（JS动态页，主会话读取失败）

## 二、@引用语法（来源：GitHub seedance2-skill 完整语法表 + 苏米客 + 知乎漫剧手册）

- 【多源】@图片N/@视频N/@音频N，必须为每个引用明确用途（"@图片1 作为首帧""参考@视频1的运镜"）
- 【多源】"参考"一词触发引用模式；视频编辑用"严格编辑@视频1"、延伸用"向前/向后延伸"，不要用"参考"
- 【冲突】**@引用权重百分比写法**：知乎漫剧手册（zhuanlan.zhihu.com/p/2030282234528260520）明确推荐"（外观权重90%）"写法并给出多例；GitHub skill 和苏米客实测文均无此语法；红队/提示词工程师评审断言为以讹传讹。→ 需官方文档裁决
- 【单源·漫剧手册】@编号规则："上传后每张图片自动获得编号：图片1、图片2……"——但编号是当次会话内还是素材库持久，未明说。红队断言"当次上传顺序决定"。→ 需核查即梦实际交互

## 三、提示词写法（来源：翔宇工作流八层框架长文 + GitHub skill + 知乎漫剧手册）

- 【冲突】**最佳词数**：翔宇（社区200+次测试）：单镜60–100词、多镜200–300词、超300词后半段被忽略；知乎漫剧手册：中文30–100词最佳、过长注意力分散。两者对"多镜单元"的口径差近3倍。→ 需核查官方口径或实测
- 【多源】核心信息放前面（注意力从左到右递减/前20%加权最重）
- 【多源】一镜一运镜；运镜与主体动作分开描述
- 【单源·翔宇】禁用"快速/fast"（必然运动模糊）；镜头标签用"镜头N"、精确时间码支持不稳定
- 【冲突】**分时段写法**：翔宇称官方文档说精确计时(0-3秒)支持不稳定；但 GitHub skill（自称基于官方手册）推荐10秒以上用分时段描述（0–3秒/3–6秒…），且官方短剧模板本身用"画面（0-5秒）"。→ 需核查官方手册原文
- 【多源】不支持负面提示词输入框；正文内约束句写法存在（"保持面部一致，无变形，不生成字幕，不生成水印"）
- 【多源】台词写法：描述台词内容时（xx说："……"）模型保持台词不变生成；未写台词则模型自由发挥（阿里云万相文档同样描述此机制）
- 【单源·翔宇】同屏角色≤3，超过则面部一致性下降
- 【多源】情绪外化优于抽象情绪词；光影具体描述（方向/色温）收益最高
- 【单源·官方模板转载】短剧模板中台词带语气标注：`台词1（角色A，哽咽怒吼）："你到底想骗我什么？"`

## 四、人物/场景一致性（来源：WaveSpeed 实测长文 + 知乎AI短剧文 + 漫剧手册 + super-i 全景教程）

- 【多源】角色参考图：纯色背景、柔和均匀光、中性表情、正面半身最重要；一套服装贯穿全剧
- 【单源·WaveSpeed】参考包最佳实践：≤3张静态照（正面/四分之三/侧面，同一拍摄同光线）+2–3秒中性动作短片+1张风格锚点帧；拼贴图有害；混合光照有害；提示词缩短1/3效果更好；修复阶梯（换单张参考→逐条加约束→缩短动作→降视觉熵→轮廓兜底）
- 【多源】锁定1–2个硬特征锚点（耳环/疤痕）；命名角色为单一实体
- 【单源·漫剧手册】六视图角色库（正全/正半/正特/侧半/3/4侧/背面）+表情特写集
- 【单源·super-i】720°全景虚拟影棚：参考图→LLM反推全景提示词→2:1全景图（Nano Banana 2等）→全景查看器旋转截图→角色融合（前缀"参考图片环境生成，保持场景一致性，50mm镜头，无透视"）。注意：文中具体提示词做了加密处理，只有流程可信

## 五、短剧爆点方法论（来源：人人都是产品经理"情绪印钞机" + 流媒体网三点论 + 新华网 + 红果编剧第一课）

- 【多源】3秒定生死；钩子类型：画面钩/悬念钩/情绪钩（新华网口径）；冲突/悬念/反差开场（编剧课口径）
- 【单源·woshipm】每分钟3–4个情绪爆点（出处为《我在80年代当后妈》拆解，2分钟付费剧集生态）；30秒情绪爆破（耳光+玻璃碎裂音效完播率提升172%）；七宗罪杠杆；瞳孔峰值在身份反转+肢体冲突；卡点付费设计（8-12集一卡）——注意此文语境是付费长篇短剧，非单集单故事
- 【多源】反派=极致恶行+阶段性胜利；主角记忆点=反差设定×情绪杠杆
