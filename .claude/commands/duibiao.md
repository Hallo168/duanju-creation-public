你是短剧结构分析师。**第一步先 Read `knowledge/1-核心规则.md` 和 `knowledge/2-拆解提示词.md`**——前者是判断底座，后者定义拆解输出的字段模板。

**铁律**：本命令只解剖不创作——不改写台词、不出大纲、不换壳、不接产品。

## 输入

对标素材：$ARGUMENTS
- 是文件路径 → 读取；是文本 → 直接用；为空 → 请用户提供（只收文字台词稿，视频/链接请用户先自行取得字幕文本）
- 素材中若附带数据表现（点赞/完播/评论热词）或来源说明，记入拆解结果

## 执行流程

1. **判型判抓手（头两件事）**：剧本类型＋观众抓手（7-选题生成法 §〇 四模式），**开头一句大白话报结论让用户能拦**；再读 `爆款结构库.md`（剧情框架导航＋卡片索引），按当前主类／小类定位并比对核心机制列查重，疑似同款再读对应卡文件确认——内核近似的不另立新卡，在老卡文件追加一行变体记录即可，收尾报告
2. **存档**：来源全文原样写入 `对标素材库/素材/六位编号/六位编号-对标名.md`，与视频共用编号；新素材先运行 `python -X utf8 对标素材库/工具/reserve_material.py --title "对标名"` 分配统一编号
3. **拆解**：按 `2-拆解提示词.md` 的字段模板完整拆解（含 2026-08-06 新增：观众抓手/开场双钩/台词手法/规则回测）；残稿不补剧情、不编结局，推断项集中标注；对标铁律＝"验证过的爆款没有缺陷，只有没看懂的设计"
4. **直接入库不等确认**（2026-08-06 改，原：交用户确认后入库）：按既有卡片格式（核心机制/人物配置/结构链/可复用点/换皮限制/情绪路径/⚠️待修项/注意；换皮限制栏 2026-09-01 起新卡必填＝2号【换皮限制】栏的负向不变式，存量卡无此栏属正常、借用时现场补提）**新建卡文件** `爆款结构库/{带货|流量|口播}-{卡名}.md`，按 `爆款结构库.md`「归类与复用约定」在唯一主归属分组**追加一行**（卡名链接｜核心机制一句话｜已二创列填"—"｜辅助标签）；来源方数据结论标"来源方经验"，不写成我方已验证；用户对拆解有异议时按反馈当场改卡。**剧情小类同步（2026-09-10）**：按总索引「归类与复用约定」维护对应小类的版本差异、源卡及原稿入口，并同步导航数量；修改已有小类前先 Read 当前内容。同源变体与跨类记录按原稿路径去重；只更换表层不新增小类，判不准先保留待分类。本步沿原“直接入库”执行，新小类为来源结构资产，不改变带货框架候选的拍板要求。**带货段双入库（2026-09-02 三层资产）**：对标有带货段的，同步①框架归属——对照 `带货框架库.md` 索引，归得进的在该框架卡「样本清单」追加一行（直接入）；归不进的（环序或逼单结构不同才算新框架，捧哏/加码/切入形态不同只是变体登老卡防撞名单）按框架卡体例出新框架候选**交用户拍板**后立卡；②转化话术按七个功能位入 `knowledge/转化话术库.md`（直接入不等确认；防膨胀规则见库头：同功能位同句式只留最强、更强替换不追加）；③产品专属卖点/预期素材写进该品 `产品规格.md`「转化话术素材」节（该品不在产品库的留在结构卡话术链里）
5. **手法候选**：拆解中发现的措辞技法对照 `knowledge/手法库.md` 查重——老手法的新实例**不入库**（例句比锚例强只提"替换锚例"），真正的新手法按手法库格式（≤3 行）出候选**交用户拍板**后才写入；好句本身留在卡片的金句/刺痛词清单里当数据。**带货段话术不走手法库**（手法库不收例句）——走 `knowledge/转化话术库.md`（带货段豁免 8 字，可收原句，见第 4 步）。**开场手法另走 `knowledge/爆款开头库.md`**（2026-08-08）：【开场双钩】对照库标模式归属写进卡片；新开场模式**与卡同步直接入库**（不走拍板；老模式不重复收，锚例只换不加）
6. **版图同步（2026-08-09 用户裁定：拆解也要给选题库攒故事类型）**：拆完对照 `爆款结构库.md` 的类型版图＋母题盘＋库内零件盘——对标落在**新故事类型**的，类型版图加行（过形态关四问，判定列标"来源＝对标拆解"）；发现新母题/关系壳/装置变体/财力反差配置/反转杠杆的，零件盘对应组追加一行（一行制带卡名，重复不录）；已有条目盖得住的不动，报告里提一句同步了什么或"无增量"；剧情主归属只在第4步所用分类索引维护，旧类型版图继续记录原调研与准入判断，不另立第二套主分类
7. **规则回测**（收尾必做）：对标违反我方现行规则仍是爆款的，逐条记 `规则变更日志.md` 误伤台账；同一条款累计两次触发复审——报告里单列一节【规则回测】，无发现写"无"

## 收尾报告

一句话内核＋结构链骨架、钩子与反转机制要点、可复用点、风险提示。加一行剧情归属：大类／小类／具体源版本（或待分类理由），说明小类与附属版本同步结果。带货集另加一行：带货框架归属（老卡追加样本／新框架候选待拍板）＋话术入库条数（按功能位）。金句只可复用句式骨架，原句措辞进二创稿即违规（换壳红线，见 CLAUDE.md 硬性规则1）。
