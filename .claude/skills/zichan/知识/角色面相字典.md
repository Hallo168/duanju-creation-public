## 定位菜单（脸型 / 眉眼 / 鼻唇 / 神态 四栏，每栏挑 1）

**男主**（霸总型/落魄逆袭型）
- 下颌线清晰的窄长脸 / 剑眉、眼尾微垂的深邃眼 / 高挺直鼻、唇形端正 / 神情疏离沉静
- 避雷：五官太凌厉→观众读成反派；用微垂眼尾或圆润眼型中和锐气

**女主**（苦情型/大女主型）
- 鹅蛋脸或小V脸 / 圆润杏眼、眉形柔和 / 小巧圆鼻、唇色干净 / 眉眼清秀耐看
- 避雷：面中凹陷、眉眼精明→读成心机女配；穷困人设也不降颜值档（P-88）

**大佬/长辈高人**（幕后大人物/扫地僧/慈祥长辈）
- 国字脸或方正下颌 / 浓眉、眼神沉稳有神 / 鼻梁厚实 / 不怒自威、气定神闲
- 扫地僧型反着写：面相平凡普通＋眼神偶露精光，靠反差压场
- 避雷：写成凶相→变打手不是大佬；"威"来自沉稳神态不是狠五官

**反派男**（阴狠型/纨绔型）
- 阴狠型：面颊消瘦的狭长脸 / 三角眼或吊梢眉 / 鹰钩鼻、薄唇 / 眼神凌厉无亲和
- 纨绔型：五官深邃精致 / 桃花眼 / 唇色偏艳 / 笑意不达眼底——金玉其表、斯文藏狠
- 避雷：**丑得出戏**是大忌；狠靠眉眼神态，不靠五官崩坏

**反派女**（恶毒女配/恶婆婆）
- 颧骨棱角分明 / 吊梢眼、眼白微露、锐利挑眉 / 薄唇、唇线锋利 / 精致的刻薄感
- 避雷：太硬只显悍不显狠——妆造可以精致漂亮，狠在眼神与唇线

**忠厚好人配角**（老实人/助攻）

- 避雷：平顺≠猥琐；别写出记忆点抢主角戏
