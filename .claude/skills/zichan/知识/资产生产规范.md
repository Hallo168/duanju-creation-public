## 〇、生图执行方式：普通资产内置生图、彩铅专用通道

**/zichan 产出提示词后必须直接把图生完，不把生图操作留给用户等待。**

**普通资产（2026-09-28 用户裁定）**：暂停使用本机 GPTAPI/chatgpt2api，直接调用当前会话内置 `image_gen`；沿用原提示词、参考图、命名和技术核对，变体仍须图生图。**彩铅派生使用专用通道（2026-10-11 用户指定 AIHubKit）**：固定使用 `https://apimodel.aihubkit.com` 的 `gemini-3.1-flash-image-preview`，只接同角色同状态写实人物设定图这一张参考图，输出 9:16、1K，提示词逐字固定为「不改变图片，把图片风格转换成素描彩铅画」；不得把彩铅任务静默回退到其他通道或模型。

**人脸触发派生规则（2026-08-03 用户新增）**：Symphony 返回 `InputImageSensitiveContentDetected.PrivacyInformation`、`face detect not pass` 或同义的明确人脸/参考图隐私拒绝时，保存原始错误与任务账本，逐单元把“视频挂载”中的角色 ID 映射到精确文件名，建立可疑参考图清单；不得把普通审核拒绝、网络错误或 `direct_outcome_unknown` 当作人脸触发。对确认的可疑人物图，只从同角色同状态写实人物设定图单张图生图派生新彩铅图，使用本节当前 AIHubKit 通道、9:16、1K 和原固定提示词；旧图不覆盖，新图先做技术核对并通过 Symphony warmup，再按剩余实际额度和账本对账结果只重投受影响单元，重跑次数计入 V14 上限。

普通资产由执行者直接调用内置生图；彩铅任务使用 `工具/gen_grids_multi.py` 的任务文件（`{output_dir, tasks:[{id,file,size,prompt|prompt_file,refs?,provider?}]}`）和拓扑分层。文件名含「彩铅」或「素描」，或显式 `provider: "aihubkit_gemini_image"`，即走 AIHubKit。已提交的历史任务先对账，不因迁移重复提交。脚本中的普通任务已由配置阻断。彩铅任务服从当前生产开关，启用时固定走 AIHubKit，不自动切换通道。
- 彩铅跑法：`python gen_grids_multi.py <任务json> 0`；彩铅并发读取其独立配置，启停服从 `工具/生产开关.json`。任务中指定未配置的生图渠道会在提交前终止，不静默改走其他渠道。
- 暂停期间留档的 GPTAPI 配置：`工具/api配置.json` 的 `providers.chatgpt2api`（`base_url` `http://127.0.0.1:8000` + `api_key`＝该项目 config.json 的 `auth-key`，端点 `/v1/images/generations` 与 `/v1/images/edits`）；不用于当前普通资产生图。
- 彩铅默认路由为 `工具/api配置.json` 的 `colored_pencil_defaults.provider`，配置为 `providers.aihubkit_gemini_image`；适配器 `工具/aihubkit_image_client.py` 使用 Bearer 认证及 Gemini 原生 `generateContent` 接口，原图以单张 `inlineData` 提交；固定 `gemini-3.1-flash-image-preview`、9:16、1K。请求和账本不保存密钥，不依赖浏览器登录或扩展。操作见 `工具/AIHubKit彩铅接入.md`。

## 一、人物资产：竖版双格人物设定图（2026-08-05 用户裁定终版：大头照＋全身照合在一张图，整图挂载；四格/三视图设定图仍全面退役）

> 裁定链：官方"双胞胎问题"章节证实多视图/宫格素材易被识别为多主体生成克隆人，四格制退役；官方推荐"大头照＋全身照两张分开引用"，用户裁定改为**合并一张竖版双格**（同日推翻两张分挂方案）——比四格少一半人物实例、比两张分挂省一半挂载位。双格仍属多视图族，故**反克隆约束句为强制配套**（T16）；若新链克隆率回升，按 CLAUDE.md 14.5 复验降级为官方两张分挂。存量集资产不回滚。

**每角色每状态固定输出两张图**（写实版＋彩铅版，同一竖版双格布局）：

1. 布局（9:16 竖版，两格上下排列、白色细分隔线）：**上格＝正脸头肩近照**（负责面部特征），**下格＝正面全身照**、从头到鞋完整入画，自然站立、双臂自然下垂（负责妆造/体型/服装）；
2. 两格必须是同一人物、同一年龄、同一发型、同一服装、同一体型，纯白背景、均匀影棚光、无文字无水印；
3. **写实人物设定图**负责身份母版、封面与写实关键帧；**彩铅参考图**专供视频生成与人脸修复挂载，成片仍按写实风格生成。

**命名**（沿用旧惯例，工具零改动）：
- 写实版：`R{n}-{角色名}-{状态}-人物设定图.png`
- 彩铅版：`R{n}-{角色名}-{状态}-彩铅参考图.png`
- 角色换服装/换年龄段/换状态 → 同状态另出这一对双版本，原图不动

**生成链（硬规则）**：
1. **基础写实版**：每角色第一状态可文生图直出固定竖版双格布局。
2. **写实变体版（换装/变老/伤妆）**：必须以基础写实版图生图，保持人物五官、脸型、发型骨相和体型一致，只改变指定状态；禁止独立文生图。
3. **彩铅版**：必须以同角色、同状态的写实人物设定图作为唯一参考图，经 §〇当前 AIHubKit 模型图生图；固定 9:16、1K、极简提示词，不采用其他模型兜底。双格布局、人物身份、年龄、发型、服装、体型和表情基准不变，只转换绘画媒介；禁止从文字独立生成，禁止拿其他状态的图代替。
4. 存量集补拍/修复需要新参考图时，以该集原设定图（含历史四格图）作身份母图，图生图派生本节竖版双格图，再派生彩铅版；旧图保留作可恢复母图，不删除。

**写实人物设定图提示词模板**：
```
生成一张竖版2行1列人物设定图，两格上下排列、白色细分隔线：上格正脸头肩近照，下格正面全身照。
[人物描述块逐字放入]。两格为同一个人，五官、脸型、年龄、发型、服装、体型完全一致；全身格从头到鞋完整入画，自然站立，双臂自然下垂，表情平静。
纯白背景，均匀影棚光，无投影，无文字，无水印。[全局风格块]
```

**彩铅参考图提示词模板（必须图生图；§〇当前 AIHubKit 模型、9:16、逐字固定）**：
```
不改变图片，把图片风格转换成素描彩铅画
```

生成后交用户检查两版双格是不是同一个人、同一服装、同一布局；用户判定不一致并点名后再重跑——执行者不得自行看图代审。

**挂载用法（整图直接挂载，不裁切）**：
- 封面与写实关键帧：挂**写实人物设定图**。
- 视频生成：人物一律挂对应状态的**彩铅参考图**（一人一张一个挂载位）；素材声明 `将<图片N>中的[2-3个特征]人物定义为主体N（角色名）`，不写"图中两格是同一人"等解释句（T7）；最终画面沿用本集全局风格块，不复刻彩铅纸纹。
- 人脸漂移修复：优先重做或替换彩铅参考图；只有用户指定或平台实测要求时才临时改挂写实版；需要更精准面部参考时，才从彩铅版上格临时裁一件补挂（裁切为修复备用手段）。
- **反克隆约束句（官方模板，人物挂载单元必加，双格挂载的强制配套）**：`视频全程禁止出现外形、着装、配饰完全一致的人物，不生成同款分身或双胞胎效果，每个角色在同一画面中只出现一个`——为 F25 白名单第三条负向句（官方点名例外，提示词规范 T16）。

## 二、人物描述块（写进本集资产清单.md，单一来源）

格式：**≤60 字**，含——年龄性别 / 脸型五官 / 发型发色 / 体型 / 服装（颜色+材质+款式，一集不换）/ **1–2 个硬特征锚点**。

> **未成年角色照剧本写真实年龄与身份词（2026-09-03 用户裁定解除去龄化默认，提示词规范 T10.1）**：描述块"年龄性别"位正常写年龄数字与孩子/学生等词，服装可写校服。去龄化只在通道拒绝后作修复手段：届时描述块改 **"男生／女生"** ＋外观锚点、校服改运动外套，分镜逐字复制保持一致（描述块是分镜的单一来源，改源头不改分镜）。

写作要诀：
- **外貌与气质**：全角色颜值、外貌多样性及身份变化的形象表达，以 `角色面相字典.md` 为唯一依据，不按善恶套脸。
- **具体压倒好听**："鹅蛋脸、细长丹凤眼、及肩黑色直发" 比 "清秀漂亮" 稳定十倍；“帅气、漂亮”可明确目标，但须配具体五官与造型依据
- **视觉档次跟经济身份（2026-08-05 用户裁定，偏好库·视觉档次）**：贫富差靠画面砸出来——富方角色的服装位写**高级具体词**（真丝衬衫、剪裁笔挺的深色西装、金丝眼镜、精致盘发、珍珠耳钉），发型妆面精致、整体帅气漂亮但仍用具体词表达；寒酸方写"旧但整洁"（褪色、起球、洗白，不写脏乱）。60 字预算内档次词优先级高于第二个硬锚点

## 三、场景资产（普通透视场景图）

每场景生成1张 **16:9 横版**正常视角的场景图，直接作为本集场景基准图和分镜挂载图；不生成全景底图，不派生四宫格。含常驻人物的基准图变体同样为 16:9 横版，在声明中点明人物与位置（如“床上有XX闭眼平躺、头朝床头”）。

- **生成渠道**（渠道政策见 §〇）：用 `工具/gen_grids_multi.py` 文生图（任务 JSON 不带 refs 自动走 `/v1/images/generations`），产物存本集 `资产图/S{n}-{场景}-场景图.png`，直接挂载。
- 全片场景主动收敛到 **1–2 个**（上限：纯剧情集 ≤4、带货剧放宽 ≤6）；**场景数 >2 时提醒用户收敛**。**本行＝场景数唯一权威源**（6-分镜契合 §5 与本 skill 入口均指此）；场景描述块（光影层逐字复用源）写进本集 资产清单.md。
- **场景档次跟剧情身份（2026-08-05 用户裁定，偏好库·视觉档次）**：富方/豪华场景的场景图提示词必须写足华丽材质与空间感（大理石地面反光、水晶吊灯、整面落地窗、真皮沙发、层高开阔），光照按本剧调性与 Y20 执行——豪宅拍出豪宅样，贫富差从场景图源头就拉开；寒酸场景写“旧但整洁”，用材质表达旧（掉漆、磨损），明暗随场景时间与剧情，不因贫穷统一压暗。
- 素材声明写法：`图片N为该[场景名]的场景图，作为场景基准，直接使用该环境`。
