## 一、基础运镜

| 写法 | 功能 | 适用 |
|---|---|---|
| 推镜(push in / dolly in) | 强调细节、情感强度递增 | 情绪高潮、关键对白、揭示 |
| 拉镜(dolly out) | 揭示环境、释放情绪 | 场景开场、结局收尾 |
| 左摇/右摇(pan) | 展示空间、跟随移动 | 环境展示、双人间视线转移 |
| 上摇/下摇(tilt) | 角色登场、垂直空间 | 人物出场（从脚到头）、建筑 |
| 环绕(orbit) | 立体展示、视觉冲击 | 角色亮相、对峙 |
| 跟拍(tracking shot) | 沉浸感、动作连贯 | 走路、离场、追逐 |
| 固定(fixed) | 纪实感、突出对话 | 对话场景、静默拍 |
| 手持(handheld) | 临场真实感 | 紧张场面、纪实风 |

## 二、高级运镜（一集 ≤2 处，用在爆点）

| 写法 | 效果 |
|---|---|
| 希区柯克变焦(dolly zoom) | 空间扭曲、认知崩塌瞬间 |
| 一镜到底(one-take) | 全程不切镜 |
| 荷兰角(dutch angle) | 不安/紧张 |
| 升格慢动作(slow motion) | 关键瞬间仪式感（耳光/摔杯） |
| 甩镜(whip pan) | 快速转场、紧张（C级衔接常用） |
| 移焦(rack focus) | 焦点前后景转移（人脸→道具） |
| 低角度仰拍 | 英雄感、压迫感 |
| 第一人称主观视角(POV) | 代入感 |

## 三、景别（全景/远景禁用，Y4）

| 景别 | 范围 | 短剧用途 |
|---|---|---|
| 中景 | 腰部以上 | **默认档·全部对话与叙事主力（含定场、群像反应）** |
| 中近景 | 头肩 | **默认档·对话、情绪铺垫** |
| 面部特写 | 人脸充满画面 | 仅打脸/情绪顶点 |
| 极致特写 | 眼/嘴/手/道具 | 仅爆点关键道具、产品展示 |

对白密集单元运镜保守（固定/缓推/移焦）；纯画面单元可上跟拍/环绕/甩镜。

## 三点五、机位语法与景别切换（对话戏/独白戏必读）

> 核心：**机位和景别的切换要有语法，不是随机换着玩。**（调研沉淀＋04集"红毯吸附"教训）

**1. 对话戏骨架：正反打 + 轴线**
- 双人对话 = 主镜头（中景交代空间站位）+ 正反打来回切，说话方触发切换；**过肩与非过肩对白镜头的安排按 Y21**，禁把对话戏写成一串单人正面朝镜头的独白镜
- **180度轴线规则**：机位全程待在两人连线同一侧——A 永远画面左、B 永远画面右。写法：正反打单元显式声明「机位保持在同一侧，A在画面左、B在画面右，保持视线方向一致，不越轴」
- 需要换侧时用**中性镜头**（正对人物正面/正背面的机位）过渡一拍，不许硬跳
- **门口/柜台/车窗两侧的对话**同属双人对话：机位固定界线一侧同轴正反打，禁分割线构图——细则唯一出处= 分镜自查检验.md §十二 F27

**2. 30度规则（防跳帧感）**
同一主体相邻两镜，机位角度变化 ≥30度；默认中景下防跳切主要靠机位角度差，不靠换景别凑数。

**3. 景别默认策略（Y4）**
- **默认区间：中景～中近景**（腰部以上～头肩），全单元、全部镜头非例外一律锁在此区间；单元首镜定场用中景＋环境细节交代空间，三人以上群像反应也用中景（同屏≤3人是硬规则5，装不下的归画外/虚化肩背）
- 例外仅三种：①打脸/反转/情绪顶点格：面部特写＋权力机位仰俯拍（Y14，往近）②带货产品展示：产品特写（包装文字需清晰，往近）③灾难/大场面基调单元：1–2 镜全景表现毁灭规模（往远，总表登记＋成片重点验收，配方与风险对价见 §八）
- 景别递进（由远到近推情绪）为可选进阶技巧，不作要求——情绪表达由表演三件套（F20）＋光影＋声音标注承载

**4. 单人长台词（≥2句/8秒的独白、口播、说教戏）**
允许全程一个景别到底。同轴推近 punch-in（机位轴线不变、只微收景别，口播首选最保口型）与走位跟拍可选不强制；**场内有听者时，听者反应插入 1 拍为必做（Y21③）**——无听者的真独白/口播才允许全程单人。

**5. 竖屏（9:16）铁律**
- 景别以中景/中近/特写为主，人脸占画面 1/3–1/2；人物居中偏上构图；运动方向优先纵深不优先左右
- 节奏约 2–3 秒一个镜头视觉变化（单元内=镜头切分或 punch-in）；切换要有逻辑，禁为炫技乱切

**6. 三人对话套路**
- 骨架：主镜头群像（中景）先交代三人站位——每人"站/坐+面朝谁"逐一写（F12）→ 把**当前说话的两人**当一组按 Y2 正反打 → 第三人不接话时插**反应拍**（中近景一镜）保在场感
- **正反打镜内双人闭合（2026-07-26 裁定）**：正反打每一镜正文只写说话双方，第三人**不点名不入画**——在场感靠定场镜＋反应拍承担；必须同框时写全状态锁，细则见 分镜写作法则.md §五2.5
- 轴线以**当前对话两人的连线**为准锁同侧；对话组切换（A↔B 换 A↔C）先回群像过渡一拍再进新正反打；第四人只闻声或归入"众人"群像

**7. 对话感三件套（Y21）**

反例一行：全片写成单人正面镜串（对手不入画、视线无落点、无反应拍）＝独白拼接（36集）。单主体（F26）管"谁露正脸和嘴"，不等于"画面里只许有一个人"。

- ①**过肩构图**：过肩对白镜采用中近景，前景留对手不露嘴的虚化肩背；过肩镜头占本对话单元总镜头数的 **20%～30%**，其余镜头按剧情需要安排，可采用配合剧情的动作、反应、物件画面，也可采用只拍说话人、不带对手肩背的非过肩对白镜头。**6镜单元允许2镜过肩（约33.3%），作为整数取镜的例外**。「单人正面朝镜头」只留三种场合：口播带货、全集末看镜头互动、场内无听者的真独白；只拍说话人不等于让角色直视镜头讲话。（2026-09-16 用户调整）
  **过肩镜是视频生成模型的公认弱项（2026-08-05 外部交叉验证：OTS 构图正确率评测低至 0.13）——典型翻车＝前景肩背者被画成完整人物或克隆入画。改良写法四件套（写过肩镜必须全带）**：①机位句按 **F23 的画内人物相对方位写法**，不以场景道具锚定机位；②前景者写明**哪侧肩背＋遮挡范围**（"A的左肩背虚化占画面左下角约三分之一，不露脸不转身"）；③封口句把前景者计入名单（"画面中只有A的虚化肩背与B"）；④人物挂载单元带官方反克隆句（T16）。**同一单元过肩镜翻车 1 次即降级该镜为单人镜＋视线衔接（F26、下项②），不恋战；因此降级修复时允许过肩比例低于上述下限**。
- ②**视线衔接**：对手在画内时，写明说话人目光的**人名落点**，统一写「目光落在[人名]身上」，禁写「前景[人名]方向」或用画面左右侧代替人名；对手在画外时，按 **F25 禁四**写方向或「镜头外某人」，不在视线句中写画外人物姓名。前后镜头保持对话朝向与视线衔接。
- ③**反应拍定量**：双人以上对话单元每单元至少 1 拍听者反应（可并入镜头内一笔带过或独立反应镜）；刺痛词落点单元强制走 Y12——说者转画外原声＋听者单人反应镜（写明「X的画外原声继续说」）。剧本层供的刺痛词（6-分镜契合 §3）就是给这拍反应供弹的。

## 四、光影方案（写法：光源方向+色温感知描述）

> **光源与调性（2026-09-18 用户裁定）**：全剧视觉调性沿用本集 `资产提示词.md`，选定规则唯一出处＝`../../zichan/知识/风格预设.md`。光源写清方向、冷暖和场景依据（窗光、顶灯、台灯、路灯等，可在画外）；可用反射补光、侧光或轮廓光塑造层次，效果须与场景光源关系相容。

### 4.0 按本剧调性安排光色（Y20，全流程适用）

冷暖、明暗与对比由本剧调性和当前场戏决定，不统一套明亮低对比。把画面要求写具体：

- **光线与明暗**：明确主光方向及明暗过渡，按剧情保留亮部与暗部层次；夜戏可有夜色，悬疑可用局部光和较高对比，承担表演的人脸、动作与关键道具仍应看清。
- **肤质与色彩**：肤色与皮肤纹理真实，柔光不等于磨皮；环境冷暖、饱和度随本剧调性，避免让统一色罩淹没肤色和材质差异。
- **焦点与空间**：按本镜叙事主体安排焦点和景深；需要看清人物关系或道具时保留相关景层，不把电影质感等同于每镜背景虚化。
- **同场连续**：同场同时间保持光源位置与基础光色一致；场戏转换或剧情内光源变化时再调整，不随正反打重新布置互相矛盾的光线。

场景句式示例（按本剧改写，同场延续时沿用光源关系）：
> **温暖日戏**：柔和窗光从左侧照入，墙面反射光承接人物暗侧；高光柔暖，肤色自然，表情清楚，衣料与旧木桌保留细腻纹理。
>
> **冷调夜间对峙**：办公室环境偏冷，桌面台灯从人物侧前方照亮面部，窗外城市灯光留在后景；脸部明暗有层次，眼神与桌上文件清楚，背景较暗，肤色自然。

**词语按场景使用**：电影质感、暗调、高对比、轮廓光不再列为禁词；使用时写出具体光源和画面效果，不只堆风格标签。颗粒、光晕、怀旧色偏按选定风格需要使用，不作为电影质感的固定套件。

**适用范围**：资产场景图、分镜光影句与封面；人物设定图保留资产规范的均匀光以明确身份。成图审核与修复沿用生产线总则，不另加暗调验收关卡。

### 4.1 情绪光影方案（在本剧调性内选用，不是题材固定配方）

| 情绪 | 可用写法 |
|---|---|
| **温馨治愈** | 暖窗光与墙面反射光形成柔和过渡，人物与环境色彩协调 |
| **浪漫梦幻** | 黄昏暖金阳光与室内柔和反射光呼应，按场景保留柔亮高光 |
| **对峙冲突** | 有方向的侧光拉开人物与背景，冷暖、对比随当前权力关系和环境安排 |
| **悬疑紧张** | 局部灯光照出眼神或线索，房间边缘进入阴影，保留叙事所需细节 |
| **悲情揭示** | 窗光或台灯收束到表情，环境色彩适度收敛，不固定把悲情拍暗 |

光影强度随故事推进；暗调不设每集次数配额。切镜、表演、声音和运镜仍按 §八 当前情绪基调执行，不因采用电影质感统一放慢节奏。

## 七、镜头叙事语法（/fenjing 排镜必过）

> 总原则=P-43：**镜头叙事优先于机械的"谁说话拍谁"，但分镜阶段不得以镜头为由删改已确认台词**。

**1（Y10）每镜叙事问——总纲**
排每一镜先问"这一镜画面在讲什么"，答案不能是"轮到他说这句了"。已确认台词逐字保留，通过画外音、听者反应、POV、插入格、权力构图和镜头间重新分配来增强叙事。台词偏少时按台词时长估算.md 重切合并或登记欠载；情绪动作、反应、走位、道具动作或非台词职能画面只与台词并行，不单独补时；不得新增剧情，不得用无意义停顿、慢动作、重复反应或空镜拖时（T1/P-44）。

**2（Y11）Look–POV–Reaction 三镜链**
角色发现信息/物品/他人行为时的标准排法：镜N=角色看向画外（眼神+头部转向）→镜N+1=主观视角拍被看对象（POV，无人物入画但有归属，P-42）→镜N+2=回到角色面部反应。因果全靠画面顺序，零台词。边界（P-46）：只用于"发现/注视"类**交代性信息**；爆点、审判、反转的主体承载仍是台词。

**3（Y12）反应镜头优先律＋库里肖夫组接（刺痛词落点单元强制执行）**
冲突/爆点单元的情绪落点给**听者**：动作/狠话格后立刻切听者特写（僵住/别脸/攥拳），说者可只给半句+画外音——观众的代入落点是反应不是动作。库里肖夫效应反向可用：同一张面部特写，前面接不同的插入格（冷脸/账单/合影），含义完全不同——设计反应格时先设计"他刚看到了什么"。

**4（Y13）插入镜头与物件三次法则**
要观众记住的道具走三次法则：**埋**（首次特写入画）→**提醒**（中段扫过/再看一眼）→**兑现**（高潮用它触发动作）——三次跨单元分布，写进状态追踪表。插入格三段式运镜：微推近景→焦点转移至物品→急停定格；情感信物=物品特写→缓慢升起至人物表情。每个道具特写必须有视线归属（P-42）。

**5（Y14）权力机位语法——爽剧核心武器**
强弱势的画面表达：按当下谁在施压、谁在承受、谁在夺回主动权设计，不把善恶身份固定等同于强弱。施压者可用身体前压、占据空间或控制回应节奏；受压者可保护自身物品、稳住位置或争取发言；反击时拍清拒绝、争取或保护的动作变化。先确定人物动作、双方距离与主动权变化，再选机位：**强势可用低机位、较大占画；受压可用较高机位或受挤压的构图；反转时随主动权转移调整角度、占画与位置**。画面须拍清主动作的相关部位及落点，镜头移动服从动作；固定镜头也可借人物前压或退缩表达压力。对"强压迫→当众打脸"剧型，关键转折需让观众看见权力变化，不要求每句都换角度或加大动作。

**6（Y15）竖屏双人调度：纵深不横向**
三个替代方案：①**前后景堆叠**——一人前景占下1/3（大）、另一人纵深处（小），大小对比替代左右对比，视线走对角线；②**前景框架**——门框/窗棂/衣架做前景遮挡分层，天然适合偷听/窥探桥段；③**纵深走位**——"由后走向前"替代"从左走到右"。对峙戏用镜像对称：A/B 正面近景交替、构图对称（同占画面中部1/2）。

**7（Y16）首尾格设计**
换场段落首格=定场/进场拍（接 P-39；定场用中景+环境细节）。单元末格优先**动作收尾**：摔杯/转身/锁门/攥紧——动作即句读（仅指收尾那一格；爆点/审判主体仍由台词承载，P-46）。相邻格保持**视觉焦点接续**（eye-trace）：上一格视觉重心在哪个位置，下一格新信息放同一位置。情绪激烈↔平静的边界直接硬切，落差本身就是转场。

**8（Y17）静默拍**
静默拍=**人在场的沉默**——人物静止但有微动作（呼吸起伏/手指微颤/喉结滚动），镜头对着人，不是空镜（与 P-37 兼容）。**静默不占时（2026-08-06 裁定，动作占时作废）**：只允许两种形态——①听者沉默画面＋说话人画外原声并行（J-cut）②峰值重音定格 ≤1 秒；成镜成段的纯静默禁止。开场钩子可用冲突动作特写三格组：冲突动作特写（只拍手部+受力）→宣战台词+面部→情绪特写。

**9（Y18）Murch 情绪优先律——刻意破轴的许可证**
剪辑取舍权重：**情绪 > 故事 > 节奏 > 眼球轨迹 > 轴线 > 三维连续性**。默认仍按 Y2 锁轴，但全集允许 1–2 处**刻意破轴**——仅用于失控/背叛/认知崩塌的爆点格，破轴本身制造"世界失序"的不安感。一集超 2 处即违规。

**10（Y19）主镜头先行**
排单元镜头前，先想象这段戏的完整**主镜头**（master shot：一镜能覆盖全部空间信息的机位），再把各镜头拆成主镜头的局部特写——镜头与镜头的空间关系天然不穿帮。

（本节来源：StudioBinder/Katz/Arijon/Murch＋竖屏实战文三路调研交叉去重，2026-07-17。）

**2. 增补授权与判据**：为让单元质感贴合标注基调，允许在台词之外**增补/调整**——反应拍、微动作、环境小动作、音效、镜头行为、句间节奏，但**增补一律与台词并行、不单独占用画面时间（2026-08-06 裁定：动作占时作废，单元容量唯一计价物＝台词）**。判据一句话：**把这个增补删掉，段落情绪掉不掉档——会掉才有资格加**。红线不变：台词逐字锁定、不新增剧情信息、不无意义拖时。
**增补动作默认压在台词进行时里同时发生（2026-08-05 用户纠正，T26.4 同源）**：环境事件、他人反应优先安排在某句台词的话音进行中（"话音进行中，画面深处的X已闻声回头"），禁写成"说完一句→放一段哑剧"的串行链；纯哑剧镜仍受静默拍全剧 3–5 处限额，单镜篇幅压到两三句（案例一行：56集开场v2动作链扩成大段零台词镜，v3 压回台词进行时）。
