# 台词时长估算（容量规划用）

> 定位：/fenjing 切单元与台词密度核验的估算方法（2026-07-25 用户裁定引入，取代"字/秒×占比"旧换算与固定字数线）。结果只进分镜总表与生成参数行，**任何秒数、时间码都不得写进单元提示词正文**（T 系列规则照旧）。这是容量估算，不是声学定律；首批跑片后必须按角色实测语速校准（见文末）。

## 核心机制：宁紧勿松

生成参数按所选档位固定 **15秒或30秒**（选档唯一规则见生产线总则2）；下文 D 为选定秒数。台词与停顿按下文音节公式估算，动作与台词并行，不另计装填时间。

| 单元类型 | 15秒档初始装填估算 | 30秒档初始装填估算 | 处置 |
|---|---|---|---|
| 普通对白、稳定口播 | 16–17秒自然台词；下限15秒 | 32–34秒自然台词；下限30秒 | 约107–113%的装填比例；最终以音节与停顿公式为准，不按字数凑词 |
| 稳定语速的纯对白加档 | 17–18秒 | 34–36秒 | 总表登记，后期恢复倍速按D÷自然秒数估算 |
| 高风险（复杂手部/商品操作、奔跑、车辆、爆发哭戏、多人抢话） | 按14秒装填，禁止超载 | 按28秒装填，禁止超载 | 约14/15的装填比例；不把动作单独加进容量 |

**证据边界**：两档数字沿用既有装填比例，30秒由15秒比例换算，均是初始规划估算，不是当前通道/模型的实测结论；换通道或模型后按宪法14.5重新校准，不凭此声称提速、口型或动作质量已验证。总时长改变不意味语速加倍，也不允许扩写已确认台词凑字数。

历史记录仅供对照：2026-07-25第20集重切曾将72–77字（自然内容16.6–17.7秒）装入15秒容器，4个单元一次生成成功；原记录未完整标明测试通道/模型，按宪法14.5只作待复验经验，不外推为30秒保证。

## 音节计数

- 按实际发音的普通话音节数 `N` 计：一个汉字约一个音节，标点不计。
- 数字、金额、日期、英文缩写先展开成读法再数（"3000"＝"三千"＝2 音节）。
- 叠词、结巴、哭腔断句、被打断的残句按实际要说出的音节计。

## 公式

```text
T台词 = N ÷ (5.3 × K表达 × K人物状态) + 各项停顿
T单元装填 = ΣT台词   （停顿预算已计入T台词，不再重复加动作/反应/首尾稳定）
生成设置 = D秒（15或30）；各类装填目标见上表（初始估算，待当前模型实测校准）
```

基准 **5.3 音节/秒**——短剧紧凑基准（日常对话约 5.0，短剧观众期待明显快于日常）。**动作不计时（2026-08-06 用户裁定，"给动作留时间"作废）**：动作一律与台词并行（边说边做、边听边做），不得单独占用画面时间；单元容量的唯一计价物＝台词音节＋停顿预算。

## K表达（按说话行为选，不按情绪标签）

| 表达策略 | 系数 |
|---|---:|
| 自然回答、日常交流 | 1.00-1.10 |
| 干脆回应、抢断、急促反驳 | 1.10-1.20 |
| 连续证据链、带压迫的指责 | 1.05-1.15 |
| 冷静施压、威胁、审问（高压≠快） | 0.90-1.00 |
| 安抚、劝说、温柔说明 | 0.90-1.00 |
| 震惊后的第一句（另加起始停顿） | 0.85-0.95 |
| 悲伤、自责、悔恨 | 0.80-0.90 |
| 哭腔、疼痛、气息不稳（另加换气） | 0.70-0.85 |
| 恐慌呼救、紧急催促 | 1.10-1.20 |
| 产品说明、清楚口播 | 1.00-1.10 |

## K人物状态

健康成年 1.00-1.05；儿童清晰童声 0.90-1.00；老年身体稳定 0.85-0.95；疼痛气短 0.75-0.90；哭泣哽咽 0.70-0.85。多种不利状态取最主要的一个，其余用停顿补，不连乘。慢速是**有剧情动机角色的例外**，不是默认。

## 停顿预算（从紧给，标点不自动产生停顿）

| 类型 | 秒 |
|---|---:|
| 普通逗号/轻语义边界 | 0.10-0.15 |
| 完整句结束 | 0.15-0.30 |
| 省略号、犹豫、欲言又止（有剧情动机才给） | 0.30-0.60 |
| 说话人切换（正常接话） | 0.10-0.25 |
| 说话人切换（抢话、顶嘴、紧接） | 0 |
| 震惊/意识到真相的起始停顿（只给真反转） | 0.30-0.50 |
| 哭腔/短促换气（每次） | 0.25-0.50 |
| 关键落点反应（每段最多 1-2 处，普通轮次为 0，反应与下一句台词并行） | 0.30-0.50 |
| 建立时间（仅单元首镜关系镜；切单人镜硬切不占时） | 0.30-0.50 |
| 单元首/尾稳定 | 各 0.20-0.30 |

普通对白轮次的倾听反应**不单独占时**——下一人开口时上一人的反应仍在画面里进行（J-cut 思维），只有宣判、揭秘这类关键落点才专门留反应时间。

## 超载与融合判定

- 普通对白与稳定口播按上表所选时长档估算；允许的加档须在分镜总表登记后期恢复倍速（D÷自然秒数），不将速查字数作为硬性凑词线。
- 高风险单元（复杂操作/奔跑/车辆/爆发哭戏/多人抢话）：15秒档按14秒、30秒档按28秒初始估算装填，禁止超载。
- 普通单元低于所选D秒（高风险单元：15秒档低于14秒、30秒档低于28秒）先做相邻融合审查：第一优先同场同时间（合并后仍固定所选D秒、挂载≤9张，镜数按提示词规范 T26）；仍不足允许**跨叙事切点合并**（单元内硬切分段、双场景图都挂载、总表风险标注列登记，2026-08-11 裁定，取代"停下报告回剧本层补台词"）；穷尽合并仍欠载＝**宁欠载禁加词（逐字锁定 > 装填下限，执行者不得自行新增/扩写台词）**，总表登记欠载、后期加速兜底（例外仅带货产品展示与剧本层无台词闪回场）——**禁止拿无台词动作/反应/静默镜垫满（2026-08-06 裁定）**。

## 后期节奏兜底

- 成片偏快：0.90-0.95x 放慢还原，无损。
- 成片仍偏慢：1.05-1.20x 加速——短剧观众无感，矩阵成片的常规操作；加速后注意音调是否自然。
- 优先靠装填量控节奏，后期倍速只是兜底，不能救镜头内的长死气。

## 首批校准（必做）

首批成片出来后，选 2–3 段听感正常的：数出实际说出的音节数 ÷ 实际说话时长（去掉停顿）＝该角色实测语速。用实测值替换 5.3 基准，主要角色各记一行，写进该集分镜提示词.md 的分镜总表附注。此后该集一律用实测值估算。
