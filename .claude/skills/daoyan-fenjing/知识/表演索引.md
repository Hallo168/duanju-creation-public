# 表演参考索引

取用方法唯一出处：[导演思维·表演索引如何用](导演思维.md#表演索引如何用)。先按本场问题从A或B进入，只读有关小节；每条合写**情境／面部与目光／身体动作候选／整句声音／画面落点**。按人设、关系、现场持物与对方回应改写后，落实到最终提示词，不把几个索引分别读完再拼。

| 入口 | 何时用 | 读取位置 |
|---|---|---|
| A 行为场面 | 求救、催促、争取、反击、安慰等要对人做什么 | [A-表达行为](表演/A-表达行为.md)，从相应行直达脸、动作、声音、画面合写的参考 |
| B 情绪反应 | 区分开心、担忧、羞怒、得意等细分表现 | [B-情绪反应](表演/B-情绪反应.md)，从相应行进入组合参考 |
| D 复合变化 | 原戏确有并存、转换、强忍或掩饰 | [D-复合变化](表演/D-复合变化.md)，按实际关系取组合 |
| 平淡与倾听 | 正常说明、安静听人说话也要有具体表演 | [平淡与日常](情绪表演参考.md#平淡与日常) |
| C 表现细节补查 | 选好情境后还需调整动作力度、路径、速度或发声形式 | [C-表现方式](表演/C-表现方式.md)，只补有关部分 |
| 说者与听者的脸 | 确定可见表演主体与幅度 | [面部覆盖与说听两种演法](导演思维.md#每个人物对话镜都落实面部表演) |
| 声音身份与接话 | 首开口声线、停连、打断或改口 | [声音与断句](情绪表演参考.md#声音与断句)、[接话专项](表演/声音表现参考.md#断句与接话) |
| 易错发音 | 实际出现专有词、歧义读音或同词发音失败 | [专有词与易错发音](情绪表演参考.md#专有词与易错发音) |
| 来源 | 核对可复用线索与本项目改写的区别 | [资料来源](表演/资料来源.md) |

详细参考留在对应小节；索引不展开全库。编号不写进生成提示词，不要求每场凑齐A/B/C/D；已有合适表演可保留，无合适参考时直接从本场行动设计。
