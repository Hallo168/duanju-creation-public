# 即梦格式（Seedance）

仅在选择即梦格式时读取。导演、节奏、容量、连续性和无BGM要求仍按共用的 `提示词规范.md`；本文中的 T 编号回指该文件。以下沿用原即梦格式，不将符号写法视为台词逐字准确的保证。

官方依据：[Seedance 2.0 提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh)、[Seedance 2.5 提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)。现有项目默认用镜头序号，不写时间码；这是本项目格式选择，Seedance 2.5 官方也支持时间戳。

## 一、单元提示词结构

```
〖素材声明〗（官方一致性三件套）
将<图片1>中的[2-3个静态特征]定义为主体1（角色名）；
主体1的面部特征参考图片1（大头照），妆造参考图片2（全身照）；
图片3作为场景基准，直接使用该环境。

〖镜头1〗每镜按官方四要素顺序：
运镜/切换方式 → 说者或听者的面部表现与动作 → 空间位置 → 整句声音演法及台词
〖镜头2〗…
〖镜头3〗…

〖全局收尾〗风格锚点 + 约束句 +（需衔接时）尾帧定格句
```

**素材声明规则**：
- 素材声明层绑定上传顺序中的图片与角色，后续镜头用角色名，不在镜头正文反复写 `@图片N`；文件与编号仍对应单元挂载清单。
- 【官方】主体定义句式：`将<图片N>中的[主体核心特征]定义为<主体N>`，用 2–3 个静态特征
- 【官方】顺序即权重：越需要精准参考的素材，放提示词中越靠前
- 【官方】人脸大头照与全身照分开引用（面部特征 vs 妆造）——**本项目按 2026-08-05 用户裁定改用单张竖版双格设定图（上格大头＋下格全身）整图挂载**，一人一个挂载位、必配 T16 反克隆句；官方两张分挂降为克隆翻车时的降级选项。**人物四格/宫格素材仍全面禁用**——官方"双胞胎问题"章节：多视图易被识别为多个主体、同画面生成克隆人（生产链见 资产生产规范 §一）
- **禁止**任何"（外观权重N%）"百分比写法——非官方语法，已证伪
- 每个引用必须说明用途；"参考"一词触发引用模式；视频编辑用"严格编辑"、延伸用"向前/向后延伸"
- **禁写解释性/元叙述句**（2026-07 用户裁定）：不给模型"讲课"——"图中四格为同一人""四镜正反打快速对答衔接紧凑"这类解释画面结构或导演意图的句子一律删除，即梦能自动识别人物设定图/多视角图；提示词里只留画面和声音的直接指令，每个字都要换成像素

## 二、台词与声音符号

| 内容 | 符号 | 示例 |
|---|---|---|
| 台词 | `{}` | `苏晚（压着火追问，起句音量低，说到“自己”时声线骤然抬高）{亲子鉴定。你自己看。}` |
| 音效 | `<>` | `<文件拍桌闷响>` |
| 音乐 | `（）` | `（低沉弦乐渐起）`——一般不用，BGM后置剪映 |
| 字幕 | `【】` | 一般不用（约束句声明"「生成视频不要出现任何字幕」"） |

- 整句情绪演法与可听变化写在 `{}` **外**的圆括号里；`{}` 内只放台词原文，不只标重音/短收。每个人物对话镜都在画面句写说者或听者的具体面部表现，允许平淡；画内/画外口型归属按提示词规范§〇，不冻结听者嘴部
- 台词按自然说话节奏断句；停连与重音按本目录《情绪表演参考》“声音与断句”执行
- 需要专有词发音指导时，仍放角色括号内，不改台词正文；按同文件“专有词与易错发音”执行

## 三、镜头切分

- 只用"镜头1/镜头2/镜头3"标签，按事件顺序组织
- 项目默认不写精确时间段（如“0–5秒”）；转换已有带时间码的万相稿时，将原时间预算留在总表，不改变单元时长或镜头顺序。
- 不为单镜强制指定秒数；总时长靠生成参数（UI）控制
- 单元时长标识（按所选15秒或30秒档，历史稿沿原参数）只写在单元标题、分镜总表与生成参数行；镜头正文只写动作顺序与表演过程，**不写“0–5秒”这类精确时间码**
- 例外：视频延长（"将@视频1延长5秒"，生成时长选新增部分）、音乐卡点任务可用时间锚点，接受抽卡风险

## 四、历史写法示范（旧15秒，仅参考声画写法；不继承旧装填数字与景别配额）

```
将<图片1>中的黑色低马尾、米白西装的女性定义为主体1（苏晚）；苏晚的面部
特征参考图片1（大头照），妆造参考图片2（全身照）。将<图片3>中的剑眉方脸、
深灰三件套西装的男性定义为主体2（陆承），面部参考图片3。图片4作为深夜
总裁办公室场景基准，直接使用该环境。

镜头1：固定镜头(fixed)，中景。苏晚：28岁女性，鹅蛋脸，黑色低马尾，米白
色西装套装，左腕细银手镯。陆承：32岁男性，剑眉方脸，右眉尾一道浅疤，深
灰色三件套西装。苏晚立于桌前，陆承坐于桌后，两人隔桌相对。苏晚将牛皮纸
文件袋从胸前向桌面拍下，手掌压住文件；眉间明显向下收拢，嘴唇先抿紧一下，开口时下颚向前顶，眼睛看住陆承。
苏晚（压着火追问，起句音量低，说到“自己”时声线骤然抬高）{亲子鉴定。你自己看。}<文件拍桌闷响>

镜头2：缓慢推镜(push in)，过肩中近景，越过苏晚右肩拍陆承（右眉浅疤，深灰
西装）。听见“亲子鉴定”时，陆承眉毛抬高、眼睛睁大，嘴张开一下；身体紧接着从椅上前倾站起，椅子向后滑出，双手撑住桌沿，开口时眉间收拢，目光从文件移到苏晚脸上。
陆承（急着留住对方、带着慌张辩白，称呼先抢出来，后半句赶着解释）{晚晚，你听我解释，不是——}苏晚的画外原声（受伤的控诉，突然提高音量截住他，称呼处带出颤音）{三年了，陆承。}陆承听到“三年”时嘴唇合住、眉头内侧抬起，不替苏晚对口型。<椅腿刮地声>

镜头3：苏晚面部特写（鹅蛋脸，黑色低马尾），先固定，再移焦(rack focus)。眉头内侧抬起并向中间挤拢，眼泪越过下眼睑滑到颧骨；下唇颤了一下，开口时抬眼看向画外右侧，说完才把目光落到桌上文件。
苏晚（忍哭后的哑声，轻声但明确地结束这场争辩，第一句气息发颤，后一句用连贯气息说完）{不用了。到此为止。}她话落后，焦点才从面部移到桌上文件。<环境音骤然收静，只剩挂钟秒针声>

深夜办公室环境偏冷，桌面台灯从侧前方照亮两人面部，窗外城市灯光留在后景，
脸部明暗有层次，眼神与桌上文件清楚。真人都市电影质感，环境偏冷、肤色自然，
清晰光影层次，材质真实，色彩干净克制。保持参考图中同一人物的身份与服装款式，眉眼和嘴部按镜头表演变化。
全程不要生成背景音乐（BGM），仅生成人物对白和提示词明确指定的动作音效。「生成视频不要出现任何字幕」，不生成水印。结束构图：桌上文件清晰，苏晚留在后景，嘴角收平，泪痕仍在，视线落在文件上。
```
