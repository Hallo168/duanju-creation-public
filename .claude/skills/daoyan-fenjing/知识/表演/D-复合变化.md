# D｜复合表现与变化索引

本页定位四种复合关系，按原戏选择，不给角色自动添加隐藏情绪。

| 编号 | 大类 | 小类索引 |
|---|---|---|
| D01 | 同时存在 | 喜与悲／喜与怒／喜与羞／怒与怕／怒与委屈／感激与愧疚／欣慰与担忧／不舍与怨怒／得意与心虚 |
| D02 | 前后转变 | 喜转惊／惊转喜／怒转愕／怕转怒／期待转失落／委屈转反击／强硬转求饶／慌乱转镇定／冷淡转动容 |
| D03 | 强行压住 | 忍笑／忍泪／压怒／压慌／忍痛／想喊却压回／话涌上来又咽回／硬撑到失控 |
| D04 | 对外掩饰 | 强颜欢笑／赔笑压怒／故作镇定／佯装无辜／假装惊讶／假装亲热／冷脸藏不舍／装轻松掩疲惫 |

具体演法只读[复合表现](../情绪表演参考.md#复合表现)对应行，同看面部、身体、声音与画面；并存可分由不同通道承担，转变须写清触发前后。用眉眼、嘴部、目光与动作的实际变化表达，不把“眼睛悲伤、嘴巴开心”当成已经具体化。并存、转换、压住和掩饰可以交叉，但不预设每场都要复合。

动态复合表达研究依据见[资料来源S7](资料来源.md)。以上组合是导演整理候选，不能直接当成已验证的面部拼接公式。
