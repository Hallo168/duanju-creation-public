| 入口 | 来源 | 取用范围 |
|---|---|---|
| 怒 | [Anger](https://writershelpingwriters.net/2008/01/emotion-thesaurus-anger/) | 同一情绪既有外放也有控制住的发声；用于怒的不同演法 |
| 受阻、挫败 | [Frustration](https://writershelpingwriters.net/2008/07/emotion-thesaurus-entry-frustration/) | 动作受阻、失准与压住的发声；改成现场已有任务的变化 |
| 愤慨 | [Indignation](https://writershelpingwriters.net/2008/05/emotion-thesaurus-entry-indignation/) | 受冒犯后的打断、否认与身体反应；不等同中文“义愤”的全部含义 |
| 怨怒 | [Resentment](https://writershelpingwriters.net/2008/09/emotion-thesaurus-entry-resentment/) | 抵触与拒绝回应的外部线索；不照搬源文中的特定人物行为 |
| 等不及 | [Impatience](https://writershelpingwriters.net/2008/08/emotion-thesaurus-entry-impatience/) | 等待中注意转移、动作改换和短促回答；用于急切与焦躁 |
| 求助无门 | [Desperation](https://writershelpingwriters.net/2008/10/emotion-thesarus-entry-desperation/) | 请求、发声受阻与寻求他人回应；不凭参考添加违法或危险剧情 |
| 释然 | [Relief](https://writershelpingwriters.net/2008/01/emotion-thesaurus-relief/) | 紧绷后的放松、呼气与重新靠近；需有前面的担忧 |
| 喜悦 | [Happiness/Joy](https://writershelpingwriters.net/2008/02/emotion-thesaurus-entry-happinessjoy/) | 本轮重读公开正文，取分享、接近、轻快步态和说话加速的候选；不规定所有喜悦都大笑或拥抱 |
| 担忧 | [Worry](https://writershelpingwriters.net/2008/11/emotion-thesaurus-worry/) | 本轮已读公开正文，取等待中身体难以安定、留在消息来源附近等线索；实际探身、走到门边或坐回的组合为本项目改写，不移植长期症状 |
| 歉疚 | [Guilt](https://writershelpingwriters.net/2008/05/emotion-thesaurus-entry-guilt/) | 本轮已读公开正文，取向受伤者寻求回应、局促动作和急切道歉的线索；递物、修复与手的收回按原戏拟写，不照搬自伤等极端行为 |
| 悲伤 | [Sadness/Grief](https://writershelpingwriters.net/2008/02/emotion-thesaurus-sadnessgrief/) | 本轮已读公开正文，公开样例多为身体感受及互动受阻，仅取哭泣、回应困难等短镜头可表现线索；扶物、支撑与收手不是该页现成清单 |
| 嫉妒 | [Jealousy](https://writershelpingwriters.net/2008/03/emotion-thesaurus-entry-jealousy/) | 针对关系对象的言行变化；不因套参考新增破坏或冲突 |
