## 〇、核心心法：提示词是写给 AI 的"意图对齐"，不是写给人的文学

**每写一句，先问自己一句："这句话，模型会把它渲染成什么画面？"**
- 拆解的目的只有一个：让 AI 正确理解你要什么。该展开的展开到"模型能画出来"（情绪、模糊动作），该收的收到"不引发多余联想"（会字面穿帮的冗余动作）。
- 判断标准不是"人读着够不够细"，是"AI 照着画会不会画对"。

**"写给摄影组，不是写给读者"三纪律**：
1. **像导演对摄影组下指令，不像小说家写场面**——"新人站在舞台中央红毯尽头"是给读者的画面感文学；给 AI 要拆成机位指令+站位指令+地标归属。一句里的每个名词都会变成像素
2. **不写的细节 AI 会自己编**（Sora 官方原话）——时间/天气/机位/站位不写，模型就用默认值随机填
3. **前置=高权重**——主体和关键约束放句子/段落开头

拆解有两个相反的病，对应 §一/§二 两个法则。

## 一、病A·欠锚定 → 状态转换三锚定法则

**症状**：角色中途改变"持续状态"（摘帽/换装/卸妆/受伤/湿身），提示词只写"改变的那个动作"，没锚定"改变后的持续状态"——模型倾向回归参考图默认状态，下一镜又变回去。根因：一句"摘帽"动作压不过一整张参考图的重力。

**法则——凡中途改变持续状态，必须三处同时锚定**：
1. **素材声明层**：一句话说清"哪张图是变化后的基准"——`将图片1中的戴帽男性定义为主体1（孟山河），孟山河摘帽后的面部参考图片2（无帽彩铅参考图）`
2. **约束尾**：显式声明变化后的持续状态——`孟山河摘帽前后为同一人面孔`
3. **后续每次提及主动带新状态标签，而不是只删旧状态词**：摘帽后简写写"孟山河（未带帽，方正脸鬓角微白，深灰夹克）"，单独提及写"孟山河（未带帽）"——显式负状态标签比"帽字消失"更稳；旧状态词仍禁止出现。湿→干写"（头发已干）"、撕破后写"（衣袖破口）"，同理。

案例一行：03集单元201 后厨摘帽按此三锚定重跑通过（完整原文见该集分镜提示词）。

## 二、病B·过度指定 → 动作意图精炼法则

**症状**：一个动作意图用两句写，后一句是多余的"显性子动作"，被模型字面渲染成穿帮画面。你写"拇指按下录制键"，模型必须表现"按录制"→把手机屏幕翻过来朝向镜头→穿帮。

**法则——一个意图，只写"足以让模型理解它"的那句，删掉会引发字面穿帮的冗余子动作**：
- ❌`慢慢从夹克兜里掏出手机，抬手把镜头对准大堂中央，拇指按下录制`
- ✅`慢慢从夹克兜里掏出手机，抬手把手机背面镜头对准大堂中央`

**常见"字面穿帮触发词"清单**（能用结果状态表达的，别写显性操作）：
| 别写（触发字面穿帮） | 改写（写结果/意图） |
|---|---|
| 按下录制键/点击拍摄 | 把手机背面镜头对准XX |
| 掏出手机看屏幕/解锁 | 低头看了一眼手机（屏内文字必崩） |
| 打字/回信息 | 手指在手机上飞快点了几下（不给屏幕特写） |
| 拨通电话/拨号 | 把手机贴到耳边 |
| 掏出/展示证件、文件上的字 | 把证件递过去（证件文字必崩，交剪映或不特写） |
| 屏幕上显示XX金额/文字 | 不写屏内内容，交剪映后期贴 |
| 把A垫上B/架在C上（多物体组合操作） | 无叙事意义直接删；有意义的写结果状态（04集实测垫砖→砖放到箱顶） |

**通用判据**：凡"屏幕内容、证件文字、招牌字、按钮操作"的显性动作——改成"结果状态"或"意图动作"，屏内文字一律交剪映。

**双面不对称道具的正反面（F15，07集相框穿帮固化）**：相框/照片/手机/证件这类"一面有内容、一面空白"的道具，不声明结构时 AI 会把两面都渲染成有内容。两步锁死：
1. **声明物理结构**：`木质相框，正面为照片人像加玻璃面、背面为空白深色硬纸背板和折叠支架`
2. **每一镜按"谁该看到正面"锁朝向**：人物端详/拿起看 → 背面朝镜头、内容面朝人物；让观众看清内容 → 正面朝镜头。逐镜写清"正面/背面朝向谁"。

## 三、该展开的要展开（欠拆解的反面）

模型画不出的抽象概念必须展开到"可渲染"：
- **情绪** → 身体部位动作+声音标注+标点（查情绪外化字典，不写"她很生气"写"下颚绷紧，牙关咬着挤出话"）
- **模糊动作** → 身体部位级+幅度+速度（不写"他慌了"写"手抖得解不开手机锁，反复划了两下没划开"）
- **抽象氛围** → 可见的物理细节（不写"气氛紧张"写"满堂霎时安静，只剩吊扇转动的嗡声"）
- **"快"** → 禁用"快速/fast"，用物理细节表达（"椅子被带得向后滑出半米"）

边界：展开到"模型能照着画出唯一画面"就停。

## 四、少即是多（flyne实测，降翻车率）

单个镜头锁定：**一个主体 + 一个主动作 + 一个运镜 + 一种光线**。动作越复杂，模型即兴发挥越多。
- 需要多动作时拆成多个镜头/单元
- 手部动作：让手在画面里占比大（远处小小的手必崩指）
- **道具交接是崩点（04集裁定）**：手到手的递/接/传手/塞回能免则免；无交接任务的手持物保留同一持有者，必须交接时单独一镜＋手部占画面大。此规避不限制同一承载面上由单人完成的物件移动、遮挡或按住；这些动作若承载本场拒绝、争取等交锋，按 F20 拍清过程，按状态表承接结果，不一律改成台词和眼神。
- **容量与生成（F8）**：模型可能将内容拉伸/压缩至D秒，需按通道验证。用清楚任务、表演和预算组织单元，不默认超额装填；吞词、口型或动作畸变时调整容量与切分，保留戏的关键变化。
- 要保留的文字/logo（如产品包装）：让它大、居中、约束"文字清晰不变形"；其余屏内文字一律不写
- 运镜指令独立成句，用标准影视语言

## 五、锁定句式库（L2 文字语义锁·每单元照此上锁）

> 前提：文字锁不住像素级空间态（见 连续性与状态管理.md 三层锁定模型）。本库是文字层的地板。

**1. 身份锚定块逐字重复（文字层影响一致性的单一最大因素）**
- 每角色一个身份块，**一字不改**：首次出场镜逐字贴全块，同单元后续镜用**固定措辞**的 2 锚点简写。**禁换措辞、禁代词**（"他/她/这老头"一律换回角色名）。
- 反→正：❌ 每单元换词"一位年轻女子／她／这位阿姨" ✅ 每次原样贴"兰姨：50岁中国女性，圆脸，花白短发……"，简写固定为"兰姨（花白短发，藏青围裙）"

**2. 空间站位锁定句（≥2人同框必写；单人也写坐/站+朝向）**
- 位于身份块后、动作前。三要素 **方位 + 姿势 + 朝向（面朝谁）** ＋ 负向锁 `位置全镜不互换、不融合`。
- 模板：`[A]在画面左侧，[站/坐]，面朝右方的[B]；[B]在画面右侧，[姿势]，面朝[A]。两人隔[桌/物]相对，位置全镜不互换。`

**2.5 对话镜双人闭合——不点名＝不入画，点名不锁全＝自由发挥（2026-07-26 裁定）**
- **机制（实测确认）**：镜头正文没点名的已挂载角色不会出现。翻车源头是反面：点了名却只给半句，背景人物是低权重区，姿态道具全靠自由发挥（案例一行：18集单元9"陈浩在后景桌角抬起脸"半句带过→生成成站在后景举酒杯）。
- **法则**：正反打/对话镜默认**只写说话双方，第三人不点名、不入画**。在场感三件套代替入画：①单元首镜定场交代全员站位 ②对话镜里动作指向画外（写"指向画面外"，禁写"指向后景某某"）＋台词点名 ③单独给反应镜。
- **例外**：剧情必须同框时，第三人必须**全状态锁**——坐/站＋位置＋手中道具＋"保持镜头N姿态不起身不移动"。要么清场，要么写死，禁半句带过。

**3. 机位/景别/运镜 与 姿势 与 动作 分三句写**
- `[景别]，[运镜]。[身份块/简写]，[当前姿势与朝向]。[单一主动作]。` 混一句=模型抓不准重点。

**4. 道具唯一规格锁定句**
- 可变道具给**唯一视觉规格**（材质+颜色+唯一标识细节）＋ 跨镜**措辞一字不改** ＋ `样式全片不变，不替换`。小配饰最易被丢，每镜重申。
- 反→正：❌`他拿着手机` ✅`他拿着那部进水手机（黑色直板、机身沾着一圈汤渍），样式全片不变`

**5. 持续态贯穿句（受影响区间每镜重述+负向锁）**
- 持续态（打翻的汤/湿身/乱桌）在区间内**每镜**重述 ＋ `不消失、不复原、不被清理`，区间结束才停。

**6. 场景锚定块逐字重复**
- 光影块 + 布局关键物每镜**逐字复用同一句**（场景图锁大布局，文字负责不改口径）。

**7. 多角色唯一标签、台词不用代词**
- `角色名（声音标注）{台词}`，主语永远是角色名，禁"他/她"跨句指代。

**7.5 地标吸附效应——位置句里的道具会把主体吸过去（F10，04集婚礼场实证）**
- **坑**：写"新人站在舞台中央红毯尽头"——主角被吸到红毯上站着。空间关系词信号弱，会被权重更高的具体道具词覆盖——**"地标+相对位置"复合定位是高风险模式**。
- **法则一·解耦**：主体位置句只写他真正站的地标；其余地标作为环境词单独放，不与人物位置词同句绑定。
- **法则二·通道独占**：通道类地标（红毯/楼梯/过道）只分配给真正走它的人，加独占锁（"只有曼曼一人在红毯上"）。
- **法则三·实测兜底**：文字解耦压不住时，改切分与构图规避（收紧景别、或该镜不带该地标）。
- **配套（典礼类标准机位）**：宾客视角（机位从宾客席后方朝舞台拍）；台上每人锁左右位；司仪钉在舞台边缘；约束尾"站位全片不互换"跨单元逐字复用。

**8. 主体安放点句——"挂载即入画"防御（F11）**
- **坑**：已定义的主体模型倾向尽早用上——某主体镜头3才出场、前面没交代它在哪，就会被塞进画面里唯一被描述的位置（案例一行：03集单元101 贾鹏被塞到孟山河同桌）。
- **法则**：单元挂载了几个主体，**每一镜都给每个主体一个明确的安放点**——本镜不出场的，要么宽景别里给远处位置，要么收紧景别让画面容不下第二人。
- **配套**：显式分离句（"两人分坐两张不同的桌子，相距数米"）＋约束尾正向锁（"XX全程独自坐在…，同桌没有任何其他人"）。
- **反向坑（未挂载但被台词点名）**：台词点名、角色全单元不入画时，禁用预设在场的写法（"这位是XX"会诱导模型现编一个路人版）。指代词改不预设在场的说法（"他是"）；望向/指向该角色的动作统一锚定同一画外方位；每镜加"画面中只有X一人"入画锁定（案例一行：03集301 画外喝止、303 才亮相）。

**9. 同场延续姿态接棒句——标了"同场延续"不等于继承了状态（F16，07集 U37→U38 实证）**
- 坑一行：模型看不到上一单元成片，"同场延续"只是标注不是状态命令——07集助理站姿无声变坐姿。
- **三步硬锁**：
  1. **首帧句点名状态**：`视频从以下画面开始：助理站在办公桌左侧汇报，面朝坐在桌右总裁椅上的周正`——逐字承接上一单元尾帧句（连续性与状态管理 一点六）；禁只写"承接上一单元"。
  2. **姿态有效区间＋支撑物归属**：承接首帧的站坐姿态保持至下一次明确动作转换；没有转换时才贯穿本单元。椅子/沙发/床沿等会诱发坐卧的支撑物明确归属；动作改变姿态或占用后，按新状态接戏，不用全局硬锁取消这次动作。
  3. **逐镜给可见证据**：承接镜头和人物再次出现镜头至少中景取到膝部或全身，写`双腿伸直、双脚落地`；近景只负责表情。人物出现几镜，姿态就重申几次。
- **模板**：`承接上一单元尾帧，[A]起始在[地标]保持[站/坐/跪]，直到镜头N的[明确转换动作]后改为[新姿态]；[支撑物]由[当前使用者]占用。相关承接镜与转换镜给出姿态的可见证据。` 本单元无姿态转换时省略转换部分。
- **边界**：剧情或符合原剧情的表演设计明确发生姿态转换时不锁"不变"，该镜只安排一个主动作，转换后按新状态接戏（接 F2、T27）；不新增剧情事件。

**9.5 分区空间四锚——"人在舞台上、机位在台下"仍不够（F17，07集 U19/U20 实证）**
- 坑一行：只写"周正站舞台中央、机位在台下"仍会跳位、只画空椅子——抽象区域名无承载面与边界；`宾客席方向`只是朝向，不等于观众存在。
- **四锚同时写，缺一不可**：
  1. **承载面**：`周正双脚始终落在抬高舞台地面`
  2. **物理边界**：`清晰舞台台口始终横向隔开周正与观众席`
  3. **机位所在区**：`机位位于台下观众席中轴线，隔着观众朝舞台拍摄`
  4. **占用证据**：中景保留2–3排虚化后脑；近景最下缘留少量虚化头部轮廓；可见座椅均有人坐
- **通用化**：门内/门外、柜台内/顾客区、审判区/旁听席、道路/人行道同理。
- **群演降熵**：只用后脑、肩背、浅景深虚化人影证明"有人"，不追求同一批脸（接 连续性与状态管理 L5）。

## 五点五、机位与景别切换（每单元排镜时过一遍）

> 详细语法见 `运镜与光影速查.md` §三点五。排镜硬规矩：
1. **景别由画面任务选择（Y4）**：中景/中近景常用；空间、动作范围、细节或表情有需要时可用全景或特写。反应按当下变化安排，不按数量强插。
2. **正反打锁轴线**：双人对话单元声明「机位保持在同一侧，A在画面左、B在画面右，视线方向一致，不越轴」——左右位全片一致
3. **相邻两镜机位角度差 ≥30度**（Y3），人脸占画面 1/3–1/2
4. **对话戏禁全员面向镜头（04集实测）**：不写朝向时模型容易复刻设定图的正面站姿。对话构图与视线衔接按 **Y21**——每镜写明出镜人物的对话朝向，对手在画外时按 F25；同框交谈时约束尾加"侧身相对交谈、面朝彼此、不面向镜头"；正面朝镜头**三种合法场合**（唯一出处＝提示词规范 §〇/T0）：①口播 ②看镜头收尾 ③无听者独白
5. **姿态/站位跳变：先 L2 写满，同场延续走首尾帧承接**：每镜每人必写"站/坐+面朝谁"是地板；同场延续接点用首尾帧提示词承接（逐字成对，连续性与状态管理 一点六）＋F16 姿态接棒三写
6. **到访/迎接/追送类走位：分清"谁刚到、谁本来在"（F14，06集单元3实测）**：有人物进出移动的多人戏，不写清时空关系时模型会把到达者和在场者直接并排站一起。三招锁死：①分区+运动方向逐镜写——到达者钉在入口侧、逐镜向室内移动，在场者钉在室内侧迎向入口；②会合镜头之前两方不并肩，只在指定"相聚镜头"才同框；③给到达者"刚到"锚点——行李/随身包/旅途姿态全程带着
