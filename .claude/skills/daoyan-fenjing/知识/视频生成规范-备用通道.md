## Guagu OpenAPI（按需通道，执行器 `工具/guagu_video_batch.py`）

协议来源：用户于2026-09-06提供的 `Google下载/guagu-openapi-v1.md`。正式 Base URL 为 **`https://guagu.cc`**，全部走 HTTPS；统一配置 `providers.guagu_video.base_url` 与执行器缺省地址同步，项目不再使用旧IP明文地址。原生接口前缀为 `/openapi/v1`。`/openapi/openai/v1` 是另一套只支持文生视频的兼容接口，本项目参考图生成继续使用原生协议。

### A. 参考素材上传

Guagu v1 不接受外部图片 URL 直接作参考素材。先调用 `POST /openapi/v1/video-generations/references`（multipart 字段 `file`，可选 `kind`），取得 `asset://...` 后才能在创建任务时引用。图片与音频单文件上限20MB，视频上限30MB；支持图片 jpeg/png/webp/gif，音频 mp3/wav/m4a/aac/ogg/flac，视频 mp4/mov。参考视频每条2–15秒、同任务累计最多15秒，还须符合该模型的素材数量限制。

上传超时至少120秒；执行器上传并发最多2路，提交任务并发仍由本批参数控制。大图上传超时优先压为JPEG/WebP并保留源图，不重复盲传同一大文件；实际采用的参考图状态仍以用户授权和本单元挂载为准。

### B. 创建任务

请求头除认证与 JSON 类型外，必须设稳定的 `Idempotency-Key` 或 `X-Request-ID`；超时/断线重试复用原键，只有用户确认新开一次计费重跑才生成新键。

```json
{
  "model": "{用户本批确认的完整模型名}",
  "prompt": "{当前单元「单元提示词」第一个代码块的内部正文}",
  "resolution": "720p",
  "ratio": "9:16",
  "duration": 15,
  "generate_audio": true,
  "content": [
    {"type": "image_url", "role": "reference_image", "image_url": {"url": "asset://{彩铅参考图资产ID}"}},
    {"type": "image_url", "role": "reference_image", "image_url": {"url": "asset://{其他参考图资产ID}"}}
  ]
}
```

- `content` 顺序必须与视频挂载清单一致；模型不支持带音频时不得静默换模型。
- `model` 按实时模型表原样取值，结合 `name`、`description` 核对分辨率、时长与素材上限；`resolution` 是所选模型的校验值，`ratio` 必须显式传 `9:16`。`duration` 按本次用户授权与分镜生成参数发送；模型不支持的时长或画幅可能先被受理、再在生成阶段失败，不能把202当作能力验证，也不能静默改时长。
- `POST /openapi/v1/video-generations/estimate` 可用完整拟提交请求做费用与素材准入预检，不创建任务；`GET /openapi/v1/balance` 的 `balance` 才是可用积分，`frozen` 是已冻结积分。模型价目是每条单价，实际费用以创建响应及终态结算为准。
- 创建后轮询 `GET /openapi/v1/video-generations/{id}`；成功读 `result.video_url`。费用以 `final_cost` 与 `billing_status`（pending/charged/refunded）为准，失败退款以任务实际状态为准。
- 恢复任务用 `GET /openapi/v1/video-generations?page=...`；仅 queued 可尝试 `POST .../{id}/cancel`。
- **金融字眼与去重坑（2026-07-25 实证，主文件 §二.8/9 同源）**："拖款/到账/转账/打款"触发金融审核直接拒；瓜谷按提示词文本去重——同文重提返回缓存拒审结果，换挂载图也无效，只有文本变化才是新任务。

接通记录（2026-09-06，Guagu）：实时返回 `seedance55`＝“2.5 · 720p · 30秒 · 不卡脸 · 渠道Y”，描述“9图 0音频 0视频”，当时单价3积分；89集U3＋U4已用六张图片提交一条30秒任务137220。这里的零音频指参考音频数量，提交仍可启用生成对白。此条仅为接通与提交快照，不是长期报价、默认模型或画面质量承诺；每批仍重新查询实时模型表。

### D. 参考素材与创建任务

参考图片通过 `images` 数组传公网 HTTPS URL，不沿用 Guagu 的 `asset://` 句柄。平台提供 `POST /v1/materials` 上传接口（`multipart/form-data`，字段 `file`，单文件≤20MB），响应含素材 `id` 和 `url`；相对路径按本渠道 Base URL 补为完整地址。2026-09-10已实传第98集U1的7张PNG，全部返回素材地址并通过匿名GET图片访问；该内容路由的HEAD返回404，不能据HEAD单独判素材失效。素材托管不扣模型额度是渠道文档声明，实际计费仍以账单为准。

上传及挂载顺序以当前单元“视频挂载”清单为准，素材状态服从生产线总则的当前生产开关。将取得的真实图片地址按相同顺序放入 `images`；本模型不传 `videos`、`audios`。创建任务为 `POST /v1/videos`，`Content-Type: application/json`，请求格式如下（占位内容须替换）：

### E. 查询、下载与核验边界

- 文档中的创建响应含 `id`、`status: "queued"`、`progress`；取得 `id` 后立即记本批账本，再用 `GET /v1/videos/{task_id}` 查询同一任务。
- 文档中的完成状态为 `completed`，结果可通过 `GET /v1/videos/{task_id}/content` 下载。相对结果地址同样按本渠道 Base URL 解析；下载后的时长、画幅、编码、音轨及完整解码按主文件核验。
- 本渠道的幂等、取消、并发限制、失败退款与排队速度尚未核实；提交断线或超时不能直接当成失败重投，须先按任务号和账本对账，也不自动换通道。
- 命令行执行器在POST创建前记录`submitting`、成功后立即记录任务号；已有创建记录的同一账本拒绝重复POST。素材按当前挂载顺序上传并以哈希缓存，查询默认30秒一次；`--confirm-cost`须与本批实时公开预算一致。下载仅向本渠道同源请求附认证，跨域下载跳转不携带密钥。

## Canvas API（封存通道，执行器 `工具/canvas_video_batch.py`）

### A. 请求与素材

请求头：`Authorization: Bearer {当次会话密钥}`、`Content-Type: application/json; charset=utf-8`。参考图以 data URL 放入 `images` 数组，顺序即"图片N"编号：

```json
{
  "model": "{用户本批确认的完整模型名}",
  "prompt": "{当前单元「单元提示词」第一个代码块的内部正文}",
  "images": ["data:image/png;base64,{彩铅参考图}", "data:image/png;base64,{场景图}"],
  "duration": 15,
  "aspect_ratio": "9:16",
  "ratio": "9:16",
  "resolution": "720p"
}
```

- 每次 POST 都可能新建计费任务；无已验证的幂等键或取消路由，禁止用带真实模型的请求探活（探活只用 `GET /v1/models`＋纯本地检查）。
- 成功响应必须取得 `task_id`；费用以 `charged_cents`、`balance_cents` 为准。一个 `task_id` 后续只允许 GET 轮询。

### B. 轮询与断线恢复

1. 每10–15秒 `GET /v1/videos/{task_id}`。
2. 成功状态下兼容读取 `video_url`、`result_url`、`resultVideoUrl`、`url`、`videos[0].videoUrl`。
3. `failed` 但无明确 `failReason` 且视频字段为空时继续查3次；连续3次失败或出现明确原因才判最终失败（瞬时状态竞态兼容）。
4. POST 连接重置或无响应时，先比对余额、工作台记录和本地账本，只补交确认没创建的单元（V8）。
