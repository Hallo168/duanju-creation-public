## 一、基础运镜

| 写法 | 功能 | 适用 |
|---|---|---|
| 推镜(push in / dolly in) | 强调细节、情感强度递增 | 情绪高潮、关键对白、揭示 |
| 拉镜(dolly out) | 揭示环境、释放情绪 | 场景开场、结局收尾 |
| 左摇/右摇(pan) | 展示空间、跟随移动 | 环境展示、双人间视线转移 |
| 上摇/下摇(tilt) | 角色登场、垂直空间 | 人物出场（从脚到头）、建筑 |
| 环绕(orbit) | 立体展示、视觉冲击 | 角色亮相、对峙 |
| 跟拍(tracking shot) | 沉浸感、动作连贯 | 走路、离场、追逐 |
| 固定(fixed) | 机位不主动移动 | 行动、关系或表演在既定构图里展开 |

稳定质感与上表的摄影机主运动分开选择。手持(handheld)描述机身起伏，可以基本原地，也可以与跟拍、推近配合；锁定、平稳移动或手持质感均按具体场面选择。它们与固定、运动的平等关系及情绪表达依据，见《导演思维》“镜头追随戏的变化”。

## 二、高级运镜（有具体叙事作用时使用）

| 写法 | 效果 |
|---|---|
| 希区柯克变焦(dolly zoom) | 空间扭曲、认知崩塌瞬间 |
| 一镜到底(one-take) | 全程不切镜 |
| 荷兰角(dutch angle) | 不安/紧张 |
| 升格慢动作(slow motion) | 展开快速事件的冲击细节或人物主观瞬间；写清呈现范围，按导演思维“事件怎样快、怎样慢”安排 |
| 甩镜(whip pan) | 快速转场、紧张（C级衔接常用） |
| 移焦(rack focus) | 焦点前后景转移（人脸→道具） |
| 低角度仰拍 | 英雄感、压迫感 |
| 第一人称主观视角(POV) | 代入感 |

## 三、景别

| 景别 | 常见作用 |
|---|---|
| 全景/关系范围 | 空间差异、人物距离或动作范围本身在表达戏，竖屏保证重点可读 |
| 中景 | 行动、作用对象与人物关系 |
| 中近景 | 对话和上半身表演 |
| 特写 | 表情、手部、道具或商品细节承担当前变化 |

复杂构图是否值得承担，由戏的作用与可生成性共同决定。

## 三点五、机位语法与景别切换

**1. 对话与轴线（Y2）**：主镜头先想通空间，再选择正反打、同框调度或连续表演。保持左右位与视线；默认不越轴，换侧可经中性镜头。门口/柜台/车窗技术写法查F27。

**2. 相邻镜（Y3）**：机位或景别改变要可理解，常规可用约30度差异防跳帧，不为变化无缘由换机位。

**3. 景别（Y4）**：面部是本镜重点时用能看清眉眼嘴部的近景或特写，允许裁去不承担本镜内容的手脚；动作和作用对象是重点时再给相应范围，两类镜头可以分工。强情绪不因“动作也要全看见”一律退成中景，细微表情则靠近并留住其过程。空间关系重要时放宽，不限定只有高潮能特写、灾难能全景。

焦段与机距的情绪作用见《导演思维》“镜头追随戏的变化”；取景要保留所选表情和动作对象，不以焦段数字替代可见的观看关系。

**4. 连续表演（Y5）**：台词持续推进可以保持景别；新的意义转到听者、动作落点或物品时再转移注意力，不按次数插反应。

**5. 竖屏（Y6）**：主体、证据、行动落点可读，空间可考虑前后景与纵深。人脸大小随任务，不统一占画比例。

**6. 多人对话（Y8）**：交代必要关系，常规正反打只控制当前两人。其他人有作用时出现，必须同框者写清状态。换对话组保持空间和视线。

**7. 对话感（Y21）**：
- 过肩、非过肩、反应和动作镜按需要组合，不设20%–30%配比。过肩写明哪侧虚化肩背、不露嘴/不转身，肩背计入名单并带反克隆约束。该构图历史上易克隆，实际失败可改清楚单人构图和视线衔接，旧模型经验不当所有模型的事实。
- 对手在画内时目光落到对应人名，画外时按F25用画外方位，不召入背景；人物相互说话，不都正面看镜头。
- 听者反应有信息或情绪作用才安排，可与画外原声并行，也可独立留拍，后者计入时长。

## 四、光影方案（写法：光源方向+色温感知描述）

> **光源与调性（2026-09-18 用户裁定）**：全剧视觉调性沿用本集 `资产提示词.md`，选定规则唯一出处＝`../../zichan/知识/风格预设.md`。光源写清方向、冷暖和场景依据（窗光、顶灯、台灯、路灯等，可在画外）；可用反射补光、侧光或轮廓光塑造层次，效果须与场景光源关系相容。

### 4.0 按本剧调性安排光色（Y20，全流程适用）

冷暖、明暗与对比由本剧调性和当前场戏决定，不统一套明亮低对比。把画面要求写具体：

- **光线与明暗**：明确主光方向及明暗过渡，按剧情保留亮部与暗部层次；夜戏可有夜色，悬疑可用局部光和较高对比，承担表演的人脸、动作与关键道具仍应看清。
- **肤质与色彩**：肤色与皮肤纹理真实，柔光不等于磨皮；环境冷暖、饱和度随本剧调性，避免让统一色罩淹没肤色和材质差异。
- **焦点与空间**：按本镜叙事主体安排焦点和景深；需要看清人物关系或道具时保留相关景层，不把电影质感等同于每镜背景虚化。
- **同场连续**：同场同时间保持光源位置与基础光色一致；场戏转换或剧情内光源变化时再调整，不随正反打重新布置互相矛盾的光线。

场景句式示例（按本剧改写，同场延续时沿用光源关系）：
> **温暖日戏**：柔和窗光从左侧照入，墙面反射光承接人物暗侧；高光柔暖，肤色自然，表情清楚，衣料与旧木桌保留细腻纹理。
>
> **冷调夜间对峙**：办公室环境偏冷，桌面台灯从人物侧前方照亮面部，窗外城市灯光留在后景；脸部明暗有层次，眼神与桌上文件清楚，背景较暗，肤色自然。

**词语按场景使用**：电影质感、暗调、高对比、轮廓光不再列为禁词；使用时写出具体光源和画面效果，不只堆风格标签。颗粒、光晕、怀旧色偏按选定风格需要使用，不作为电影质感的固定套件。

**适用范围**：资产场景图、分镜光影句与封面；人物设定图保留资产规范的均匀光以明确身份。成图审核与修复沿用生产线总则，不另加暗调验收关卡。

### 4.1 情绪光影方案（在本剧调性内选用，不是题材固定配方）

| 情绪 | 可用写法 |
|---|---|
| **温馨治愈** | 暖窗光与墙面反射光形成柔和过渡，人物与环境色彩协调 |
| **浪漫梦幻** | 黄昏暖金阳光与室内柔和反射光呼应，按场景保留柔亮高光 |
| **对峙冲突** | 有方向的侧光拉开人物与背景，冷暖、对比随当前权力关系和环境安排 |
| **悬疑紧张** | 局部灯光照出眼神或线索，房间边缘进入阴影，保留叙事所需细节 |
| **悲情揭示** | 窗光或台灯收束到表情，环境色彩适度收敛，不固定把悲情拍暗 |

光影强度随故事推进；暗调不设每集次数配额。切镜、表演、声音和运镜仍按 §八 当前情绪基调执行，不因采用电影质感统一放慢节奏。

## 七、镜头叙事工具

先按导演思维.md确定全剧观众体验与场面行动，再有条件使用下列工具。

1. **Y10 画面任务**：理由不能只是“轮到他说”。看当前有意义的行动、事实、关系或反应；台词可经导演台本改编。
2. **Y11 发现链**：看向某处→对象→反应能交代发现，按信息是否已清楚取舍，不凑三镜。
3. **Y12 反应落点**：伤害、惊喜或认知变化在听者身上时给他；说者的转变更关键时保留说者。反应可有独立时间，不默认继续灌词。
4. **Y13 道具照应**：在需要时建立、提醒、兑现，使观众记住意义，不每物三次。物件镜可由已建立视线、操作或清楚上下文交代归属。
5. **Y14 主动权**：先设计施压、承受、夺回主动的动作与空间变化，再用角度、占画与距离拍清。善恶不固定对应强弱；固定镜也可借前压/退缩表达。
6. **Y15 纵深调度**：前后景、门框或纵深移动可表达关系，复杂度与素材相容，不为构图强塞人物。
7. **Y16 首尾画面**：场景进入给够必要关系，之后承接正在发生的戏；末格可留期待或完成兑现。技术边界不要求悬停。
8. **Y17 无台词拍**：看懂、决定、接受、拒绝或行动后果正在发生时可独立留拍。写清变化与结束标志；无任务的呼吸、微颤和空镜不填时间。按台词时长估算计时，不设一秒或次数限制。
9. **Y18 情绪与空间**：默认清楚；确需失序且仍能理解时可改变轴线，不随机跳切。
10. **Y19 主镜头先行**：先想清整场空间与行动，各镜是其中有用部分；生成单元切开之后仍继承整场设计。

## 八、基调与节奏（Y22）

基调帮助选择声音、光色和表演气质，不自动生成切镜配方。同属悲伤可以爆发或忍住，同属强势可以抢话或从容等待。

| 场面需要 | 可考虑方向 |
|---|---|
| 紧急/混乱 | 抢接、动作先于完整解释，焦点交接清楚 |
| 对峙 | 施压、试探、拒绝有节奏差异，不必人人大声快速 |
| 悬疑 | 给清楚可追问信息，控制揭晓，不以模糊画面代替悬念 |
| 温情/重逢 | 具体照顾、辨认和接受的动作，给读懂的时间 |
| 悲恸 | 身体与声音变化有因果，必要换气和反应不被挤掉 |
| 爽感/反击 | 拍清证据、行动落点与关系变化，让观众看见兑现 |
| 大场面 | 前因、规模、后果可读，运动量在模型可实现范围 |
| 展示/亮相 | 关键材质、身份差异或用法可读，避免无内容巡游 |

节奏随人物与场面变化，不把所有单元提速，也不因电影质感统一放慢。新增反应、动作、声音须承担作用，不以细节堆积代替判断。
