## 〇、前置硬门槛：先定镜头主体，再写其他内容

> **P-73 升格规则（2026-07-30 用户再次强调）：镜头不负责证明所有人都在场，只负责拍清当前叙事主体。**

每个镜头落笔前，必须先回答三问：**①这一镜谁是唯一叙事主体；②谁可以露正脸和嘴；③其余在场者是完全不入画、只作画外音，还是只留不露嘴的虚化肩背。** 三问没有唯一答案，不得继续写机位、动作和背景。

- **说话镜的画面主体必须是说话人本人**（过肩与非过肩镜头的安排按 运镜与光影速查.md Y21；「单人正面朝镜头」仅限口播/看镜头收尾/无听者独白）；含台词镜头在台词后写口型归属锁句「只有X的嘴随台词自然开合」，同框留有他人时补「[他人]闭嘴听着」。反应者另切反应镜。
- **视线衔接**：按 运镜与光影速查.md Y21②区分对手在画内或画外的写法；画外人名限制按 分镜自查检验.md F25 禁四。
- 禁为"交代全员在场"把无叙事任务的人塞进后景、画面边缘或单元尾帧；同一镜两张清晰正脸，必须说明两人为何都承担当前叙事任务，说不出来就拆镜。
- 入场戏与门口对话的固定写法（静态亮相禁跨门槛走位／同轴正反打禁门里门外分屏）、同框白名单与 31 集三案复盘，**唯一出处= 分镜自查检验.md §十二（F26/F27）**，本节不重复细则。

## 一、生成单元

- 每单元固定选定的15秒或30秒，写本轮导演分镜测试目录；单元数量和镜数由导演台本、场面节拍与容量决定。
- 导演可按本Skill授权改台词、动作及呈现方式；展开后以导演台本核对，保留核心剧情事实和产品真实信息。不为换词而改，不为凑时长填词。
- 每次生成仍完整描述本单元主体、场景和声画；有意义的非语言拍可承担独立时间，无任务停顿、重复反应和空镜不用于填满。

## 二、单元提示词结构

```
〖素材声明〗（官方一致性三件套）
将<图片1>中的[2-3个静态特征]定义为主体1（角色名）；
主体1的面部特征参考图片1（大头照），妆造参考图片2（全身照）；
图片3作为场景基准，直接使用该环境。

〖镜头1〗每镜按官方四要素顺序：
运镜/切换方式 → 主体动作与表情 → 空间位置 → 音频信息
〖镜头2〗…
〖镜头3〗…

〖全局收尾〗风格锚点 + 约束句 +（需衔接时）尾帧定格句
```

**素材声明规则**：
- 【官方】主体定义句式：`将<图片N>中的[主体核心特征]定义为<主体N>`，用 2–3 个静态特征
- 【官方】顺序即权重：越需要精准参考的素材，放提示词中越靠前
- 【官方】人脸大头照与全身照分开引用（面部特征 vs 妆造）——**本项目按 2026-08-05 用户裁定改用单张竖版双格设定图（上格大头＋下格全身）整图挂载**，一人一个挂载位、必配 T16 反克隆句；官方两张分挂降为克隆翻车时的降级选项。**人物四格/宫格素材仍全面禁用**——官方"双胞胎问题"章节：多视图易被识别为多个主体、同画面生成克隆人（生产链见 资产生产规范 §一）
- **禁止**任何"（外观权重N%）"百分比写法——非官方语法，已证伪
- 每个引用必须说明用途；"参考"一词触发引用模式；视频编辑用"严格编辑"、延伸用"向前/向后延伸"
- **禁写解释性/元叙述句**（2026-07 用户裁定）：不给模型"讲课"——"图中四格为同一人""四镜正反打快速对答衔接紧凑"这类解释画面结构或导演意图的句子一律删除，即梦能自动识别人物设定图/多视角图；提示词里只留画面和声音的直接指令，每个字都要换成像素

## 三、符号体系【官方】

| 内容 | 符号 | 示例 |
|---|---|---|
| 台词 | `{}` | `苏晚（冷声，字字压着）{亲子鉴定。你自己看。}` |
| 音效 | `<>` | `<文件拍桌闷响>` |
| 音乐 | `（）` | `（低沉弦乐渐起）`——一般不用，BGM后置剪映 |
| 字幕 | `【】` | 一般不用（约束句声明"「生成视频不要出现任何字幕」"） |

- 语气/声音标注写在 `{}` **外**的圆括号里；`{}` 内的台词模型逐字保持并对口型
- 台词按自然说话节奏断句；标点即表演指令（见情绪外化字典）

## 四、镜头切分【官方】

- 只用"镜头1/镜头2/镜头3"标签，按事件顺序组织
- **禁写精确时间段**（"0-5秒"）——官方原文："模型对精确时间的支持不稳定，强行限制时长可能导致生成结果异常"
- 不为单镜强制指定秒数；总时长靠生成参数（UI）控制
- 单元时长标识（按所选15秒或30秒档，历史稿沿原参数）只写在单元标题、分镜总表与生成参数行；镜头正文只写动作顺序与表演过程，**不写“0–5秒”这类精确时间码**
- 例外：视频延长（"将@视频1延长5秒"，生成时长选新增部分）、音乐卡点任务可用时间锚点，接受抽卡风险

## 五、人物描述：锚点递减制

- **首镜全量**：角色首次出场的镜头写完整人物描述块（≤60 字，从本集资产清单.md 逐字复制）
- **后续镜头锚点简写**：`角色名（2个硬锚点）`，如"陆承（右眉浅疤，深灰西装）"；特写镜头锚点换五官级（脸型+发型）
- 一致性主承重墙是参考图，文字描述是冗余锚定
- **未成年角色不再默认去龄化（T10.1，2026-09-03 用户裁定，取代 2026-07-29／08-10 两次去龄化裁定）**：叙述层照剧本写年龄数字与身份词（孩子/学生/校服/"十二岁男孩"均可写），声音DNA"年龄感"槽照常写。**去龄化降为修复手段**：只有该单元被通道以未成年主体拒绝（提交关卡 V24 `10001303`，或成片审核拒）时，才在 /xiufu 未成年触发分支里对该单元叙述层去龄化重投，改法沿用——主体定义句/描述块/锚点/动作景别里的年龄数字与未成年标识词（孩子/小孩/男孩/女孩/儿童/学生/校服/母子）改 **"男生／女生"** ＋外观锚点（`十二岁男孩，圆脸，蓝白校服` → `男生，圆脸短发，蓝白运动外套`）；`{}` 内台词一字不改（台词是锁定契约，全局替换会命中台词——26 集实测）；与 T11 冲突走改源头（同步 Edit 本集 `资产清单.md` 描述块，分镜逐字复制）；年龄感留在声音槽（示范：`小月以十五六岁少女清亮原声，音量中等、语速偏快……{叔叔我不是收破烂的，我找人——}`）。已知边界（Symphony 实测）：触发源常是儿童参考图本身，措辞去龄化不保证过审，仍拒按 视频生成规范 §四点五E 未成年触发项处理；**不因此在选题/成稿阶段规避儿童角色**
- **身份块逐字重复**：描述块与固定简写跨镜/跨单元**一字不改**，禁换措辞、禁代词——换措辞=给模型重新想象的空间（实测：这是文字层影响一致性的单一最大因素，比模型自带一致性开关更有效）
- 服装一集不换；服装描述包含在描述块内随首镜出现

**多角色同框**：
- 素材声明层做一次定义绑定，正文一律用**角色名**，不再出现 @图片N（正文中的@会被理解为"把图插入画面"）
- 一人一句，主语必须是角色名；禁"他/她"跨句指代
- 双人镜头必写**空间锁定句**：方位（左/右·前/后景）+ 姿势（站/坐）+ **朝向**（面朝谁）+ 负向锁"位置全镜不互换"，位于描述块后、动作前（"小唐站在案台左侧、面朝右方的孟山河；孟山河站在案台右侧、双臂抱胸面朝小唐，隔案台相对，位置全镜不互换"）。完整句式库见 `分镜写作法则.md` 第五节。**注意：文字站位是弱信号，只锁"描述一致"，锁不死像素级站位——靠换景别剪辑点与剪映盖缝规避（连续性与状态管理 一点六）**
- 同屏角色 ≤3

## 六、动作·运镜·光影

- 动作：写清身体部位、对象、幅度和行为过程，速度服从人物任务，不统一写慢；避免空泛“快速/fast”，用具体动作与结果表达。
- 情绪一律外化（查情绪外化字典），禁止裸用抽象情绪词
- **一镜一运镜**（单镜内禁叠加第二个运镜指令——"固定镜头"+"环绕"同镜=混乱输出），中文（English）括注（"缓慢推镜(push in)"）；运镜与主体动作分开写；**全单元运镜种类合计 ≤2 种**（防单元内运镜杂乱，非单镜可组合之意）
- 光影：光源方向 + 色温感知描述为主（"暖黄台灯从左下打亮，窗外冷蓝街灯逆光勾轮廓"），K 值可写但不指望精确执行；明暗比同理
- **姿态配给（T27）**：一镜一个主动作，其余只许微动作；跪地/弯腰拾物/递接物品/转身走位叠台词/跌倒攀爬/复杂手部操作为高危姿态——每镜至多一个且台词减载；已完成态的适用范围与关键过程保留按本文件 T27，不据此省略普通动作或关键情绪转折
- 约束句：优先正向陈述（"面部与参考图完全一致，服装全程不变"）；否定句白名单三条——"「生成视频不要出现任何字幕」""不生成水印"＋人物挂载单元的官方反克隆句（全文见 T16）；其余实体负向句禁止（F25）

## 七、音频分层（省钱规则）

- 提示词只写：**对白 `{}`** + 极少数与动作同源的重音音效 `<>`（拍桌/椅响/耳光）
- BGM、环境音、爆点音效**一律后置剪映**——成片是混合单音轨，卡点精度只能在剪映做
- 需干净对白的单元，声明"无背景音乐"
- 对白单元音效只做重音标点；纯画面单元可全铺环境音+动作音效

## 八、台词与叙事拍预算（只进总表）

按本目录台词时长估算.md，对自然对白、必要换气及不重叠的串行叙事拍估算。适合紧接就紧接，需要看懂证据、完成选择或让行动产生结果就留空间。普通事务动作可以边说边做。

单元参数仍固定D秒；超时先重切，确有影视化需要可同步改导演台本。少台词看独立画面是否有任务和预算；无任务则合并/重切。静默不设全剧次数，也不为低密度把每场拍慢。价格、数量、用法需要听清。

## 八点五、台词校正护栏

分镜对白对本轮导演台本核对；原稿到台本的艺术加工已获授权，不将有意改编当错字复原。防止转写遗漏、错角色、乱序和无意重复；继续改编时同步台本及记录。

修复时保留或重写身体行动、手部/面部和声音状态，不用“同上”“按原语气”“按导演台本原台词表演”等占位语。无台词镜具体写画面任务即可，不为模板凑身体线索。按 ../SKILL.md 第5.5步核对。

## 九、对白密集单元 vs 纯画面单元

> 纯画面可承担发现、选择、行动后果、商品展示等明确任务，按任务与预算决定是否独立成单元；不机械留满D秒。

| | 对白密集单元 | 纯画面单元 |
|---|---|---|
| 镜数 | 按场面变化与T26安排，不凑固定镜数 | 按实际画面信息和过程安排 |
| 台词量 | 按人物表演与容量估算，不强制紧接或超载 | 可无台词，画面有独立任务和时长依据 |
| 词数重心 | 声音层标注；听者反应用一个短语带过（"僵住""攥拳"），不展开成句 | 动作幅度/物理细节 + 运镜 |
| 运镜 | 保守：固定/缓推/移焦（剧烈运镜毁口型） | 可上跟拍/环绕/甩镜 |
| 音效 | 对白为主，音效只做重音标点 | 环境音+动作音效全铺 |
| 多人对话 | 官方支持单人独白/多人对话一次生成；**每镜一人开口**、正反打切换说话人；同一单元内两人快速对答是常态写法 | — |

## 十、单元衔接策略（B级软衔接默认／C级转场遮断）

> **现行默认**：叙事切点→B级软衔接/C级转场遮断硬切；技术切点（同场延续）→**首尾帧提示词承接**（上一单元尾帧句＋下一单元首帧句逐字成对，不抽帧不挂图，句式见 `连续性与状态管理.md` 一点六）。
> 配套教训（04集实测：母亲上单元站着、下单元变坐着；三人排排面对镜头）：**姿态/朝向跳变的第一防线是 L2 写满**——每镜每人写"站/坐+面朝谁"，对话构图与画内/画外视线写法按 Y21。

- **B级·剪辑点软衔接**（80% 场合）：主动换景别制造剪辑点——上单元收特写、下单元开中景（或反之；全景已禁用，Y4）；只需三样文字连续：服装块逐字复用、光影层逐字复用、**情绪残留交代**（下单元首镜第一句动作承接上单元情绪终点："苏晚眼眶仍泛红，正弯腰去捡地上的文件"）
- **C级·转场遮断**（时空跳跃）：甩镜(whip pan)收尾、黑场、或插 1 秒空镜（场景图直接当空镜素材），豁免连续性
- **情绪接力表**：分镜总表含"单元情绪终点｜下单元情绪起点"两列，编写时保持相等或合理过渡；不做QA逐行复审，关键位置的明显降档按 `../SKILL.md` 第5.5步处理

## 十一、挂载清单（必须项）

## 十二、首帧图提示词（先图后视频关卡·默认跳过）

**默认不产**（2026-07-12 用户裁定：首帧关卡默认跳过；同日裁定 5 秒短测一并否决——每次生成都是抽卡，短测无预测力，高风险单元直接上全长）。仅当用户按集要求恢复首帧关卡时，才每单元产出一条**首帧图**提示词（即梦生图用）：单元首镜的静态版本——景别 + 人物描述块 + 空间位置 + 场景 + 光影，无动作过程、无台词。用途：先生成首帧图 3 秒确认脸/服装/构图，再转视频（可用首帧图作起始画面）；也是 /xiufu 超限降级"首帧图生视频"的底稿写法。

## 十二点五、带货段单元（带货剧专用）

带货段的画面语言与剧情段不同，三类单元交替：
1. **人物口播单元**：剧中人向对手或镜头介绍商品，机位按场面需要，声音清楚亲和，价格/数量不能压糊；按本目录容量估算，台词来源为导演台本。
2. **产品展示单元**：产品特写/冲泡演示/成品拉丝质感——**产品图必须挂用户实拍图**（"图片N中的产品作为主体，保持包装与文字完全一致"），产品包装上的文字是最容易崩的元素，约束句加"保持产品包装文字清晰不变形"；无台词，环境音后置
3. **使用场景单元**：家人喝/老人孩子场景——常规剧情单元规则
- **成品插入镜（2026-08-10 用户裁定，镜头级、不独立成单元）**：口播台词讲到具体成品/口味/吃法时（如红烧酱汁→红烧肉、红烧排骨），对应那一镜直接硬切该成品菜画面——人物出画，写「X的画外原声继续说」（F25 画外三禁照常），台词照常 {} 逐字锁定并行覆盖；讲回价格/促销/行动号召时切回人物口播镜。成品镜写法：成品菜特写～近景（Y4 产品特写例外口径）、食欲光影（暖光/蒸汽/酱汁光泽/浅景深）、缓推或环绕微运镜；**每道菜必挂成品菜参考图**（"图片N中的[菜名]成品作为主体，菜品外观与图片N完全一致"，出图口径见 资产生产规范 §四点五）。数量不定额——台词点到哪道菜就切哪道菜，台词没点名的菜不硬塞
- **产品特写配额（2026-08-12 用户裁定"带货段要给到产品成品的特写展示画面"，76集沉淀）**：整个带货段合计必须安排 **≥3 个产品专属特写镜**（画面主体是产品、不含人物正脸的产品近景，Y4 产品特写例外口径）：①干品/成品形态特写（掌心单朵、拉丝、酱汁光泽）②包装/罐内码放展示（转罐/开盖）③使用过程特写（冲泡绽放、涂抹、拌开）；有"错误用法"卖点的加一个**反面示范镜**（掂一把散菊又放回＝演示"抓一把浪费"）。禁把带货段拍成清一色人物中近景口播——口播是声轨，产品是画轨，两轨都要喂
- 带货段字幕密度高（价格/卖点要上屏），生成端仍"「生成视频不要出现任何字幕」"，全部剪映后贴
- 口播单元不做短测、直接上全长；价格数字念错必重跑（幂等键换新版本号），属可接受抽卡成本

## 十四、导演节奏与切镜（T26）

1. 信息出现、行动发生后果、人物改变策略、视线发现或情绪转向另一人时可切。持续表演还在推进戏时可保持，不每句强切。
2. 开头声画共同建立异常与关注对象，从正在发生的冲突进入；不固定三镜模板，不凭空添加灾难或恶人。后续单元承接正在发生的戏，不逐单元重新定场或点火。
3. 普通拿放、走位可与对白并行；必须独立看懂的动作、决定或反应可串行，计入预算。收掉无意义的走完全程与反复表情。
4. 抢话、连珠和听者沉默各有情境；不强制每单元交替两次，不因超过固定秒数插无用反应。
5. 收尾可以留下期待，也可以兑现、收住或转入新情绪。D秒边界是技术切点，不强制悬空动作或反应峰值。
6. 留白承载看懂、迟疑、选择、接受或拒绝的过程，任务结束就推进；不设一秒/次数配额，不把所有戏统一放慢。
