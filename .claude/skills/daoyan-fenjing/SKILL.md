# 导演分镜

项目根目录＝<项目根目录>。本技能从 .claude/skills/fenjing 完整复制建立，版本＝20260927-v2；维护源＝.claude/skills/daoyan-fenjing，Codex 发布副本不单独修改。成熟 fenjing 与其产物继续保留。

## 任务与授权

你负责把剧本变成观众愿意继续看的场面，再把场面写成可生成的分镜。先判断观众的代入、知情与期待，组织人物行动和情绪变化，再选择镜头、声音和节奏，最后适配固定生成单元。导演判断依据见“知识/导演思维.md”，不要把这一层简化为填基调标签。

2026-09-26 用户对本试验版的明确授权：“我允许导演可以在写分镜影视化的过程中，修改台词，修改动作等等……不是必然要改，而是导演认为这一部分从文本到视频效果不太好的时候，那就可以自行调整。”

因此，本技能中导演可以按影视化需要删、合、改、增台词，调整说话顺序、动作、场面调度和开场呈现，不逐处请求确认，也不要求每场必须改。已经适合表演的原稿直接保留。调整须服务具体效果，如让关系更快可读、用行动承担说明、让情绪落点成立、使性格在选择中显现；不以缩字、改动率、镜头花样证明工作量。

保留故事核心人物关系、关键事实与因果、主要情绪兑现和结局，以及产品真实规格、价格、数量、使用方式与已确认信息。可以补充承载原戏的表演细节，不凭空增加改变主线的新人物、重大遭遇、身份或反转。文案事实内部冲突且无法由原始资料判定时才报告疑点。原二创稿和资产清单不回写；原稿到影视稿的必要调整记录在试验目录的导演台本中。

## 规则范围与读取

本技能使用自己的知识副本。导演权限、叙事留白、镜头节奏与景别，按本技能和知识/导演思维.md执行；技术格式、身份素材、商品实拍、口型、连续性沿用复制后的技术规则。项目原流程中的“二创稿逐字锁定”“动作一律不计时”“普通对白必须偏紧装填”“固定镜数/反应配额”不再约束本试验版，且不回写成熟版。最终提示词与本轮导演台本保持一致，防止有意改编之外的转写遗漏。

## 输入与版本

1. 用户点名的剧本是唯一创作来源。缺少标准二创稿.md但用户明确给出剧本时直接以该稿写导演台本，注明来源，不为此强制回成稿流程。
2. 时长用用户指定的15秒或30秒。同一故事已有唯一时长的成熟分镜且本次要对比时，沿用该时长；否则询问档位。固定D秒是生成容器，不是剧情节拍，每套单元仍统一为D秒。
3. 产物落 stories/故事目录/导演分镜测试/日期-vN-D秒/；用户指定版本目录则使用指定目录。已有完整产物不覆盖，新试验递增版本；用户明确修订当前轮时可在该轮改并记录。
4. 本技能的独立生成测试从新版规则与原剧本重新写，不读取旧分镜正文，不把旧分镜或上一轮导演稿当作底稿。可由调用方提供原版档位；资产清单内旧单元挂载表仅为历史，不沿用其切分。
5. 核对资产身份/状态、场景和商品实拍是否存在。本轮素材不足时列出待补素材，仍可完成文字分镜；不冒称素材齐全，不自行生成、付费或覆盖原资产。用已有素材能表现时优先据此调度。本集彩铅/写实开关沿用资产清单的已确认状态。产品规格.md若不存在，使用本集材料中明确记录的用户确认事实并标明来源，未知规格不推编。

## 阶段零·导演处理（先整体后单元）

读完全文再设计。把全剧的观众期待和信息释放、关键场面变化、角色在压力下优先保护什么、开头如何声画并行建立冲突、哪里需要紧接与停留，简洁写进分镜骨架.md的“导演处理”。具体说本剧，不复述知识条文，不逐镜另写问答。

形成导演台本.md：按场景保存完整的影视化台词和关键动作，包含本轮原样保留的段落，不用“同原稿”省略。保留角色与场景对应，在末尾用简表记重要调整：原稿位置/原表达、本轮表达、影视化理由；仅记实际调整，不为每个字建账。可以先保留大部分原稿，只有效果需要才动。

导演台本是本轮分镜展开的台词来源；改动艺术处理时同步它与分镜，不把初稿锁死为不可修订。不得为了给动作留空间机械删掉人物关系、恩怨、证据、因果、反转或转化功能。对白推进、独立留拍与全剧声音情绪的处理统一按“知识/导演思维.md”对应节执行。

## 阶段一·切分排镜（分镜骨架.md）

1. **状态追踪**：沿用连续性与状态管理，登记跨单元身份服装、剧情道具、状态转换、同场接点；普通背景陈设不逐项登记。
2. **由场面节拍切生成单元**：先找人物策略/信息/关系/决定发生变化的地方，再按D秒组合。台词按角色表达估算；普通动作可与台词并行，承担独立信息或选择的无台词动作/反应按串行时间预算，不重复计时。容量以知识/台词时长估算.md为准。装不下就重切，空余没有叙事任务就移动边界或合并，不填重复反应、慢动作或解释性废话。
3. **同场衔接**：叙事切点标硬切；同场被D秒截开，标“同场延续单元N·首帧承接”，列接点（人物｜位置｜姿态｜面朝｜手持物｜支撑物）。不要为技术切点重复已经说过的台词。跨场合并需明确硬切且挂两场景图。
4. **排镜**：先想整场可执行的空间与行动，再选择每一镜真正值得看的主体。景别由需看清的动作、关系、证据或表情决定。镜数由变化决定，不按角色轮转、不为单元凑镜数。每镜一行：叙事主体｜人物正在争取什么、主动作与结果/画面传递什么｜景别｜机位｜运镜｜出镜者｜导演台本台词或无台词任务。基调用于调性参考，不自动派发动作和切镜配方。
5. **挂载**：每单元按实际人物状态、场景、商品和关键道具安排，文件名与图片N序号对应，总数≤9张；产品展示挂真实产品图。素材较多时先重切，不撤必需素材凑数。
6. 写盘后直接展开，不另启动骨架审查或复写整段计划。

## 阶段二·完整提示词展开（分镜提示词.md）

开工材料＝本轮骨架＋导演台本＋原资产清单与风格。逐单元写完整独立代码块，不使用“同上”“沿用原台词”“按导演稿”等占位指令。

1. **单元结构与逐镜五件套**：继承成熟版技术格式。开头按挂载顺序定义人物、场景、产品，人物首镜复制素材描述块、后镜用锚点，场景直接声明使用场景参考；同场延续写首帧句。每镜具体写：
   ①机位与景别、单一运镜；让主动作相关身体部位及作用对象入画，物件镜说明观察归属，不硬塞人物脸；
   ②实际出镜名单、坐站与朝向；其他人物用虚化肩背、画外或完全不入画安置；
   ③服务人物目的的身体、手部与面部表演；静止或持续动作照实写，不给每句另添通用手势；
   ④角色名（声音状态）{导演台本中的台词}及口型归属锁句。说话人画外时明确画外原声，画内听者闭嘴，不能给画外人物安排可见动作。无台词镜直接写可见行动/声音，不为填槽增词；
   ⑤可见或可听的切镜触发；单元末镜写结束构图。变化尚在发生且值得看时可以保持镜头。
   角色首开口给完整声音DNA，后续保持同人声线，情绪转折处写本镜可听的声音变化（见知识/导演思维.md“声音要演出情绪的力度与变化”）。音效用<>，语气在{}外；对白不夹导演解释。光影、全局风格和“不要字幕/水印”约束在单元末写全。
2. **固定接口**：标题“## 单元N（…）”；每单元有“视频挂载：”实际文件清单、“生成参数：D秒，9:16，衔接：…”、“### 单元提示词”及独立代码块。正文仅“镜头N”，精确秒数留总表，不写提示词时间轴。所有提示词彼此自足。
3. **首尾帧与状态**：同场相邻单元尾帧句/首帧句画面内容逐字一致，并与末镜实际结束状态一致。硬切不强行续姿态。技术接点不把剧情冻结成没有变化。
4. **展开调整**：实际排镜确需调整，直接落在提示词与相关总表；涉及台词变化同步导演台本。提示词是最终镜头权威，骨架只同步影响分配/接点的必要处，不全篇重写。
5. **挂载回填隔离**：本轮实际挂载表写在本轮分镜提示词.md，不回填原资产清单，不改成熟分镜。
5.5 **本轮核对与交付**：写作完成时核对本轮导演台本与分镜的台词对应、产品/剧情关键事实、单元接口与素材编号、明显超时及接戏矛盾；创作改编不能按“与原剧本不同”误报。只修具体问题，不增加全片表演/措辞审查。用户对比的文字试验保持 fenjing_ready: false，状态写“导演分镜文字试验，待用户对比”；不将它报告成视频已验证。若后续用户要求进入实际生成，再由一个独立子任务按导演台本核对上述接口和接戏、核实缺失素材，局部修复后才置true，按另行授权提交。

## 试验交接

本技能默认交付文字导演分镜，不自动生成资产或视频。长期测试按轮保存，调用方在写作前保存本轮规则快照及输入来源，避免规则变化后混淆版本。用户指定子Agent测试时，让独立执笔者只拿新Skill与本集原始材料从头写，不预告主代理想看的镜头或改编答案；原版分镜仅在新稿完成后用于比较。

收尾给导演台本、骨架、完整提示词路径、时长/单元数、重要改编与保留处和真实未解决项。艺术效果交用户对比并以后续成片反馈修正，不用字数、镜数或技术核对替代创作评价。
