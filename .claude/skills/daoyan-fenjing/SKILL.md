# 导演分镜

项目根目录＝.。本技能为正式导演分镜入口，版本＝20261029-v6；维护源＝.claude/skills/daoyan-fenjing，Codex 发布副本不单独修改。成熟 fenjing 与其产物继续保留。

## 任务与授权

你负责把剧本变成观众愿意继续看的场面，再把场面写成可生成的分镜。先判断观众的代入、知情与期待，组织人物行动和情绪变化，再选择镜头、声音和节奏，最后适配固定生成单元。导演判断依据见“知识/导演思维.md”，不要把这一层简化为填基调标签。

2026-09-26 用户对本技能的明确授权：“我允许导演可以在写分镜影视化的过程中，修改台词，修改动作等等……不是必然要改，而是导演认为这一部分从文本到视频效果不太好的时候，那就可以自行调整。”

因此，本技能中导演可以按影视化需要删、合、改、增台词，调整说话顺序、动作、场面调度和开场呈现，不逐处请求确认，也不要求每场必须改。已经适合表演的原稿直接保留。调整须服务具体效果，如让关系更快可读、用行动承担说明、让情绪落点成立、使性格在选择中显现；不以缩字、改动率、镜头花样证明工作量。

保留故事核心人物关系、关键事实与因果、主要情绪兑现和结局，以及产品真实规格、价格、数量、使用方式与已确认信息。可以补充承载原戏的表演细节，不凭空增加改变主线的新人物、重大遭遇、身份或反转。文案事实内部冲突且无法由原始资料判定时才报告疑点。原二创稿和资产清单不回写；原稿到影视稿的必要调整记录在本轮分镜目录的导演台本中。

## 规则范围与读取

## 格式选择与转换路径

先区分新作分镜与已有分镜的纯格式转换。用户已指定或本轮已确认的格式直接沿用；明确使用万相/Wan时选万相格式，明确使用即梦/Seedance时选即梦格式。未指定且上下文无法确定时，默认使用万相格式，不再询问格式，不把渠道代号猜成模型。

| 本轮选择 | 只读这份格式要求 |
|---|---|
| 万相格式 | 知识/提示词格式-万相.md |
| 即梦格式 | 知识/提示词格式-即梦.md |

共用 `知识/提示词规范.md` 保留导演与制作约定；素材引用、台词定界、音效符号、镜头标签与时间码按所选格式文件执行，其他知识文件中的历史格式示例不覆盖它。格式选择不切换生成通道、模型或计费配置。

**只转换格式时**：读取用户指定的现有分镜、目标格式文件、共用提示词规范§七及跨层契约的解析接口；只有源稿含义不清时补读源格式或相关台本、资产对应项。跳过阶段零至阶段二的重新创作和独立生成测试要求。原分镜是本次转换来源，仅改变格式符号、素材指代和台词行表达，保留台词原文、说话人及顺序、镜头数与顺序、动作表演、声音状态、景别运镜、时长、素材文件与挂载顺序、首尾帧内容；落实已确认的无BGM约束。转换不是删改台词或重新切单元的授权。

默认在源稿同目录另存 `分镜提示词-万相.md` 或 `分镜提示词-即梦.md`；目标已存在则加序号，用户明确要求覆盖时才覆盖。文件头写 `提示词格式`、`来源分镜`，沿用原台本/骨架路径，不重写它们；`fenjing_ready: false`，状态为“格式转换完成，待目标通道生成预检”。交付前对照源稿核对上述内容保留及目标格式，不新增创作审稿或实际生成。只需转换时到此交付。

## 输入与版本

1. 用户点名的剧本是唯一创作来源；由 `/zichan` 衔接时，沿用其传入的本次剧本与故事目录。缺少标准二创稿.md但用户明确给出剧本时直接以该稿写导演台本，注明来源，不为此强制回成稿流程。
2. 新作分镜时长默认30秒，不再询问档位；用户明确指定15秒或30秒，或要求对比时沿用原版时长，则按指定执行。固定D秒是生成容器，不是剧情节拍，每套单元仍统一为D秒。
3. 产物按正常分镜落在 `stories/故事目录/分镜-{D}秒/`，包含导演台本.md、分镜骨架.md、分镜提示词.md；不再创建“导演分镜测试”文件夹或默认日期版本子目录。用户指定输出目录则使用指定目录。若目标目录已有完整分镜，按正常分镜约定确认重做还是修订；已有明确授权则直接执行，不重复询问。另一时长目录与历史产物保留。
4. 用户指定独立写作测试时，从指定规则与原剧本重新写，不读取旧分镜正文，不把旧分镜或上一轮导演稿当作底稿。可由调用方提供原版档位；资产清单内旧单元挂载表仅为历史，不沿用其切分。
5. 核对资产身份/状态、场景和商品实拍是否存在。本轮素材不足时列出待补素材，仍可完成文字分镜；不冒称素材齐全，不自行生成、付费或覆盖原资产。用已有素材能表现时优先据此调度。本集彩铅/写实开关沿用资产清单的已确认状态。产品规格.md若不存在，使用本集材料中明确记录的用户确认事实并标明来源，未知规格不推编。

## 阶段零·导演处理（先整体后单元）

读完全文再设计。把全剧的观众期待和信息释放、关键场面变化、角色在压力下优先保护什么、受什么刺激改变表达以及关键爆发怎样影响交锋、开头如何声画并行建立冲突、哪里需要紧接与停留，简洁写进分镜骨架.md的“导演处理”。具体说本剧，不复述知识条文，不逐镜另写问答。

默认执行“知识/导演思维.md”中的人物出场处理正式规则：对影响局势的关键出场，确定人物怎样进入、现场如何接住他的到来，并落实到导演台本和镜头中。

形成导演台本.md：按场景保存完整的影视化台词和关键动作，包含本轮原样保留的段落，不用“同原稿”省略。每段人物对话都确定可见表演由说者、听者或双方承担，把具体面部状态/变化及整段声音演法写进台本；允许平淡，但不能省略脸部表现。谁受到什么刺激、怎样接住对方回应，按知识/导演思维.md“每个人物对话镜都落实面部表演”执行；细分与复合表现从表演索引取参考。身体动作从同条参考按人设、关系、现有姿态与持物改写；普通段落可延续手头事，关键动作写起点、连续过程与终点，事件的发力、速度变化、冲击和余势也落实于台本，不只在总述贴标签。保留角色与场景对应，在末尾用简表记重要调整：原稿位置/原表达、本轮表达、影视化理由；仅记实际调整，不为每个字建账。

导演台本是本轮分镜展开的台词来源；改动艺术处理时同步它与分镜，不把初稿锁死为不可修订。不得为了给动作留空间机械删掉人物关系、恩怨、证据、因果、反转或转化功能。对白推进、独立留拍与全剧声音情绪的处理统一按“知识/导演思维.md”对应节执行。

## 阶段一·切分排镜（分镜骨架.md）

1. **状态追踪**：沿用连续性与状态管理，登记跨单元身份服装、剧情道具、状态转换、同场接点；普通背景陈设不逐项登记。
2. **由场面节拍切生成单元**：先找人物策略/信息/关系/决定发生变化的地方，再按D秒组合。台词容量统一按知识/台词时长估算.md中的当前语速值与公式计算；普通动作可与台词并行，承担独立信息或选择的无台词动作/反应按串行时间预算，不重复计时。装不下就重切，空余没有叙事任务就移动边界或合并，不填重复反应、慢动作或解释性废话。
3. **同场衔接**：叙事切点标硬切；同场被D秒截开，标“同场延续单元N·首帧承接”，列接点（人物｜位置｜姿态｜面朝｜手持物｜支撑物）。不要为技术切点重复已经说过的台词。跨场合并需明确硬切且挂两场景图。
4. **排镜**：先按整场空间与人物行动串起观众该看的画面落点，决定哪里换看、哪里留住，再分配台词；说话人更换不自动改变已选主体。每个人物对话镜明确面部表演主体是说者还是听者，或怎样由一方转到另一方，景别要让所写眉眼嘴部变化可读。镜数与单镜时长按知识/提示词规范.md §十四.1安排，切点由场面变化决定，不按角色轮转。每镜一行：叙事主体及说/听关系｜具体面部表现、主动作与结果｜景别｜机位｜运镜｜出镜者｜导演台本台词及声音演法或无台词任务。物件镜只写其实际内容，所在对话段仍须安排人物的可见面部表演。
5. **挂载**：每单元按实际人物状态、场景、商品和关键道具安排，文件名与图片N序号对应，总数≤9张；产品展示挂真实产品图。素材较多时先重切，不撤必需素材凑数。
6. 写盘后直接展开，不另启动骨架审查或复写整段计划。

## 阶段二·完整提示词展开（分镜提示词.md）

开工材料＝本轮骨架＋导演台本＋原资产清单与风格。逐单元写完整独立代码块，不使用“同上”“沿用原台词”“按导演稿”等占位指令。

1. **单元结构与逐镜五件套**：沿用共用接口及所选格式，按阶段一已定的画面主体与切点展开。开头按挂载顺序定义人物、场景、产品，人物首镜复制素材描述块、后镜用锚点，场景直接声明使用场景参考；同场延续写首帧句。每镜具体写：
   ①机位与景别、画面稳定质感与清楚的主运动；让主动作相关身体部位及作用对象入画，物件镜说明观察归属，不硬塞人物脸；
   ②实际出镜名单、坐站与朝向；其他人物用虚化肩背、画外或完全不入画安置；
   ③每个人物对话镜都在画面正文中写具体面部状态或变化，先明确由说者还是听者承担。眉形、眼睑、嘴角、下颚等怎样呈现，听到或说到什么后怎样变；只有站坐、盯视、持物、身体动作或对口型，不能代替面部表演。平淡也写可见状态，强情绪给短镜头能读到的幅度；不把所有变化收成微微抿嘴或一闪而过。画面中的情绪词、人物意图一律落实成可见指令，禁止用“神情复杂、认真划界”等概括充当最终表演。关键动作按起点→连续过程→终点写清身体、对象、速度及后果，跨镜承接实际状态；人物身份参考不锁表情。具体方法见导演思维，动作过程见提示词规范T27；
   ④每段连续发言给明确的整句演法：对谁在做什么、听起来是什么情绪与语气，以及随具体词句或对方刺激发生的可听变化。可写“憋着笑打趣、带哭腔求对方留下、压着火追问”等表演方向，再落实气息、语调、节奏、重音等有作用的变化；不能只列“某字加重、末字短收”。采用自然口语的连贯意群，声音身份与当句演法分开，不把全部角色念成同一节拍。画面句与声音句用触发或对应词句相连。画外发声标明角色的画外原声；听者不替其对口型，但可按描写张口、抿唇、哭笑或吸气，口型规则唯一出处为提示词规范§〇。无台词镜写可见表演及实际声音，不增台词填槽；
   ⑤本镜实际可见或可听的切镜触发，如某句刺中听者、手从物件上撤开、水撞上目标；不以“主动作完成后切”代替具体落点。单元末镜写结束构图。变化尚在发生且值得看时可以保持镜头。
   每个独立生成单元中角色首开口给音色身份（年龄感、音色与口音），并写当句演法；身份描述不固定语速、音量、句尾或情绪。后续直接写本段演法，不用“保持同一人的原声身份”代替它。声音与发音注记按知识/情绪表演参考.md“声音与断句”，在台词内容外表达；对白不夹导演解释。光影、全局风格和“不要字幕/水印”约束在单元末写全；每单元末写入知识/提示词规范.md §七的无BGM完整约束句。
2. **固定接口**：标题“## 单元N（…）”；每单元有“视频挂载：”实际文件清单、“生成参数：D秒，9:16，衔接：…”、“### 单元提示词”及独立代码块。正文镜头标签与时间码按所选格式文件。所有提示词彼此自足。
3. **首尾帧与状态**：同场相邻单元尾帧句/首帧句画面内容逐字一致，并与末镜实际结束状态一致。硬切不强行续姿态。技术接点不把剧情冻结成没有变化。
4. **展开调整**：实际排镜确需调整，直接落在提示词与相关总表；涉及台词变化同步导演台本。提示词是最终镜头权威，骨架只同步影响分配/接点的必要处，不全篇重写。
5. **挂载回填隔离**：本轮实际挂载表写在本轮分镜提示词.md，不回填原资产清单，不改本次目标目录之外的分镜。
5.5 **本轮核对与交付**：写作完成时核对本轮导演台本与分镜的台词对应、产品/剧情关键事实、单元接口与素材编号、明显超时及接戏矛盾；创作改编不能按“与原剧本不同”误报。同次自检直接读最终提示词：每个人物对话镜是否明确说者/听者及具体面部表现，是否用身体动作或“看着”替代了脸；情绪幅度与景别能否让短镜头读清；每段发言是否有整句情绪演法，还是只有重音和机械短收；听者是否被闭嘴限制冻结；身体动作是否按人物与现场改实、相关部位和对象是否入画，是否只在台本有动作而提示词丢失；关键动作的起点、过程、终点及后果是否接得上。有发音注记时，核对目标词实际出现位置与注记对应。只修具体缺口，不另设审核轮次，不按情绪词数量验收。文字交付保持 fenjing_ready: false，状态写“导演分镜文字完成，待生成预检”；用户明确做对比测试时，状态写“导演分镜文字试验，待用户对比”。不将文字交付报告成视频已验证。若后续用户要求进入实际生成，再按导演台本核对上述接口和接戏、核实缺失素材，局部修复后才置true，按另行授权提交。
