# Codex CLI 普通对话验证

本次范围：先在本机工作台内正常聊天。入口为左侧「自由对话」，接口选择「Codex CLI」。

- 沿用本机 Codex 的登录态和用户配置；本轮模型留空使用 CLI 默认模型，也可以填写指定模型。
- 点击发送直接启动聊天，后续消息带上当前会话最近的对话和用户钉住的记忆。聊天记录仍保存在工作台原有会话目录。
- 普通聊天使用独立临时目录和只读沙箱，不自动加载项目文档；本轮不调用拆解、选题或生产流程。现有执行策略没有关闭。
- CLI 标准输出按事件读取，只有完成的回复交给前台，并附带实际返回的 token 用量。执行日志与认证错误细节保留在后台，失败不自动重发。
