# 第一批：模型设置与资产操作台

本批实现日期：2026-09-05。入口：<http://localhost:3000/assets>。

这批将资产整理和执行从通用聊天入口中拆出来。分镜页保留原来的操作方式；选题、成稿、分镜生成、后期和复盘的专用操作区仍属于后续批次。

## 日常使用

1. 选择故事。已有清单、提示词与图片直接读入；没有方案时，读取本集二创稿生成方案，并由同一模型独立自查。方案完成后停在本环节。
2. 选择资产后直接编辑提示词。点击保存会先备份原文件。未保存的编辑保留在当前浏览器标签的临时缓存中，返回页面仍可继续；正式结果以项目文件为准。
3. “生成缺失与待重做”处理当前清单中的必要项。“生成所选”或“重做此图”只执行明确范围。依赖图缺少时，需要一并选中对应基础图。
4. 普通图片走所选图片接口；彩铅固定由 Flow 派生；场景四宫格由本地程序从全景底图派生。产品本体使用图库或导入的实拍照片。
5. 新图片通过文件格式、完整解码、尺寸等技术核对后，保存为新版本并回填当前清单。原图保留。替换基础图会将依赖它的派生图标为待重做，不自动扩大本次生成范围。
6. 需要讨论时，点击“与 Agent 讨论”。新对话带上故事、当前资产及提示词；默认路线只讨论，用户发送消息后才调用模型。
7. 本集必要资产齐全且技术核验通过时自动放行。也可以单独点击“核对已有文件”，恢复中断后的放行核对。

已有分镜仍保留原来的文件挂载。采用资产新版本后，若要让既有分镜使用新图，需要在分镜页调整对应挂载；本批不自动改写分镜或重投视频。

## 模型与 API

在资产页右上角打开“模型设置”：

- 文字生成、普通图片各有默认接口和完整模型名。
- 展开“按步骤单独设置”，可以覆盖资产方案模型、普通生图模型。独立自查沿用方案模型。
- 接口可用协议：文字 Chat 兼容接口、Responses 接口、自定义文字 Webhook、Images 兼容接口，以及本机 Codex CLI。
- 基础地址与端点分开，例如基础地址 `https://example.com/v1`，文字端点 `/chat/completions`，图片端点 `/images/generations`，参考图端点 `/images/edits`。
- Images 适配当前使用同步图片响应：`data[0].b64_json` 或 `data[0].url`。异步供应商需要独立适配，不能仅替换地址后假定通用。
- 密钥只在本机服务端保存；也可指定环境变量。API 响应不返回密钥。保存时密钥留空代表保留，清除需要勾选明确选项。
- 本机 GPTAPI 与 Flow 从项目原配置读取。Flow 的密钥继续在运行时从原 TOML 读取；不静默切换供应商，当前禁用通道不参与执行。

普通 Chat/Responses API 负责文字输出，本身不具备本地工具执行能力。CLI 模型名留空时使用 CLI 默认配置，记录会明确标注这一点；需要精确固定模型时填写完整模型名。

## 保存位置与恢复

- 正式产物仍是本集的 `资产清单.md`、`资产提示词.md`、`资产图/`。
- 新图使用带时间和唯一后缀的文件名，不覆盖旧图。
- 本集 `工作台记录/资产/` 保存任务记录、实际输入、参考图快照、模型选择、原始响应与技术核验结果。
- 本集 `工作台记录/文件备份/` 保存修改前文件与双文件事务记录。中断的写入在下次修改前核对恢复；外部编辑过的文件不会强行回滚。
- 工作台目录 `.local/models.json` 保存接口及步骤配置，该目录已排除在 Git 之外。

每次图片请求只提交一次。断线或结果未知时先保留记录并停止后续提交；刷新或重启服务不会重新生成。已有响应或下载文件可以“恢复已返回图片”。确实需要重做时，先在任务条目中填写原平台核实结果，再手动启动明确范围。

执行期间在其他软件中修改了提示词、清单、剧本或参考图，会保留新结果并停止自动采用。参考图实际提交的是本次快照，记录与提交内容保持一致。
