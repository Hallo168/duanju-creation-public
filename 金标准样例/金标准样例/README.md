# 金标准样例

来自《老爸的秘密》v3.3 制作包（2026-07-13），是用户认可效果最好时期的原始 TXT，未做任何改写。

- `GU-001_老爸的秘密.txt` —— 双机位电话戏（11 秒）。学它：机位的真实空间描述、声音事件触发切镜、逐镜表演微动作。
- `GU-014_老爸的秘密.txt` —— 单机位四人对白（13 秒）。学它：说话人/抢话/多倾听者反应分轨写、位置全部用现实锚点。

注意：这两条产生于按秒计费时期，时长 11/13 秒。现行按条计费规则下，新 TXT 统一设 15 秒、对白段装填 15-16 秒自然内容（lint 对旧时长只给警告）——**学的是写法，不是时长**。同理，老周的"老年稳定语速、力度克制"是这个角色的动机化写法，不是默认语速——新 TXT 默认写紧凑语速（01 规范 §3.6）。

治理红线：本目录文件只增不删、不改写；`python tools/lint.py 金标准样例` 必须永远 0 错误。新样例只收用户亲自认可成片效果的 TXT。
