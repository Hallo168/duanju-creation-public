# 02 资产与连续性规范 v4

（提炼自 v3.3 的 45/52/54 号规则，只保留防穿帮的实质内容。）

## 1. 人物资产板（9:16 四区）

- 单张 9:16 竖图，2×2 四区：左上正面平视头肩特写（唯一人脸身份锚点）；右上侧面或四分之三头肩；左下背面完整全身（头顶到鞋底）；右下正面身体（鼻尖以下到鞋底，不露眼眉额）。
- 四区同一人物：年龄、肤色、脸、发型、体型、服装、材质、曝光、白平衡一致。默认双手空手；固定佩戴物锁定位置；可移动物（手机、伞、包、商品）另建资产。
- **服装色彩在人物板阶段规划**：主要人物之间、人物与主场景之间用颜色和明度区分（藏蓝/灰绿/暗酒红/米白错开），避免全员深色衣服进暗景——那是画面显脏的常见来源；主体分离靠色彩，不靠加对比。
- 背景纯白或浅中性无缝棚；禁止任何文字、水印、Logo。
- 命名：`A0x_人物名_9x16_人物板_v0x.png`。

## 2. 场景资产（母场景 + 派生视角）

- 每个核心场景：`Sxx_M` 4:3 清晰母场景（锁空间结构、固定物、材质、现实主光、色温）→ 用户批准后派生 `Sxx_V01` 正打、`Sxx_V02` 反打、按需 `V03` 过肩/来向/局部。每张视角图只承担一个机位和朝向。
- 正反打必须是同一空间换机位：同一 180 度轴线、同一固定物、同一主光色温；A 视角画内的背景对应 B 视角摄影机背后的空间，物理闭合。禁止同侧背景复制、镜像翻转、两张图朝同一面墙。
- 派生前登记五项：摄影机实体锚点、看向方向、画内可见背景、摄影机背后空间、对向视角 ID。
- 视角图稳定标签只写"位置+朝向"（如"长椅左端朝右""入口侧朝证据展示区"），禁止携带人数、景别词（单人/双人/中景/近景/特写）——标签会被逐字写进每一镜的场景参考，带景别词迟早和镜头内容打架（lint 警告）。TXT 第 2 部分 @ 标签、文件名描述段与资产计划登记的稳定标签三处一字不差。
- 母场景先锁**明亮通透基线**（按 01 规范 3B 节写生图提示词）：人物预期活动区曝光充足、中低对比、黑位不死黑、白平衡中性、画面干净；正反打只换机位，不重新决定曝光、色偏和黑位。母场景图偏暗或偏脏时直接拒绝派生，回炉重生——基线错了后面每一段都脏。
- 面部光质基线：生活化场景的脸由现实来源的大面积漫射/反射光承接，配轻柔补光；眼窝、鼻侧、法令区、下颌阴影有细节且过渡柔和。
- 命名：`S0x_V0x_描述_v0x.png`。

## 3. 道具分级

| 级别 | 判定 | 处理 |
|---|---|---|
| A 普通道具 | 无剧情信息、无需特写 | 不生图，只写进连续性账本 |
| A+ 组合陈设 | 跨 2 段以上持续可见/参与动作/台词关注（如一桌饭菜） | 从已批准母场景派生一张 4:3 状态子图，锁数量、摆位、当前量、合法变化 |
| B 关键道具 | 证据/反转/特写辨认/递交打开抢夺/跨段重复 | 生 1:1 独立图，唯一资产 ID；相近证据分别锁材质、颜色、页数 |
| C 商品 | 带货商品 | 只用用户真实图，禁止 AI 重绘包装；按剧本列必需形态清单，缺形态图阻断分镜 |

## 4. 连续性账本（每个连续性组一张）

```text
连续性组ID / 覆盖生成段：
场景视角资产：
主光方向 / 色温（同组复用同一句核心光线描述）：
人物默认站位与左右关系（不换边）：
车辆/大道具方位锚点句（车头朝X、哪侧车身面向Y、驾驶门在哪侧，同组原句复用）：
固定道具位置：
可移动道具：归属人 / 左右手 / 握持点 / 初始位置 / 状态变化 / 结束位置
佩戴物锁定（哪只手哪根手指）：
后续才允许出现的资产：
本组禁止变化：
```

硬规则：

- 下一段首态 = 上一段尾态；姿态变化必须有动作桥（蹲→站要写"扶膝起身"）。
- 手部必须写左右手和握持点："右手握扇柄，扇面朝下停在胸口下方"；同一只手不占两个互斥道具；手部非重点时写"手部自然垂放，不持物"。
- 换机位只换视角，固定物不换方位；同组光线描述逐段原句复用。

### 并行生成与剪辑桥接

- 全剧默认**并行提交**：靠预设首尾态、连续性分组、统一资产锚点和左右关系锁定对齐，不等上一条成片截尾帧。
- 成片轻微割裂优先用剪辑解决：环境音/台词跨剪辑点（J-cut/L-cut）、反应镜头、手部或道具特写遮接点、场景切换加定场逻辑。
- 真实尾帧只用于返工：仅当首尾割裂严重、文字修正无效且是关键转折时，截上一条尾帧作参考图，提示词写明只继承站位、空间和光线，不复制动作。

## 5. 生成与审核流程

- 互不依赖的母资产（人物板、母场景、B 级道具）同一波次并发生成 → **用户集中视觉审核**；否决项汇总后整批返工，批准项作为父图派生子图 → 用户再审 → 真实文件名落盘，不逐张打断。
- Agent 只做确定性检查：文件存在、尺寸、格式、命名、数量、父图引用。像不像、美不美、一致性全部由用户裁决；除非用户点名排查，Agent 不打开资产图。
- **人物彩铅画可选门**：全部人物母资产和人物子资产完成并获用户视觉批准后，必须询问用户是否将全部人物资产转换为「彩铅画」。用户不同意则沿用原人物图进入下一环节；用户同意则以每张已批准人物图为图生图参考，只改变绘画媒介风格，不改变脸、五官、年龄、发型、体型、服装、佩戴物、手部、姿态、构图、分区、背景、光线、色彩关系或任何物件细节。全部彩铅版再次交用户集中审核；批准后以明确含“彩铅”的文件名替换正式人物资产，并同步更新资产计划及全部 Seedance TXT 第一部分中的人物参考文件名。进入下一环节前必须确定性检查：TXT 人物引用全部指向获批彩铅图、引用文件均存在、旧人物图引用为零。此门只处理人物资产，场景、道具和商品禁止转换。

## 6. 参考图预算

每条 TXT 最多 7 张，按叙事重要性排序：出场人物板 → 本段用到的场景视角 → 关键道具/商品。普通道具不为凑数上传；超 7 张时优先拆段或让场景图吸收固定陈设。
