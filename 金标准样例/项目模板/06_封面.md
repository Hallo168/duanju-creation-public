# 06 封面

视觉版式标准：`参考资料/封面拆解_8张参考.md`（7 条公式），对着它设计。文案与审核流程参考 `金标准样例/封面_老爸的秘密.md`。先综合完整剧本提出标题候选，等待用户选定后才允许生图。生图走默认 `tools/image_api.py --phase cover`，人物只能引用用户批准的真人写实人物板，禁止引用彩铅转换图；场景和关键道具继续引用已批准资产。封面候选图交用户审核后落盘。

## 要点（7 条公式速记）

- **一张剧照，不是海报**：单一电影感场景，人物长在环境里，环境/留白占 60% 以上，人物高度约占画面 1/5-1/3；禁止大半身怼镜头、多人等大拼贴。
- **短标题是第一主角**：候选以 2-6 字剧名式短题为主（如 阿黄/小满/累赘/第一次），各配一句小字 tagline 钩子（字距拉开）；问句式钩子只作 tagline，不作大标题。书法/手写体占画面 20-40%，落在天空/墙面等自然留白，单色无描边投影渐变，颜色从画面里取。
- **人物姿态三选一**：背影 / 远景 / 安静正面——优先背影或远景（留悬念且规避 AI 人脸风险）；禁止夸张表情和冲突抓拍。
- **全图一个色系**：中低饱和单色调，无第二抢眼色。
- **一图一个巧思，最多一个**：POV 手 / 俯拍 / 纵深引导线 / 三段式 / 拆字 / 前景道具对照。
- **信息极简**：大标题 + 一句 tagline + 固定页脚 `煎蛋有一手`（最下方正中一次，禁止添加“出品:”或“出品：”）；页脚必须使用清晰、完全不透明的中文手写体，并按实际底图明暗选择高反差单色，禁止与底图融合；可选小字演职员；除此无任何文字、Logo、水印。
- **标题后期贴字**：生图只出无字净版（标题落位区写明留干净负空间），标题用书法字库后期叠加——字不会错、矩阵可统一字体品牌。
