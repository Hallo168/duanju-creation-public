## 下载与启动

可以在 GitHub 点击 **Code → Download ZIP**，解压到自己的项目文件夹。也可以使用 Git：

```text
git clone https://github.com/Hallo168/duanju-creation-public.git
cd duanju-creation-public
```

网页工作台的 Windows 启动环境为 **Node.js 22.13 或更新版本**（含 npm）；生成与后期脚本还需要 **Python 3.13**，安装第三方 Python 服务时需要 uv。FFmpeg、剪映及各生成服务按使用的功能另行安装配置。

第一次使用，在项目根目录运行：

```text
python 初始化本地配置.py
cd tools\storyboard-workbench
npm ci
```

然后回到项目根目录，双击 **`启动工作台.cmd`**。页面默认打开 `http://localhost:3000/pipeline`，本地后台使用端口 4317。

在工作台的模型设置中配置自己的接口与密钥；使用本机 CLI 模式前，先确认对应程序在自己的电脑上能正常运行。公开版没有可直接使用的账号或模型额度。

图像检查、缩略图与四宫格功能还需要 Python 的 Pillow 包：`python -m pip install Pillow`。四宫格功能需要将 FFmpeg 加入 PATH，也可通过 `STORYBOARD_FFMPEG` 环境变量指定 `ffmpeg.exe` 的完整路径。使用其他 Python 环境时，可设置 `STORYBOARD_PYTHON`。

视频生成、资产生图和后期工具需要额外准备对应服务、真实产品图、软件路径与账号。第三方服务的安装方法见 [`外部依赖/README.md`](外部依赖/README.md)，各工具的用法见所在目录说明。生成任务会使用你自己配置的服务与额度。

## 更新已有副本

使用 Git 下载的朋友可在项目根目录运行 `git pull --ff-only`。若自己修改过规则或代码，先保存并提交自己的修改，再合并更新。使用 ZIP 下载的朋友，请解压到一个新文件夹，并迁移自己的本地配置和创作文件。

`初始化本地配置.py` 只补建缺失的配置，已有配置会保留。需要新增配置字段时，可对照最新的 `.example.json` 手动补充。

## 后期 Skill 与配套素材（2026-10-30）

完整入口为 `.claude/skills/houqi/SKILL.md`，规范见同目录 `知识/后期规范.md`。本次包含字幕提取／回写、人物介绍、配乐设计及音轨写入工具，156字幕样式、142人物介绍模板和对应字体、底板、动画资源；`配乐库/` 内同时提供索引和全部69个配乐／音效原文件。

先在项目根目录运行 `python 初始化本地配置.py`，再填写 `工具/剪映/剪映配置.json` 中的草稿根目录、剪映安装版本目录（内含 `videoeditor.dll`）。安装 FFmpeg 并加入 PATH，或在同一配置中填写 `ffmpeg`、`ffprobe` 的实际路径。后期脚本只使用 Python 标准库；剪映软件和 FFmpeg 由使用者在自己的电脑上安装。

模板资源保存为项目相对路径，写入草稿前按当前项目位置展开，项目可以放在其他磁盘或目录。准备自己的剧本、分镜、已拼接且识别字幕的剪映草稿后调用 `/houqi`。默认跳过封面生图，不需要为本轮后期调用生图服务。

可运行 `python 工具/test_houqi_portability.py` 验证资源寻址及隔离草稿写入；测试不操作个人创作草稿。音频索引中的来源和许可记录保持原样，选曲方式按后期规范执行。

## 分享范围

公开版保留项目流程和文本资料；账号档案中的原账号运营数据已去除，使用者应填写自己的资料。`.claude/` 提供项目命令、生产规范和配套脚本；默认分镜流程为 `daoyan-fenjing`，Dola 对白核对流程位于 `.claude/skills/dola-video-check/`。

文档中的 `<个人工作台>`、`<用户目录>` 等路径需要按自己的环境填写。Dola 对白识别所需的本地模型与账号渠道配置不随仓库提供，具体输入与依赖见该技能的 `references/jobs.md`。

以下内容保留在创作者本地，不随公开仓库提供：个人资料、账号与登录态、API 密钥、助手本机设置、运行日志与缓存、私人 Git 历史、创作视频与对白录音、其他私人图片音频、软件安装包、依赖环境，以及 `stories/` 内的创作工作区。后期所需的配乐、音效、字体与模板资源随本次更新提供。

三个配置模板分别位于 `工具/api配置.example.json`、`工具/symphony/symphony配置.example.json`、`工具/剪映/剪映配置.example.json`。填写后的 `.json` 本地配置和工作台运行数据已列入忽略规则，请勿强制添加到公开 Git 仓库。

公开版中的历史说明可能引用仅在原项目保留的素材或历史记录；这类素材引用不属于本次分享内容。生产与复盘请以自己的素材、商品事实和数据为准。

当前创作规则已于 2026-09-11 停用流量集，使用带货集流程。旧工作台代码仍保留流量集兼容分支，对应旧模块已归档，不应继续选择流量集生产。
