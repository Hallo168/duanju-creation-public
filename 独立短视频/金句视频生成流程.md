# 金句视频生成流程

> 沉淀自 2026-08-05～08-06「孝道金句」两批共30条15秒视频的实操踩坑。这是**独立标准外的一次性小批量视频生产流程**，不挂靠 `stories/NN-故事名` 系列（无原稿/无发布环节），产物统一放 `独立短视频/{系列名}-{日期}/`。适用场景：单人独白型金句短视频、语录卡点视频这类"一个简单画面+一句能打的台词"的内容，不适合有多人物多场景的正常剧情集（那种走 /xuanti → /erchuang → /zichan → /fenjing 正常流水线）。

## 一、选题：先出金句，不是先出剧情

**金句 ≠ 场景对话**。判断标准：这句台词单独拎出来，脱离画面也能当一条文案发朋友圈/短视频文案库，才算金句；如果这句话只在这个具体场景里说得通（比如"你别嫌我笨，教我一次我忘一次"），那是生活化对话，不是金句。

金句常见句式（可复用）：
- 对比句："你以为的'X'，是我们正在经历的'Y'。"
- 排比/总结句："我们最长情的话，就是'X'。"
- 反常识句：把一个被忽视的行为翻译成付出（"陪伴不是有空才给，是把有空留出来。"）

每条选题只需两行：一句话画面动作 + 一句金句台词。画面动作必须**具体可拍**（一个手部动作/一个表情转变），不要写抽象场景。

选题批量产出后**先给用户看，等确认**再进入生产——写选题本身不花钱，但后面的图/视频生成都要花钱，选题阶段是唯一免费的把关点。

## 二、人物资产：双格设定图 + 彩铅派生（唯一正确流程）

> 这是本次踩坑最重的环节，两次因为图错了报废视频、烧了积分。血的教训写在下面。

### 2.1 硬规矩（不能绕过）

1. **写实图必须走 chatgpt2api（GPT-Image-2），不能走 flow2api 直接文生图**——flow2api 只吃"一张已有写实图"做风格转换，本身不适合从零文生图出人物；反过来，**彩铅图必须走 flow2api Banana2，不能用 chatgpt2api 生成"看起来像彩铅"的图**。两个模型职责不能换：chatgpt2api 负责写实底稿，flow2api 只负责在写实底稿上转笔触。
2. **写实图提示词必须显式写"中国人/中国老年女性/东亚人面部特征"**——不写族裔限定词，Gemini/GPT 系图像模型默认生成欧美人脸，这是本次两次报废视频的直接原因（一次错用了 chatgpt2api 生成假冒"彩铅"、一次是 flow2api 文生图没写族裔）。
3. **固定双格竖版布局**（2026-08-05 项目终版规则）：一张图里上格=正脸头肩近照，下格=正面全身照，白色细分隔线，两格必须同一个人（同脸同装同体型）。整图作为**一个挂载位**使用，不要拆成两张图分挂。

### 2.2 标准两步生成模板

**第一步：写实人物设定图**（chatgpt2api，文生图，无需参考图）

```
生成一张竖版2行1列人物设定图，两格上下排列、白色细分隔线：上格正脸头肩近照，下格正面全身照。
中国老年女性，六十二岁，圆脸，银白短发，藏青色针织衫，神情平静。两格为同一个人，五官、脸型、年龄、发型、服装、体型完全一致；全身格从头到鞋完整入画，自然站立，双臂自然下垂，表情平静。
纯白背景，均匀影棚光，无投影，无文字，无水印。写实电影质感短剧风格，中国内地城市普通家庭人物，东亚人面部特征。
```

**第二步：彩铅参考图**（flow2api Banana2，图生图，唯一输入=第一步的写实图）

```
不改变图片，把图片风格转换成素描彩铅画
```
固定参数：模型 `gemini-3.1-flash-image`，输出 9:16，1K。**这个提示词逐字固定，不要自己改写**。

### 2.3 用统一脚本批量执行

不要手写 curl，统一用 `工具/gen_grids_multi.py` 吃一个任务 JSON：

```json
{
  "output_dir": ".\\独立短视频\\{系列名}-{日期}\\资产图",
  "tasks": [
    {"id":"R1-real","file":"R1-{角色}-日常-人物设定图.png","size":"1024x1536","prompt":"<写实图提示词>"},
    {"id":"R1-pencil","file":"R1-{角色}-日常-彩铅参考图.png","size":"1024x1536","prompt":"不改变图片，把图片风格转换成素描彩铅画","refs":["R1-{角色}-日常-人物设定图.png"],"provider":"flow2api_banana2"}
  ]
}
```

```bash
python 工具/gen_grids_multi.py "工具/运行垃圾/tasks/{任务目录}/task_plan.json"
```

脚本按 `refs` 字段自动分两层跑（先出全部写实图，再用写实图做彩铅派生），**任务幂等**——已生成的文件会被跳过（SKIP），失败的会重跑，直接重复执行同一条命令就是重试机制，不用手动挑哪些失败了。

### 2.4 已知会失败的点

- **chatgpt2api 偶发超时**（120秒等待超时）：重跑一次通常就好，不用换通道。
- **flow2api 偶发 HTTP 500（Project-scope 错误）**：账号侧限流/配额问题，重跑通常能过；如果单张反复失败 3 次以上再考虑降低并发或换时间段。
- **flow2api 派生任务因为 ref 缺失级联失败**：如果对应的 real 图那一步失败了，pencil 那一步会报 "ref missing"，属于正常级联，重跑整个 task_plan 会自动把两步都补上。

### 2.5 生成后先自查，不强制用户逐张看

按项目"图片审核归属用户"的规则，执行者只做技术性核对（接口成功/文件存在/尺寸对不对），不主动评价画面内容。但**族裔这一条例外**——如果提示词没写"中国人/东亚"，生成结果大概率是欧美脸，这属于提示词本身的错误而不是"画面内容评价"，执行者应该在写提示词阶段就把这条硬规矩钉死，而不是等用户看了图再发现。

## 三、分镜提示词写法（单人独白专用简化版）

金句视频通常是单人独白，不需要复杂的多镜头正反打。标准结构：**2镜**，不写空镜：

- **镜头1**：一个具体小动作（数钱/关灯/翻相册/系纽扣……），带出情绪，不说话或只有半句台词
- **镜头2**：推近到面部特写，说出完整的金句台词，结束帧定格在说完话的表情上

```
将图片1中的[2-3个静态特征]定义为主体1（角色名），面部与穿着参考图片1。场景：[一句话场景]，[光线描述]。

镜头1：固定镜头(fixed)，中景。[角色]（[2个锚点]）[一个具体动作，带一点情绪信号]。

镜头2：缓慢推镜(push in)，中近景，[角色]面部特写。[表情变化的一个动作]。
[角色](语速+语气标注){金句台词}

[光线描述]，画面干净，写实生活质感短剧风格。人物面部与参考图完全一致，服装全程不变，无背景音乐，「生成视频不要出现任何字幕」，不生成水印，视频全程禁止出现外形、着装、配饰完全一致的人物，不生成同款分身或双胞胎效果，每个角色在同一画面中只出现一个。结束帧定格：[说完话后的静态画面]。
```

**踩坑提醒**：`分镜提示词.md` 的 frontmatter 必须带 `fenjing_ready: true`，否则 `symphony_video_batch.py` 的 preflight 会直接报错拒绝往下走（这是给正常 `stories/` 集准备的校验，独立批次也要满足这个字段才能过）。

## 四、Symphony 提交全流程（标准四步，不要抄近道）

```bash
# 0. 起代理（如果还没起）
工具\symphony\启动代理.cmd

# 1. preflight —— 免费，检查挂载文件是否齐全、算出总积分预算
python 工具/symphony_video_batch.py preflight --story-root "独立短视频/{系列名}" \
    --prompt-file "分镜-15秒/分镜提示词.md" --units 1-20 --model "Dreamina Seedance 2.0"

# 2. warmup —— 免费，把参考图预存进 Symphony 缓存，让后续能走全静默 direct 通道
python 工具/symphony_video_batch.py warmup --story-root "独立短视频/{系列名}" \
    --prompt-file "分镜-15秒/分镜提示词.md" --units 1-20

# 3. submit —— 正式花钱，--confirm-credits 必须精确等于 preflight 报的数字
python 工具/symphony_video_batch.py submit --story-root "独立短视频/{系列名}" \
    --prompt-file "分镜-15秒/分镜提示词.md" --units 1-20 --model "Dreamina Seedance 2.0" \
    --confirm-credits 300 --backend direct \
    --ledger "工具/运行垃圾/tasks/{任务目录}/symphony-ledger.jsonl"

# 4. poll —— 轮询直到全部终态，自动下载+ffprobe核验分辨率
python 工具/symphony_video_batch.py poll --story-root "独立短视频/{系列名}" \
    --prompt-file "分镜-15秒/分镜提示词.md" \
    --ledger "工具/运行垃圾/tasks/{任务目录}/symphony-ledger.jsonl"
```

### 4.1 warmup 常见偶发失败：浏览器拖拽 flake

一批 9 张图里有时会有 1 张"没挂上composer"导致整批（这一批的全部图）回滚失败，报错形如 `reference image "xxx" did not attach to the composer`。**这不花钱**（warmup 本身不扣积分），直接重跑同一条 warmup 命令即可，脚本会自动跳过已入库的图、只重试没入库的那批。通常重跑一次就过；如果连续两次同一批还是失败，缩小 `--units` 范围分批重试。

### 4.2 单账号日限：分账号提交

单个子账号提交多了会触发"日限"，报错 `ABORTED unit=N account=默认账号 达到发布数量上限`。解法是加 `--main-accounts all`（把两个主账号下所有子账号都纳入轮转池）+ `--resume`（跳过已成功提交的单元，只补没提交的）：

```bash
python 工具/symphony_video_batch.py submit ... --main-accounts all --resume --confirm-credits <剩余单元的积分和>
```

**注意 `--confirm-credits` 要重新算**——是"本次实际还要提交的单元数×15"，不是总预算数字。

### 4.3 提交后两类失败，处理方式完全不同

| 错误类型 | 报错特征 | 是否扣分 | 处理方式 |
|---|---|---|---|
| **人脸隐私检测** | `InputImageSensitiveContentDetected.PrivacyInformation` / `face detect not pass` | 会退款 | **换参考图**：用同一张写实图重新跑一次 flow2api 派生，生成一张新彩铅图（文件名加 `-v2` 后缀，别覆盖旧图），分镜挂载行改指向新文件名，重新 warmup 该角色，再单独重投这一个单元 |
| **内容审核拒绝** | `platform_code: 10001304 / This content may violate TikTok's Community Guidelines` | 不扣分（没建任务） | **优先怀疑参考图，不是文字**——本次实测：换了两次台词措辞（去掉"药"相关词）没用，换参考图（重新派生一版彩铅图）一次就过。别在文字上反复试，直接换图 |

两种情况都遵循"旧图不删、新文件名加版本号"的规则，方便回溯。挂载行改法：直接把 mount token 写成**带 `.png` 后缀的完整文件名**（比如 `R6-母亲-日常-彩铅参考图-v2.png`），这样脚本走精确文件名匹配，不会因为同前缀多个候选文件而报"匹配到多个文件"的歧义错误。

### 4.4 重投单个单元的四连招

```bash
# 1) 重新派生新版彩铅图（temp task json 只放这一个 R 的 pencil 任务，refs 指向已有写实图，file 名加 -v2）
python 工具/gen_grids_multi.py "<临时task_plan.json路径>"

# 2) 改分镜提示词.md 里该单元的"视频挂载"行，指向新文件名（带.png后缀，精确匹配）

# 3) 只热预存这一张新图
python 工具/symphony_video_batch.py warmup --story-root "..." --prompt-file "..." --units <N>

# 4) 只重投这一个单元
python 工具/symphony_video_batch.py submit --story-root "..." --prompt-file "..." --units <N> \
    --confirm-credits 15 --backend direct --ledger "..." --resume
```

## 五、成本参考（本次实测）

- 写实图 + 彩铅派生：两个通道都免费/包月，唯一成本是等待时间（chatgpt2api 约30秒/张，flow2api 约1-3分钟/张）
- Symphony 视频：1秒=1积分，15秒视频=15积分/条；审核拒绝不扣分，人脸隐私检测失败会退款，只有真正渲染成功才扣钱
- 20条批次实测：首次提交全对的情况下总花费=条数×15；因为参考图问题需要重投的单元，每次重投视为一次独立的15积分消耗（旧的失败任务已退款，不重复扣费）

## 六、这次犯过的错误，别再犯

1. ❌ 直接用 chatgpt2api（GPT-Image-2）文生图冒充"彩铅参考图"——彩铅必须是 flow2api 对已有写实图做图生图转换，这是项目硬规矩（CLAUDE.md 硬性规则），不是可选项
2. ❌ 写实图提示词没写族裔，默认生成欧美脸——中国短剧人物必须显式写"中国人/东亚人面部特征"
3. ❌ 猜测审核拒绝原因时先改文字——应该先怀疑参考图，参考图更换的命中率高得多
4. ❌ 忘记给独立批次的 `分镜提示词.md` frontmatter 加 `fenjing_ready: true`——这不是 stories/ 系列专属字段，独立批次一样要满足
