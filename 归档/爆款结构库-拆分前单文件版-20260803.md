## 带货剧本的通用公式

对六篇带货对标做横向对比，正式带货前的铺垫惊人一致：

**憋屈/测试铺垫 → 善良行动证明 → 产品轻伏笔（或身份任务）→ 身份揭晓打脸 → 正式带货 → 返回剧情收束 → 破壁提问引导评论**

带货话术内部也有固定链条：
**痛点场景化 → 旧方案缺点对比（自己熬麻烦/老式樟脑丸刺鼻/停电抓瞎）→ 成分材质背书（口语化报成分）→ 使用场景铺开 → 边界声明（不是药/明火注意安全）→ 原价锚定 → 活动价+数量强化（"一盒不到两块钱"）→ 包邮 → 渠道指引（点头像进直播间/主页橱窗）→ 稀缺促单（库存不多/卖完恢复原价）→ 情感号召（给爸妈备点）**

三个反复出现的高级技巧：
1. **产品轻伏笔**：产品第一次出现只是一个善良动作的工具（冲一杯给孩子、递一包防潮），不展开卖点；正式带货放在身份揭晓、信任建立之后。
2. **对话式带货优于独白式**：让家人/婆婆/同事问"贵不贵""老人能喝吗""味道冲不冲"，卖点在一问一答里出来（保洁母亲篇是范本）；独白式则需要捧哏角色（助理惊呼"这个价格连快递费都盖不住了，您确定吗？"）。
3. **收束用"利他条件"**：正面角色胜利后不要钱，提一个利他的条件（摊位留凳子热水、给修车师傅备樟脑丸），价值观和产品绑定，同时给了产品第二次出场理由。

### 绿豆沙 · 集市阿婆试人心
- **核心机制**：隐藏身份 + 人性测试 + 证据回放打脸
- **人物配置**：隐藏身份的测试者（阿婆+孙女）、反派（自私摊主）、正面主角（周兰）、揭晓工具人（工作人员）、和事佬（老许）
- **结构链**：弱者求助被辱 → 反派两层压迫 → 主角放下自己的事出手相助 → 产品轻伏笔（冲绿豆沙给孩子）→ 工作人员登场揭晓阿婆身份 → 监控回放打脸 → 主角获摊位但提利他条件 → 正式带货（生活化讲解）→ 给反派递绿豆沙完成教育 → 孩子对镜头提问
- **产品切入**：生活痛点（孩子饿渴），主角"出门常备"
- **可复用点**：回放打脸（把反派的话原样放给她听）；"东西不贵，递出去的时候人心就看见了"式的产品价值观绑定

### 绿豆沙 · 保洁母亲试儿媳
- **核心机制**：长辈装穷试人 + 对照组（拜金女 vs 真女主）
- **结构链**：母子争执点题 → 拜金女登场羞辱保洁离场 → 真女主登场蹲下帮忙擦桌子 → 产品切入（女主主动去拿，冲给"保洁阿姨"解暑）→ 全对话式带货（婆婆问、男主帮腔）→ 身份揭晓（房东）+ 五万见面礼 → 女主拒收 →"对妈妈好"作为答应条件
- **产品切入**：生活痛点（食堂闷热），女主自备
- **可复用点**：**对话式带货范本**——每个卖点都由剧中人问出来；女主被揭晓后说"我不太喜欢被这样测试"，让人物真实不工具化

## 流量剧本

流量剧和带货剧是**两套不同的情绪引擎**：带货剧靠"羞辱→打脸"换转化，流量剧靠情感共鸣换完播和转发。流量剧内部又分两条路线：

- **误会温情型**（回娘家篇、电饭锅篇）：没有反派，冲突全来自误会或善意隐瞒，结尾全员体面，暖感驱动。
- **对照打脸型**（拆迁款篇）：有反派（不孝子女），靠"心疼+愤怒→善良兜底"驱动，善恶两组子女对照，正面角色用放弃利益的骨气完成道德打脸。像带货剧的骨架但不带货，情绪回报是"老人被善待"。

### 金句四技法（从"拆迁款拆散老两口"篇提炼，两类流量剧通用）

1. **小物象扛大情感**：拿最便宜的具体东西对最重的情感账——"咱家多双碗筷也穷不了，可妈少了爸的陪伴，心里一辈子都凉了"。碗筷越小，凉越重。
2. **因果循环式**：把孝道写成会报应的因果——"今天咋对父母，明天孩子就咋对咱"。观众转发它是在提醒自己的家人，自带传播动机。
3. **旧俗语翻新**：先引一句人人认识的老话（"少年夫妻老来伴"），再接自己的新话，熟悉感降低接收成本，新表达负责记忆点。
4. **"不是X，而是Y"句式**：先否定一个世俗答案，再给情感答案——"人这一辈子最大的福气，从来不是家财万贯，而是父母康健常相伴"。

反例参照：平铺直叙的价值观陈述（"要对老人好""陪伴很重要"）没有对比、没有物象、没有因果，就是没劲的金句。

### 拆迁款拆散老两口（对照打脸型）
- **核心机制**：不公平的养老安排 + 善恶儿媳对照 + 骨气式放弃利益
- **结构链**：拆迁款两家平分、老人一家养一个（隐患开场）→ 二儿家暖场接待 → 老两口深夜通话互报平安却落泪（"老来伴被拆散"痛点引爆）→ 二儿媳追问真相、哭诉价值观（第一波金句）→ 切大儿家虐待实况（老人跪着擦地，愤怒拉满）→ 二儿夫妇上门接人、当面放弃五十万（骨气宣言+道德打脸）→ 老两口团圆握手 → 厨房门口夫妻对话（第二波金句）→ 面向镜头求支持
- **可复用点**：老两口电话里互相隐瞒报平安（双向善意谎言，一个电话同时立起两位老人）；"钱一分不争"的骨气宣言把道德优势推到顶；**求支持式结尾**（"你们支持吗？"）比开放提问更容易收获站队评论
- **金句排布**：两波，第一波在中段愤怒顶点（二儿媳哭诉），第二波在结尾回暖处（厨房门口），不挤在同一处

### 回娘家照顾姥姥（误会型温情反转）
- **核心机制**：好人先被误判 → 实物证据揭晓 → 金句轰炸
- **结构链**：母亲小心翼翼开口想回娘家 → 儿子冷淡支走她收衣服（制造误会）→ 儿媳两次质问拉满误解 → 反转：儿子拿出车票、两万现金、降压药，还联系了舅舅和表弟 → 金句爆发（"孝顺父母不是请假，也不是求批准"；"给钱是孝，陪伴是孝，耐心听完唠叨也是孝"）→ 面向镜头独白升华
- **可复用点**：反转靠**实物证据**（车票/现金/药）而不是口头解释；误会期间让第三方（儿媳）替观众质问；金句放在情绪顶点由当事人说出
- **发布逻辑**：中老年观众会因认同孝道金句而转发，金句就是传播钩子

### 电饭锅没煮熟（小事见修养型）
- **核心机制**：一件小事 + 瞒住的体贴 + 圆场话术
- **结构链**：婆婆饭没煮熟（自己不知道）→ 儿子发现后不声张，打电话让媳妇买馒头 → 玄关处教媳妇"对父母多包容"（金句：脾气少三分，福气厚七分）→ 餐桌上婆婆疑惑 → 儿子用"女儿想吃馒头""电饭锅坏了"双重圆场 → 婆婆自责时用"红烧肉蘸馒头是绝配"化解 → 合家欢收尾
- **可复用点**：全剧只有三场、一个道具（馒头），极轻量；"如何体面地帮长辈遮住小失误"本身就是可无限换皮的选题模板（忘关火、买错东西、记错日子……）
- **发布逻辑**：短、轻、金句密，赌的是完播率和"@我家那位"式评论

### 窝里横（镜像体验教育型）
- **核心机制**：以其人之道还治其人身——长辈用施压者的同一种沟通方式反过来数落他，让他亲身体验委屈后自省
- **人物配置**：被教育者（前半段施压者→后半段醒悟者）、承压者（观众代入对象）、教育者/正义执行者（用镜像法+历史回放完成教育）

- **情绪路径**：愤怒→期待→解气→心酸→感动释然，峰值在镜像揭穿和闪回
