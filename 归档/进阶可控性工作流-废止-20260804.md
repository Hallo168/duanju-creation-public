## 一、长视频丝滑连贯三步法（李一帆）

**核心认知**：AI 长视频翻车不是模型弱，是"硬续长镜头"。电影本来就不是一镜到底，是靠**镜头组接**叙事。把电影剪辑法搬进来，多少段都能像一个镜头拍的。

### 方法1·切换景别和角度衔接（基础）
- **病根**：把**相似景别/相似角度**的两段连在一起 → 观感怪、卡顿
- **做法**：截取上段视频的**尾帧** → 用"九宫格多机位"生成同场景多角度画面 → 选一张**不同景别 或 不同角度**的画面，作为下一段的**首帧** → 生成
- **原则（记死）**：相邻两段之间，**要么换景别、要么换角度**，靠画面切换自然衔接（这就是电影剪辑最基本的技巧）
- 对我们：单元 B级软衔接"主动换景别制造剪辑点"就是这条，已在用；补充"换角度"也同样有效

### 方法2·在动作中衔接（进阶·最精妙）★
- **做法**：故意让相邻两段**保留一段相同的重叠动作**来衔接
  1. 在上段视频里找到某个动作的**起始帧**（例：女生"拿起咖啡"的起手）→ 截取当前帧
  2. 该帧 → 九宫格多机位 → 选一张**有景别/角度变化**的图
  3. **关键写法**：下段提示词**不要写"喝咖啡"，要写"女生继续抬起咖啡杯，举到嘴边轻轻喝一口，随后放下"**——用"**继续**[动作]"而不是写一个新动作，逼动作**重叠**
  4. 生成后把两段的动作**对齐**，**剪辑点放在动作进行到一半的位置**
- **原理**：视觉暂留（影像在视网膜停留 0.1–0.2 秒）+ 物体（咖啡杯）运动轨迹连续 → 大脑自动衔接前后帧，**察觉不到切镜**
- 对我们：**升级 A级硬衔接**。以前我们只写"尾帧当首帧续动作"，现在加两条硬技巧——①下段提示词用"继续[动作]"制造重叠 ②剪映里剪辑点卡在动作中段。这是消除拼接感最强的一招

### 方法3·不硬续，用分镜组接（终极）
- **做法**：故事板阶段就把镜头拆成**15秒内能完成的小剧情**
  1. 剧本上传 AI → 生成**带时间标注的分镜头脚本**
  2. 每次选**累计≤15秒**的若干镜头组接（例：4+3+3+4=14秒 一段）
  3. 人物设定图 + 场景参考图 一起喂 AI → 得到第一段/第二段/第三段，**每段只负责一个剧情阶段**
- 对我们：这就是现行切单元规则（CLAUDE.md 硬性规则2），已是默认流程，无需另行执行

## 二、粘土白膜故事板工作流（爱周宝 / AIGC作业本）

**核心认知**：用**线稿**故事板生成视频，经常"分镜对不上"（站位、空间、镜头角度乱）。换成**粘土白膜（灰模体块）**的故事板后——站位、空间关系、镜头角度都更准，更接近真实摄影，更可控。原因：**白膜的人物体块比线稿清楚**，站位空间关系一目了然。

**三步工作流**（原视频用 ShowRap/SOBT 画布，可迁移到我们的 GPT Image + 即梦）：
1. **锁角色+场景**：上传角色图、场景图 → 生成**角色身份板** + **场景设定图（含主场景、反打视角、侧视角、俯视角四个角度）**——牢牢锁定角色和场景的空间关系
2. **出白膜故事板**：框选角色+场景设定图 → 图生图（原用 image2/Nano Banana 类）→ 提示词生成**粘土白膜的故事板图**（灰模体块摆出站位和构图，不追求精致渲染）
3. **白膜转视频**：框选 场景设定图 + 白膜故事板 → 即梦 Seedance 2.0 → 视频提示词 → 生成。成片的人物站位、镜头角度、空间关系都贴着白膜稳定复刻

- 用途：**AI 视频预演 + 动作分镜测试**（先用白膜低成本验证构图对不对，再上精细生成）
- 对我们：首帧关卡**默认跳过**（2026-07-12 裁定，提示词规范 §十二），本手法是 J3 类翻车修复与"首帧图生视频"降级路径（CLAUDE.md 规则9）的按需工具——需要出首帧图的场合，**先出白膜体块图锁站位/构图/机位角度，确认了再补细节生成**；"分镜对不上/构图跑偏"类翻车，白膜比改文字更根治

**★链式传参防偏移**：规则本体= `资产生产规范.md` §三点五（Z8）——序列每张挂角色图＋场景图，第N张必挂第N-1张当参考。

## 三、场面调度图（刺猬星球 super-i）

**核心认知**：从"九宫格俯视场景图"升级成"**调度图**"。电影手绘分镜里这种图出现频率最高——**既告诉演员怎么走位，也告诉相机怎么拍**。描述清楚，AI 就能 1:1 复刻轨迹。

**四步做一张调度图**：
1. **拿到俯视底图**：让 AI 按剧本反推场景提示词 → GPT Image 生成九宫格场景图 → **单独提取第 9 张（俯视图）**当调度底图（顺带得到一张完整九宫格场景资产图）
2. **标人物站位**：在俯视图上圈出站位（1号位=女主、2号位=男主）——可以用设计软件画，或把俯视场景图喂 AI + 提示词描述站位 → 生成带站位的俯拍调度图
3. **画移动轨迹（关键）**：用笔把人物移动路线画出来，**不同颜色代表不同人物**（绿色=女主、蓝色=男主）→ 图传给 AI + **提示词说明每条颜色代表谁** → AI 稳定理解走位
4. **加镜头机位**：机位**别手绘**（画不精、不专业）→ 把"已画好人物运动路线的俯视图"给 AI，**让 AI 根据人物走位反推镜头机位**
- 最后：调度图等资产 + 视频提示词一起喂即梦 → 能生成复杂的**打斗、追逐、一镜到底**
- 对我们：**全新手法**。复杂走位单元（多人错位/追逐/绕行/一镜到底）除了写实人物设定图+场景图，**额外挂一张彩色轨迹调度图**，提示词写明"参考图N为俯视调度图，绿线=XX走位、蓝线=XX走位，机位按图"。常规对话正反打用不上

## 四、跨镜连续性硬锁·四件套（2026-07 研究固化，L1 图像硬锁层）

> 定位：文字锁不住空间态（站位/姿势/道具位置/瞬时状态），要真锁死只能靠图像（见 `连续性与状态管理.md` 三层锁定模型）。以下把"状态钉进图里"，按需启用；纯参考图+文字工作流不产出这些图时，站位/瞬时状态只能靠 L2 文字层尽力+剪辑规避。

1. **首尾帧链式**【备用手段（2026-07-23 确认保留）：本手法仅在 /xiufu 修复或用户点名时启用】：上段成品尾帧＝下段首帧（即梦"视频延长"／可灵首尾帧）。要点：①收尾用**中性姿态**（双手自然下垂、表情平静），别在大动作中间截断，否则下段起手僵；②首尾两帧的光线/色调/构图**提前对齐**，差异过大会触发硬切而非平滑过渡；③连续延长≥3段要**重启**（拿前段成品当新起点）防画质/姿势衰减累积；④每次延长**重复一遍角色描述**，模型会"遗忘"外观。三档句式与抽帧操作见本节末尾**§四1 附录**。〔证据：CSDN 即梦Seedance2.0全能参考指南、可灵首尾帧教程〕

2. **状态突变=强制过一次关键帧**：凡不可逆状态变化（打翻/破碎/弄湿/撕破），把**变化发生那一刻的画面**单独存成图，后续镜头固定拿它当场景参考图——别指望文字"桌上有打翻的水"让模型自己记住（业界公认无纯文字解，arXiv CausalCine 论文佐证：奶流/壶位/手势跨镜不连续）。这是"打翻的汤下一镜恢复"唯一可靠解。

3. **九宫格关键帧**：一张 3×3 图＝一段视频的关键帧序列，模型按格从左到右、从上到下**插值**成连贯视频。出图硬约束"人物/服装/环境/光线/风格 9 格完全一致，仅允许改动作/表情/机位/构图/景深"；转视频写"按九宫格顺序演绎成一段视频，不要整图生成"。锁站位构图最强的前置手段。〔证据：知乎《9宫格分镜转视频的四种高级玩法》〕

4. **空镜画框锁站位 + 色彩隔离轨迹**：先出无人空镜→图上画闭合框圈站位、彩色箭头标各角色走位（不同颜色=不同人）→当参考图喂入，提示词末加"生成后去掉框线/箭头"。**这是"纯文字锁站位不可靠"的降维打击**——图像空间信号比文字强数十倍。〔证据：CSDN《玩转AI空间控制：告别人物乱放》〕

### §四1 附录·A1/A2/A3 尾帧续画句式与抽帧操作（备用存档）

> 原 视频生成规范 §二点五（2026-07-11 用户裁定，04集单元25→26 首用；2026-07-21 视频生成规范按 Canvas／Guagu 双通道重写时迁移至此存档）。**备用机制（2026-07-23 确认）：本附录仅在 /xiufu 修复或用户点名启用尾帧链式时使用**；何时链、用哪档按 `连续性与状态管理.md` 一点六判定。

需要链时，抽上一单元成片末帧作衔接参考图：

```
ffmpeg -sseof -0.3 -i "成片\单元{N}-….mp4" -frames:v 1 -update 1 -q:v 2 -y "资产图\衔接帧-单元{N}末帧.png"
```
（ffmpeg 路径见 `工具/剪映/剪映配置.json`，PATH 有则直用）

- `-sseof -0.3` = 从结尾倒数 0.3 秒取帧（取绝对末帧偶有黑帧/压缩伪影风险）；`-update 1` 免"image sequence pattern"警告
- 抽帧后必须 Read 看图确认内容（末帧可能停在闭眼/半张嘴等废态，废态就把 -sseof 再往前挪 0.2–0.5s 重抽）
- 衔接帧存本集 `资产图/衔接帧-单元N末帧.png`，用完保留（重跑还会用）
- **提示词与挂载位已由 /fenjing 预写**（2026-07-12 起）：A 档单元的衔接句式在分镜阶段写好、挂载清单第1位预留衔接帧文件——生成期只产出帧文件、照单提交，**不改写提示词**。仅 /xiufu 修复期临时补链的单元仍走旧法：衔接帧插图片1、原素材编号顺移、提示词同步改、Edit 写回
- 链式句式三档（均属 提示词规范.md 第十节"A级链式"之下的细分，编号 A1/A2/A3；04集实测演进，按剪辑意图选档）：
  - **A1级·同机位强继承（正反打/同调度紧接）**：主体直接从衔接帧定义、三视图降级为面部/坐姿参考——`图片1为上一段的结束画面，作为起始画面，人物从该画面中的姿势和站位继续动作。将图片1中的{外观}定义为主体N（{名}），面部特征参考图片{N+1}；……`（单元21→22首用，实测首帧像素级继承；配套锁：保持起始画面站位、位置全镜不互换、机位同侧不越轴）
  - **A2级·换机位（同场景接戏但首帧要新构图，防两段同机位剪辑呆板）**：主体定义句同上，但开头改——`图片1为上一段视频的尾帧，仅作为剧情衔接参考：人物、服装、站位关系与屋内环境从该画面延续，但本视频首帧不沿用该画面的机位，开拍即更换新机位。`（单元22→23首用）。**镜头1必须给正向的具体新机位**（"从屋门一侧朝屋内拍"这种"从哪拍/拍什么"句式）——只写"机位不同于图片1/不沿用原机位"这类否定式，模型会无视并原样继承参考帧机位（04集单元29实测翻车；与"约束句正向优先"铁律同源）
  - **A3级·弱衔接（只接状态；旧称"B级弱衔接"——与 提示词规范.md 第十节的"B级软衔接"（=不链）同名反义，2026-07-12 统一改编号防混淆）**：主体仍由三视图定义，衔接帧只作开场状态参考——`图片1为上一单元的结尾帧画面：{描述帧内容+刚说完哪句}。本单元从该画面状态直接延续，人物姿态、服装、环境光线与该帧保持一致，可以更换机位。`（单元25→26首用）
- 台词衔接：下一单元开场第一句尽量"回声"上一单元的收尾词（如上单元收"这里有六万八"→本单元开口"六万八？你哪来这么多"），声画双锚定
- 改完必须 Edit 写回分镜提示词.md（挂载清单+提示词+修复记录行），保持文件与实际生成一致

## 五点五、场景四宫格【降为修复备用 2026-07-26——场景挂载统一回归全景图整图直挂（资产生产规范 §三），本节派生命令仅在大远景定场镜翻车时启用】

- **派生命令**（ffmpeg v360，从本集全景图直出，无需手动取景器）：
```
ffmpeg -i S{n}-{场景}-全景.png -vf "v360=input=e:output=flat:yaw={0|90|180|-90}:pitch=0:h_fov=95:v_fov=70,scale=768:512" -frames:v 1 前|右|后|左.png
ffmpeg -i 前.png -i 右.png -i 后.png -i 左.png -filter_complex "[0][1]hstack[top];[2][3]hstack[bot];[top][bot]vstack" S{n}-{场景}-四宫格.png
```
- 素材声明写法：`图片N为该[场景名]的四宫格视角图，图中四格为同一房间的前、右、后、左四个方向的普通透视视角，作为场景基准，直接使用该环境`
- 实测（06集A/B单变量对照）：同一六宫格同一提示词，柱形全景版大远景天花板现弧线接缝；四宫格版天花板板缝笔直、地砖透视全直，场景保真度不降
- 备选未用：直出16:9平面场景图（四宫格法已验证通过，此备选留档不启用）

## 使用原则

- /xiufu 遇到"走位/构图/衔接"类翻车，先查本文对应手法，往往比改文字提示词更根治
- 通用补充（非上述三视频，来自其他实测）：**连续 BGM/环境音能掩盖画面剪辑点**——音比画面更易察觉断裂，剪映里一条连续音轨贯穿多段，能进一步盖住拼接感
- 工具差异：原视频的"九宫格多机位""SOBT画布"是特定平台功能；我们用"某帧→GPT Image 图生图出多角度"近似替代，方法可迁移
