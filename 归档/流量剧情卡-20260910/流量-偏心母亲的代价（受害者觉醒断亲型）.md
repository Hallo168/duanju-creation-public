# 偏心母亲的代价（受害者觉醒断亲型）｜原稿存 根目录 对标原稿/04-偏心母亲的代价.md

> 分类：流量剧本（爆款结构库卡片，索引见 ../爆款结构库.md）

- **核心机制**：极端偏心双标压迫累积（钱全给儿子／账单全压女儿／陪床全推女儿的三重双标）+ 受害者本人觉醒 + "钱给谁谁养老"权责对等原则反击 + 拒绝假意求饶、拂袖离场的冷结尾留报应悬念。库内唯一"受害者本人反击、不靠嘴替、不回暖"的流量卡
- **信息差方向**：观众全知·**倒叙前置型**——无身份底牌。第1场把最终不公结果先炸出（"伺候三年 vs 十分钟拿走二十万"控诉句），字幕"二十分钟前"回拉，观众带着已知结局看压迫累积，拉力=看她什么时候反击
- **开场双钩归属**（2026-08-08 回填）：第一画面＝秀梅病床前攥着催款单情绪近乎崩溃、镜头拉开露出冷漠母亲（画面钩·危机进行时）；第一句＝"妈，我伺候您三年，哥来看您十分钟，您就把20万养老钱全给他了？！"（台词钩·数字翻账）
- **人物配置**：承压者/观众代入锚点→觉醒反击者兼金句输出机（女儿，约七成情绪台词）、压迫核心/双标发生器→假意悔悟承担讽刺（母亲）、既得利益者/补刀反派（哥哥，贪婪拿钱+推责拒陪两连，觉醒催化剂）。三人闭环，无嘴替无第三方仲裁，反击权完全在受害者手里
- **结构链**：倒叙控诉钩（结果前置+字幕回拉）→ 压迫铺垫：伺候细节 vs 只念儿子+"女儿照顾是应该的"道德绑架 → 矛盾引爆：儿子首次露面几句甜言拿走存折、质问被"我的钱想给谁给谁"喝止 → 压迫顶峰：催缴单全压女儿+"一家人算那么清楚"双标+试探请哥陪床一晚被拒+母亲帮腔（三连补刀）→ 反转爽点：拍账单宣布"住院费平摊、陪床轮流、钱给谁谁养老"，母亲假意求饶不动摇、抽手 → 冷结尾：离场背影+因果独白，切回病房空手垂落，留"儿子会来伺候吗"报应悬念
- **情绪路径**：愤怒+好奇（倒叙钩）→憋屈压抑→怒值飙升（存折）→**窒息顶峰·第4场（账单+拒陪床+帮腔三连）**→**爽点释放·第5场（对等原则宣言+抽手拒和解）**→唏嘘讽刺后劲（冷结尾）。压迫峰与爽感峰紧挨4、5场
- **金句句式骨架**（原句措辞禁入二创稿）：双标拆穿式（"给钱的时候他是您儿子，出钱出力的时候我们又成一家人了"式，身份随利益切换）；对等反问式（"他的时间是时间，我的时间就不是时间吗"式）；权责对等宣言（"钱全给了谁，就让谁尽儿女的责任"式，全剧爽点句）；不对称对比排比（"他拿走二十万您怕他饿着，我陪床八天您没问过累不累"式）；止损宣言（"我已经让了四十年，再让下去连自己的人生都没有了"式）；结尾因果警示（"儿女的心不是一天凉的""别等到床前没人时才后悔"式，转发钩）
- **刺痛词位**：母亲的理所当然三连——"照顾妈不是应该的吗"（最毒）、"嫁出去的女儿"、"我的钱想给谁就给谁"、"一家人算那么清楚干什么"；哥哥的推责嫌弃（"我哪会照顾病人啊，你心细你留下最合适"）
- **可复用点**：倒叙控诉钩（结果前置+"X分钟前"回拉，库内唯一）；三重双标结构（利益给一方/成本压另一方/责任也推另一方，逐场加码）；"最后试探"铺垫件（反击前先给反派一次自证机会——请陪床一晚被拒，坐实证据让反击站满道理）；权责对等宣言反击；假意求饶+抽手拒和解+冷结尾空手特写；数字反差组设计法（付出时长 vs 露面时长、拿走额 vs 压下额、月薪 vs 账单）
- **注意**：①阿拉伯数字遍布（20万/3万6/5000/40年）且催缴单道具特写带精确数字，二创全转中文数字、道具去数字特写；②结尾独白约150字远超独白红线（≤3句/约40字），必拆或大幅压缩；③存折交接（摸出→接过）踩道具交接崩点，分镜须钉死一人手里或台词完成；④原稿特写密集+慢动作，我方默认中景、禁慢动作，不复刻；⑤"伺候三年"vs"陪床八天"并存，二创须一句话说清（三年=长期照顾、八天=本次住院）免穿帮；⑥第3场女儿一句为原整理者补全台词；⑦无破壁提问互动弱，二创可补站队钩；⑧单一场景（病房+走廊）场景经济极好，三人同屏不超限，无雨戏；⑨无来源方数据表现，骨架有效性未经我方验证
