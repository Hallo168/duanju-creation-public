# 短剧工具箱

AI 短剧二创流水线的**工具层**：台词稿 → 资产生图 → 分镜提示词直生视频 → 剪映后期的全部脚本与本机服务。本仓库由主创作仓库单向导出生成（全新 git 历史，不含任何密钥、账号与创作资产）。

## 内容

| 目录 | 说明 |
|---|---|
| `工具/symphony/` | TikTok Symphony 视频通道本机代理（FastAPI，直连提交/轮询/下载＋浏览器兜底） |
| `工具/剪映/` | 剪映草稿读写：加解密、音轨写入、草稿降级 |
| `工具/配乐/` | 配乐库索引与配乐方案脚本 |
| `工具/*.py` | 各视频/生图平台的批量执行器与探活脚本 |
| `外部依赖/` | 三个收编的开源项目源码（见其 README：来源、许可证、安装） |

## 快速开始

1. 前置：Python 3.13＋[uv](https://docs.astral.sh/uv/)、Node.js（含 npm）
2. `python 外部依赖/安装.py` —— 重建 node_modules 与两个 .venv
3. 补凭据（都不在仓库里）：`外部依赖/chatgpt2api/config.json`、`外部依赖/flow2api/config/setting.toml`、`工具/api配置.json` 里被置空的 `api_key` 字段
4. `工具/symphony/symphony配置.json` 按本机改路径与账号，然后 `工具/symphony/启动代理.cmd`
