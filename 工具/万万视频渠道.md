# 万万视频渠道（慢速）

已于 2026-10-13 保存为 `wanwan_video`，按需选择。

- 接口根地址：`https://wanwan.coolhs.com`
- [API 文档](https://wanwan.coolhs.com/docs#auth)；[OpenAPI 规格](https://wanwan.coolhs.com/openapi.json)
- 渠道配置：`工具/api配置.json` 的 `providers.wanwan_video`。
- 卡密单独保存在 `<用户目录>/.codex/runtime/credentials/wanwan-video.txt` 的 `KEY` 字段；配置不含卡密正文。

## 认证与模型

每次请求携带 `Authorization: Bearer <卡密>`；也支持 `X-Wan-Card: <卡密>`。请求需带 `User-Agent: Mozilla/5.0`，文档注明 Python 默认标识会被 Cloudflare 拒绝。

2026-10-13 实时 `GET /v1/models` 返回 `wan`、`wan-480p`、`wan-720p`、`wan-1080p`。文档支持 2–30 秒和 `9:16` 等画幅；本次未指定默认模型或分辨率。

## 提交与查询

| 用途 | 接口 |
|---|---|
| 模型列表 | `GET /v1/models` |
| 是否收单、排队状态 | `GET /v1/ride` |
| 卡密额度 | `GET /api/portal/me` |
| 上传素材 | `POST /api/portal/media` |
| 提交 | `POST /v1/videos` |
| 查询原任务 | `GET /v1/videos/{task_id}` |
| 下载成片 | `GET /v1/videos/{task_id}/content` |

`/v1/videos` 使用下划线字段：`model`、`prompt`、`seconds`（字符串）、`size`、`n`；JSON 或 multipart 均可。带参考图时，文档示例使用 multipart 的 `input_reference`；预上传素材的驼峰字段协议见原文档，不混用字段。

按用户指定的慢速版使用方式，**每 1800 秒（30 分钟）查询一次原任务**，采用配置中的 `poll_interval_seconds`。查询响应已经包含候车状态 `wait`，无需每次额外查询班次。`wait.phase` 为 `done` 或 `failed` 时停止该任务轮询；排队和处理中继续查询原任务。

本次仅保存配置与卡密，并核实公开模型接口；未提交视频任务，未消耗生成额度。现已提供专用批量执行器 `工具/wanwan_video_batch.py`。

## 多图批量执行器

`工具/wanwan_video_batch.py` 使用官方 `/api/portal/media` 上传去重素材，再以 `/api/portal/jobs` 的 `media[]` 逐单元提交，`token=图N` 对应本单元挂载顺序，`role=ref`。指定 `resolution=1080P`、`duration=30`、`ratio=9:16`、`audio=true`、`copies=1`；此接口的1080P任务在同一渠道对应`wan-1080p`，不改变项目默认渠道。官方单任务最多10张图，项目仍按9张上限。

执行器分 `prepare / submit / poll / watch`。请求和自定任务ID先落盘，远端已有同提示词任务则先对账；有提交尝试的任务只查询原ID，不自动重发。`watch`沿用1800秒间隔，完成后下载到指定成片目录并核对时长、1080×1920及音轨；失败保留账本，不自动重提。
