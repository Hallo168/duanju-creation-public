# 阶段零：参考文案拆解

> 用法：核心规则 + 本文件 + 参考文案，一起发给 AI。拆解确认无误后，再进入选题阶段。
> 拆解结果同时存入项目的爆款结构库（`爆款结构库/` 一卡一文件＋《爆款结构库.md》索引行），骨架积累复用。

**拆解总铁律（2026-08-06 蒸馏项目移植）：验证过的爆款没有缺陷，只有没看懂的设计**——看不懂的先当设计存疑，不当缺陷改掉。收到参考文案后输出结构拆解并**直接入库、不等确认**（2026-08-06 改，原：先输出等待确认）；**判型、判抓手是头两件事，开头一句大白话报结论，让用户能拦**。这个阶段不出选题，不写剧本。

按以下格式输出（每条一到三句话，写判断不写复述）：

【剧本类型】：带货剧本（写明产品和口播卖点顺序；2026-09-11 停做流量素材，存量流量稿只作历史拆解）。

【观众抓手】（2026-08-06 新增）：镜像型／愿望型／后怕型／观赏型（定义见 7-选题生成法 §〇），一句话说明凭什么抓住观众。**二创保真沿用、不许换挡**。

【核心机制】：这个剧本靠什么让人看下去。例如"隐藏身份+人性测试+证据回放打脸""误会型温情反转"。

【剧情分类入口】：按[爆款结构库的归类与复用约定](../爆款结构库.md#plot-rules)标“大类／小类／具体源版本”及辅助机制标签；主归属集中登记在总索引，本卡留来源与小类入口指针。同源变体记录原稿完整路径，判不准的保留待分类与差异，不靠换产品名新增小类。此字段是剧情分类，与下方带货框架归属分开。

【信息差方向】：观众同惊型（身份藏到揭晓，观众和反派一起被打脸）还是观众全知型（开场亮底牌，观众全程期待兑现）；底牌在第几场、以什么方式亮给观众。

【人物功能配置】：每个人物在结构里承担什么功能（测试者 / 被测者 / 反派 / 正面主角 / 揭晓工具人 / 捧哏 / 替观众发问的人），而不是他们叫什么。

【场次节奏表】（2026-09-01 升级）：逐场三件事——①结构任务（例"第三场：压迫升级，正面角色用行动站出来"）；②因果推力：这一场的结果如何逼出下一场（谁做了什么、为什么做、结果是什么、下一场为何必然发生）；③观众心理功能：这一场拿住观众的是什么（站队/悬念/心疼/期待兑现/解气……一句话）。只写"发生了什么"＝不合格：❌"女主被欺负→贵人出现→反派被惩罚"；✅"冒名者逼签离职协议并踩碎研发记录→维修工冒险拦下即将离场的董事长说出真相→董事长取消行程返回制止"——每个节点自带因果与推力。

【情绪路径】：用箭头写出观众情绪的变化链，标出峰值在第几场；对标故意不解决、不解释的**悬停点**单独标出（冷结尾留报应悬念、不点破的误会之类——悬置是设计不是缺陷，2026-09-01 增）。

【关键反转】：反转揭露了什么信息，靠什么揭露（人物登场 / 实物证据 / 回放 / 当事人开口）。

【产品切入】（带货剧本才写）：
- 切入方式：生活痛点 / 身份任务 / 混合
- 轻伏笔位置：**已废止**（2026-08-08 二轮，见 3-带货模块「禁埋暗线」）；产品首现形态只记"软咬合＝首现紧贴带货位 / 硬广后置＝带货段才首现"二者之一
- 正式带货位置：在第几场，位于身份揭晓/打脸之前还是之后，是对话式还是独白式，谁在捧哏、问了什么（2026-08-06 起此项不只是事实记录——二创带货段形式与话术直接跟随对标整段沿用，见 3-带货模块）
- 主讲人选与口吻：谁主讲（日常使用者 / 渠道权威 / 见证者 / 受益者），口吻是用法、价格、效果、亲历中的哪种
- 话术链（2026-09-02 改按功能位切分）：把带货段逐句归到七个功能位（切入/卖点/号召行动/剧情情绪加码/逼单/收到预期/再次逼单，定义唯一出处＝3-带货模块「带货段三层资产与功能位」），标出缺哪环、逼单几波、加码挂的剧情事件、捧哏形态
- 框架归属（2026-09-02 新增）：对照 `带货框架库.md` 索引标归属框架——归得进的在该框架卡「样本清单」追加一行；归不进的（环序或逼单结构不同）按框架卡体例出**新框架候选**交用户拍板后立卡
- 转化话术候选（2026-09-02 新增）：通用句（切入针脚/号召/加码/逼单/再逼单，及卖点/预期的讲法句式骨架）按功能位对照 `knowledge/转化话术库.md` 查重入库，每句标"谁能说"＋槽位＋源，数字中文化、渠道句改"点左下角链接"；产品专属内容（卖点/预期画面）该品在产品库的写进其 `产品规格.md`「转化话术素材」节，不在库的留卡内
- 返回主线方式：带货结束后用什么剧情收束

【结尾互动钩子】：结尾用什么引导评论/点赞/转发（提问、求祝福、金句、站队话题）。

【金句清单】：摘出剧中承担传播功能的金句及其出现时机。

【开场双钩】（2026-08-06 新增）：台词钩＝第一句；画面钩＝第一画面靠什么钉住人。弱钩对标要点名（如靠"逐步暴露不对劲"慢开的），并标真钩位置在第几场。拆完对照 `爆款开头库.md` 标**模式归属**（2026-08-08 新增：画面钩＋台词钩各归到模式条目写进卡片；套不进的按库头规则立新模式入库；弱钩不立模式，按库规约三找真钩归属）。

【刺痛词清单】（带货剧本重点写）：摘出反派最毒、观众会气到去评论区复述的台词短语（"别耽误我做头发"级别），标出各自出现的场次。

【台词手法】（2026-08-06 新增）：好句逐句往 `手法库.md` 已有手法上标归属；套不进的提"新手法候选"（≤3行格式）；例句比锚例强的提"替换锚例"。

【可复用 / 必须换新 / 换皮限制】（2026-09-01 扩三栏）：①可复用骨架；②必须换新的皮——可替换变量逐项点名（人物身份/关系名词/场景/事件名目/道具/台词措辞）；③**换皮限制**＝负向不变式：逐条写"动了哪一件这台机器就塌"＋一句塌因（例式："证人只给'她很努力'式空话＝可信度塌，必须有具体劳动细节或实物证据""揭穿必须连续露馅，一句话揭穿＝考核环节白建"）。写不出塌因的限制不立。/xuanti 对标线提机件层时，③与①是底料。

【风险提示】：参考文案里踩了我方禁区的地方（雨戏、阿拉伯数字、绝对化用语、称呼不一致等），二创时需规避或修正。

【规则回测】（2026-08-06 新增，收尾必做）：这条对标（是爆款）有没有违反我方任何现行规则仍然成立？有＝逐条记入 `规则变更日志.md` 误伤台账（同一条款累计两次触发复审）。这是"框架越用越宽"的执行点——每条新对标都是对规则库的一次回测。
