# 情绪外化字典

> /fenjing 第3步（写单元提示词）前加载，/erchuang 预标情绪时参考。
> 总原则：**视频模型对抽象情绪词的理解远弱于拆解后的物理描述。所有情绪必须翻译成三层：身体部位动作 + 声音状态标注 + 标点节奏。**禁止在提示词中裸写"生气地说""很伤心"。
> 补充总纲（2026-07-28 金标准蒸馏）：**语速默认紧凑（§2.0）、冲突节拍上"一大一小"、反应快半拍、峰值定住一拍（§八）**——三层外化解决"演不演得出来"，这两条解决"像不像短剧"。
> 来源：项目自建 + AI视频实测经验（Seedance 2.0，梧桉AI等）+ 金标准样例 01 规范（2026-07-28）。
> **防膨胀硬规（2026-09-11 补，照手法库体例）**：只收**可复用的外化句式**，不收单集专用句；新对标/新实测的情绪写法先往已有条目上套，套得进只许**替换**更强的锚例、不追加新行；每节超 20 条先合并同类；全文件超 30KB 触发瘦身（回溯来源、合并近义、删已进 skill 层的转述）。

| 羞辱 | 脸颊到耳根迅速涨红，头低下又强行抬起，指甲掐进掌心，眼眶发热却死死瞪着对方，嘴唇抿成发抖的直线 |

## 二、声音层（写进台词 `{}` 外的圆括号标注）

### 2.0 语速基线：默认紧凑，慢速是特权 ★（2026-07-28 金标准蒸馏，总纲级）

> **整片的拖沓感，就是从每句都写克制慢速里来的。**

- **默认句（没有特殊动机的每一句台词都按这个写）**：`语速自然偏快、吐字清楚有力、句间衔接紧凑、不拖尾音`
- **"缓慢、迟疑、停顿片刻、若有所思、沉默、语速放慢"只给有剧情动机的角色或时刻**——老人的稳定语速、心死、绝望后冷静、愧疚，这些下方声音层表里明确标了慢的条目才允许慢（得意拖音已废止，2026-08-11）。**不做全员默认**。
- 与 T18/F8 的分工：T18 管**装多少字**（密度），本条管**用多快念**（语速）。两条同时松，成片必拖沓；密度写够了但每句都标"缓缓地说"，Seedance 照样把 15 秒摊慢。
- 反→正：❌ 全单元每句都是"（声音低沉，缓缓开口）" ✅ 只有心死那一句慢，其余"（语速偏快，吐字有力，句间不留空）"

### 2.0b 音量红线：禁"轻声/小声"类低音量指令 ★（2026-08-11 用户实拍裁定，制作层红线；生效通道＝Symphony 生产实测，按 CLAUDE.md 14.5 换通道复验）

> **低音量指令生成出来的是气若游丝＋语速被拖慢——情绪没收住，节奏先垮了。**与 §2.0 同病根，一并按红线管。

- **禁用词族**（声音标注一律不写，同义表述同禁）：轻声／小声／低声／耳语／气声／气音／压低声音／压到气声／音量压到极低／音量放轻／声音很轻／音量很低／越说越低／几乎听不见
- **音量档位只升不降**：2.2 第 3 项只允许"比上一句高一档／陡然拔高"方向，禁写降档
- 情绪要"收"时音量不降档，改走四条通道：**音色**（发紧／发哑／发干／闷住）、**长度**（放短、字字钉下去）、**停顿**（长停顿、半晌才开口、字间有抽气）、**平直**（没有任何起伏、字字清晰）
- **两层共用**：成稿预标同禁——源头不写，分镜就不用删

### 2.1 声音 DNA 七槽句式（角色首次开口必写全，同集后续可缩写）

金标准范文的标准写法，七个槽位一次给足，模型才不会每镜换一个音色：

```
[角色名]以[年龄][性别]自然原声，[音色]，[口音]，吐字清楚，[语速档]，[力度＋表达意图]，说：{台词}
```
> 老周以七十二岁男性自然原声，略低、带轻微沙哑，普通话带很淡的北方生活口音，吐字清楚，老年稳定语速，力度克制、字字放稳，说：{……两万三，我都准备好了……你可别哄我啊。}
>
> 周涛以四十多岁男性自然原声，中低音、普通话清楚，语速稳，力度克制缓和地说：{爸，我们不是审您。}

- 七槽：**年龄感 / 音色 / 口音 / 吐字 / 语速 / 力度 / 表达意图**。缺"年龄感"最容易翻车——不写年龄，中老年角色会被配成中青年声。未成年角色的年龄感照写本槽（"十五六岁少女清亮原声"式）；叙述层年龄不再受限（2026-09-03 解除去龄化默认，细则见 提示词规范 T10.1）。
- 同集后续镜头缩到 2–3 槽即可（`老周（略低带沙哑，老年稳定语速）`），但**措辞一字不改**（同 F9 身份块规则，声音也是身份的一部分）。
- 与下表的关系：七槽句是**角色的声音底色**（一集不变），下表的情绪标注是**这一句的即时变化**（逐句变）。两者叠加写。

### 2.2 可听参数五件套（冲突对白必须命中 ≥2 件）

**禁止**"愤怒地说""悲伤地""痛心疾首地"这类文学形容——它们不是声音，是读后感。改写成可听的：

| # | 参数 | 写法示例 |
|---|---|---|
| 1 | **重音落点**（砸在哪个词） | `重音砸在"棺材本"三个字上` `每个"你"字都加重` |
| 2 | **句尾走向**（上扬/下砸/悬空） | `句尾往下砸` `尾音上扬又哽住` `尾音悬着没落下` |
| 3 | **音量档位**（相对上一句，只升不降·2.0b） | `音量比上一句高一档` `音量陡然拔高` |
| 4 | **句前情绪声** | `倒吸一口气才开口` `先从鼻腔冷笑一声` `喉结滚一下` |
| 5 | **句尾情绪声** | `末字带哽咽` `说完从鼻子里哼出气` `尾巴上带一声短促的笑` |

下表各情绪条目已经把 2/3/4/5 覆盖得比较满，**最常被漏掉的是第 1 项"重音落点"**——写冲突台词时优先补它，它决定观众听懂哪个词是刀。

| 情绪 | 标注写法 + 台词示例 |
|---|---|
| 生气·压抑型 | （声音从压抑的低沉逐渐提高，尾音发颤）{你到底……想骗我什么？} |
| 生气·爆发型 | （哽咽怒吼，音量陡然拔高）{够了！} |
| 生气·冷型 | （一字一顿，牙缝里挤出来）{好。很。好。} |
| 震惊 | （倒吸一口凉气，半晌才挤出声音，音量比平时低）{你说……什么？}——省略号+首字重复（"你、你说"） |
| 羞辱 | （声音发紧，从喉咙深处挤出，尾音带着不甘的颤）{够了……你说够了没有。} |
| 得意 | （笑意浸在声音里，尾音上挑带刺，重音砸在"求"字）{哦？现在知道求我了？} |
| 恐惧 | （声音发抖发干，语句破碎不成句，字与字被急促的抽气打断）{别……别过来……我求你……} |
| 心死 | （平静到没有任何起伏，字字清晰，语速比正常慢半拍）{好。我知道了。}——**全部句号，禁用感叹号和省略号** |
| 绝望后冷静 | （声音低、稳、干净，没有哭腔也没有怒意，尾音轻轻落下像盖上句号）{你走吧。} |
| 嫉妒 | （笑着说，但字与字之间隔得略长，甜度过头）{你们，还真是般配呢。} |
| 委屈 | （带浓重鼻音，每句结尾音调上扬又哽住）{我明明……我明明都是为了你……} |
| 强忍眼泪 | （声音发紧、放短，尾音像喉咙被堵住但仍努力说完整）{我没事。} |
| 急切辩解 | （语速加快，尾音发虚）{晚晚，你听我解释，不是——} |
| 心疼的责备（对亲近者，04集补） | （急得声音发哑，责备里全是心疼，音量提起来一瞬又半截哽住）{车卖了你怎么接活？！}——身体层配"前倾+攥紧衣物/毛毯+眼眶发红"，**禁配"吼/撑桌撑扶手/胸口起伏"的怒气动作**（配了就从心疼变凶） |
| 悲伤·忍泪 | （声音闷住，每个字之间有细小的吸气声）{没事。你们吃吧。} |
| 羞涩·心动 | （声音放软不放小，尾音微微发软，不要太甜也不撒娇）{你怎么来了。} |
| 决绝 | （音量不高但每个字都钉下去，中间不留犹豫的停顿）{这件事，到此为止。} |
| 轻蔑 | （从鼻腔发音，句尾上扬带笑，语速慢而漫不经心）{就这？} |
| 愧疚 | （声音发哑发涩，尾字短促收住，中间有长停顿）{是我……对不起。} |

## 三、标点节奏（标点即表演指令）

| 标点 | 声音效果 | 用法 |
|---|---|---|
| 省略号 …… | 哽咽停顿、犹豫、气短 | 悲伤/恐惧/震惊；一句内 ≤2 处 |
| 破折号 —— | 话被打断，后句立刻抢入 | **仅限被抢话截断**；拖长音用法废止（2026-08-11 用户裁定：节奏太慢），得意拖音同废 |
| 密集逗号 | 急促、慌乱 | 辩解、恐惧（"我，我不是那个意思，你听我说"） |
| 短句号 | 冷硬、压迫、决绝 | 冷怒、心死、决绝（"好。很。好。"） |
| 感叹号 | 爆发 | 慎用，一个单元 ≤1 处，只给最高爆点；心死/绝望后冷静禁用 |
| 首字重复 | 结巴、失措 | 震惊、恐惧（"你、你说什么"） |

## 四、递进写法（AI视频核心技法·"拒绝抽卡"的关键）★

**单个情绪镜头不要写成静态的一个表情，要写成一段"变化过程"——模型演的是过程，不是定格。**这是 AI 演技从"呆滞"到"影视级"的分水岭。

**重要：用"先…接着…最后…"的自然语言分阶段描述，禁用"0-1秒/1-2秒"时间码**（官方：Seedance 对精确时间支持不稳定，见提示词规范）。业内很多教程用时间码，我们取其"分阶段"的思想、去其时间码的形式。

**示范·绝望后冷静（一个特写镜头内）**：
```
镜头1：面部特写，全程静止。她起初看着对方，眼里还有残留的痛，呼吸不稳，嘴
唇微张；接着眼神一顿像突然想明白，眉头慢慢松开但眼神变空；随后呼吸平下来，
脸上的痛一点点收回，下巴不再颤；最后目光变得清醒而遥远，平静开口。
她（声音低稳干净，没有哭腔）{你走吧。}
```

**示范·哭戏递进（痛失所爱，一个中近景）**：
```
先是听到消息的震惊失神——眼神停住、瞳孔轻颤、呼吸像断了一下；接着眼里的光
暗下来、下眼睑蓄泪却没落；然后第一滴泪滑落、嘴唇抿住撑不住；最后身体前弯、
低头哭出声，哭声断续带哽咽，肩膀发抖。
```

**递进四段常用骨架**：震惊/怔住 → 强忍/克制 → 破防/决堤 → 失力/耗尽（或收束回平静）。每段只给身体信号，让模型自己连贯。

## 五、高强度情绪的 AI 翻车防御（哭戏/怒戏必加）★

实测：Seedance 等模型演强情绪（尤其哭戏）有固定翻车模式，必须在约束尾用正向+否定组合拦截：

**哭戏翻车四宗罪 → 防御写法**：
- 脑门/额头爆青筋、血管凸起 → 正向："额头平滑自然，眉心不过度挤压"
- 未哭先红（眼睛没开始哭就通红）→ 正向："眼眶只微微发红，泪水自然聚积"
- 眉头用力挤压、深皱纹 → 正向："眉头只轻微收紧，不用力皱眉"
- 脸部畸变、五官扭曲、表情狰狞 → 正向："面部肌肉保持柔和，表情克制精致"

**肤色红线（指针）**：脸色发白/煞白/铁青/面无血色等青白系肤色词一律禁写——模型逐字执行颜色指令，真渲染青白脸；禁词清单与细则唯一出处＝分镜自查检验.md F21。"吓得失色"用第一节恐惧/震惊条目的肌肉姿态写法替代。

**否定句补充**（备选清单，实测有效；受 T16 否定句总量 2–3 条上限约束——与「生成视频不要出现任何字幕」、不生成水印**合计计数**，故每单元只从中挑本单元最高风险的 **1 条**追加，可并句写如"不要青筋、不要五官扭曲变形"，其余风险交上方正向防御句承担）：`不要青筋 / 不要眉心凸起 / 不要脸部变形 / 不要五官扭曲 / 不要狰狞表情 / 不要嘴巴张太大 / 不要眼睛翻白`

**总原则**：强情绪 = "克制的强"。演哭不是嚎哭，演怒不是狰狞——**悲伤靠眼神失焦+呼吸断续+眼泪滑落+嘴唇发抖+身体失力，愤怒靠下颚绷紧+胸膛起伏+牙关紧咬**，把情绪压在肌肉和呼吸里，比夸张的表情更高级也更不容易崩。

## 六、情绪递进曲线（跨镜头·单元内声音演变示范）

平静 → 不安 → 愤怒 → 崩溃 → 平静，10 句内完成：

```
{这封信是你写的？}（平静，手里拿着信）
{……是。}（不安，手指绞在一起）
{三年前写的？}（追问，声音开始紧绷）
{我当时不知道该怎么办。}（防御，语速加快）
{所以你选择不告而别？}（愤怒，声音提高）
{我以为那样对你更好！}（激动，站起身）
{更好？}（崩溃边缘，声音颤抖）
{你知道这三年我是怎么过的吗？}（眼泪涌出）
{……对不起。}（崩溃，双手捂脸）
（长久的沉默）{坐下吧。我们慢慢说。}（深吸一口气，平静回归）
```

## 七、使用规则

1. 每个爆点句必须三层齐备：身体动作（写进镜头描述）+ 声音标注（`{}` 外圆括号）+ 标点节奏（`{}` 内）
2. **单个情绪镜头写成递进过程**（第四节），不写静态定格；强情绪镜头必加翻车防御（第五节）
3. 对白镜头**听者的反应动作与说者同等重要**——被打脸方的僵住、围观者的倒吸凉气，都是爆点的一部分
4. 沉默也是台词：爆点前 2–3 秒的静默拍用身体层填充（攥拳/转身/倒酒/秒针声）
5. "蓄而不发"（第一节·藏不住型）只作**破防前的蓄力拍**：最多蓄一两拍，蓄完必须当场发出来（§九.3 破防落大动作）——能哭出来就绝对不憋着，禁整场蓄而不发（2026-08-11 用户裁定收窄，原"优先用在忍辱/暗恋/愧疚戏"的整场用法废止）
6. 同一情绪在一集内第二次出现时换一种外化写法，避免观众审美疲劳
7. **语速默认紧凑**（2.0）：没有剧情动机就不写慢——这是全片节奏的总闸
8. **冲突节拍必须上"一大一小"**（第八节）：1 个大幅度身体动作 + 微表情承接；反应快半拍，峰值定住一拍
9. **表演不复读**（分镜自查检验 F24）：说话人换了，表演描述必须跟着换；倾听者逐人单独写
10. **情绪饱和度全台词拉满**（第九节）：每句顶格、禁平淡温和含蓄；爆点句禁温标注、五件套≥3、忏悔/哭戏必上大动作、冲突单元至少一处三层全量爆点
11. **/fenjing 写作应用与审核边界（2026-09-10 用户批准精简）**：首次开口的七槽声音DNA、重场递进表演、台词情绪与音量写法，在落笔时按本字典执行；**取消原写盘后四项逐镜/全台词硬性复审**。例行核对仅按 `.claude/skills/fenjing/SKILL.md` 第5.5步，在开场、关键反转、产品展示快看明显情绪缺失，不由本字典追加全篇扫描或返工轮次。剧本层使用本字典的流程照原命令执行。

## 九、情绪饱和度：全台词拉满档 ★（2026-07-31 用户裁定立下限；2026-08-11 用户裁定升格为**全台词默认**）

> 总精神：**所有情绪拉满到极致——禁止平淡、温和、含蓄的表达。每句台词都把情绪顶到该句的最满，表达方式二选一从高不从低：能喊出来就绝对不说出来，能哭出来就绝对不憋着。**适用范围＝全部台词，不再只管爆点句。
> 与第五节"克制的强"的调和公式：**声音层拉满、身体层控幅、面部靠防御句兜底。**声音是生成音频——吼、破音、哽咽、劈掉都不会导致画面畸变，它是拉满情绪最安全的通道；画面幅度继续按"一大一小"（第八节）控制，面部风险交第五节正向防御句。
> 禁写标注黑名单（任何一句都不许配）：平静地／淡淡地／温和地／轻描淡写／云淡风轻／欲言又止／点到为止式含蓄留白——冷情绪的"平"不在此列，见第 5 条。

**1. 爆点句禁"温标注"**

爆发型台词（怒斥/揭穿/控诉/求饶/哭喊，即台词里带感叹号或字面在骂在喊的句子）禁止只配中性档声音词。"声音发紧""尾音发颤""语速加快"是铺垫戏的标注，不配给爆点。爆点句的声音必须给到该情绪的顶：

- ❌ （声音发紧）{你怎么能这么对我妈！}
- ✅ （哽咽怒吼，声音劈了，音量陡然拔高，重音砸在"我妈"）{你怎么能这么对我妈！}
- ❌ （尾音发颤）{他们当您手里没牌了！}
- ✅ （声音又急又劈，音量拔到喊，末字带颤）{他们当您手里没牌了！}

顶格声音词备选池：吼／哽咽怒吼／声音劈了／破音／喊到嗓子哑／哭到说不完整、字与字被抽气打断／从吼塌成哽咽／音量陡然拔高一档再拔一档。

**2. 爆点句五件套 ≥3 件，且必含"音量档位"或"句前情绪声"**

普通冲突对白维持 2.2 的"≥2 件"；**爆点句提到 ≥3 件**。音量档位（比上一句高一档／陡然拔高）和句前情绪声（倒吸气／先冷笑／喉结滚动）二者至少占一——没有音量变化的"爆发"不是爆发。

**3. 忏悔／报恩／哭戏 = 掏心掏肺档，身体层必上大动作**

忏悔、认错、报恩、诀别、哭戏单元禁止只写"眼眶泛红／眼眶发热／低下头"级微表情。身体层必须给一个掏心掏肺级大动作：**跪下／磕头／死死抓住对方的手或衣角不放／瘫坐在地／捶自己胸口／把头抵在对方手背上**。声音层同步给崩溃档（哭到语句破碎、带浓重鼻音哽咽、越说越不成句）。"眼泪打转"是蓄的写法，只许用在破防前一拍，破防之后必须落大动作。

**4. 冲突单元每单元至少一处"三层全量爆点"**

一个冲突/打脸/爆发单元里，至少一个镜头同时命中：**大幅度身体动作（第八节"一大"）＋顶格声音标注（本节第1条）＋标点爆点（`{}` 内感叹号或破碎句，属台词层，仅核对不改写）**。全单元从头到尾都是眉骨微压、喉结滚动的收敛微表情＝不合格——那是文艺片，观众划走（08集病根）。铺垫单元不受"三层全量爆点"定额约束，但**同样禁平淡温和含蓄**（2026-08-11）——铺垫句按 §2.0 紧凑直给、快而有力，一有情绪立刻顶格。

**5. 与既有规则的边界**

- 台词 `{}` 内一个字不动（上游锁定契约）——本节全部火力都打在 `{}` 外的声音标注与身体层。
- 感叹号"一单元≤1处"（第三节）管的是台词层写作，/fenjing 阶段台词已锁定，按原样核对即可，不因本节增删。
- 心死／绝望后冷静／隐忍类**冷情绪不适用本节爆发定额**——它们的"满"就是彻底的平与冷（那是狠，不是温和，不算被禁的平淡），照第一、二节收敛写法执行，别硬塞爆发。但冷情绪只给真正的心死/诀别/隐忍节点，**不许拿"收敛"当全场默认档**（2026-08-11）。

## 八、表演节奏档：一大一小 / 快半拍 / 定住一拍 ★（2026-07-28 金标准蒸馏）

> 前七节解决的是"情绪有没有被外化"，这一节解决的是"外化得像不像短剧"。第一节身体层是**素材池**，本节是**从池子里怎么配比、什么时候动**的法则。

**1. 一大一小（短剧演技档，冲突/质问/打脸节拍必上）**

冲突节拍每镜的 3–5 个可见线索里：
- **必须有且只有 1 个大幅度身体动作**——拍桌、指人、猛回头、逼近一步、猛地起身、把东西拍在桌上、一把攥住对方手腕
- **其余全部用微表情承接**——眉骨轻压、下颚微绷、瞳孔一缩、喉结滚动、鼻翼一张、握着的手指再收紧一档、呼吸一停

机理：**大动作给短剧张力，微表情去 AI 感，缺一头都不行。**
- 只有微表情 → 成片是文艺片，观众划走（08集"推翻重写"的原始病因）
- 只有大动作 → 满屏张牙舞爪，AI 感和廉价感直接拉满，且大幅度动作越多越容易畸变穿帮

**日常铺垫戏不上大动作，全按微表情写。** 一个单元里大动作最多 1–2 个，全给爆点镜。

**2. 反应快半拍（去 AI 感的最省力开关）**

- ❌ `听完后缓缓抬头` `等对方说完，她慢慢转过脸`
- ✅ `话音未落就猛地抬头` `对方"离婚"两个字还没落地，她的手已经僵在半空` `没等他说完就抢过话头`

真人的反应是**抢在台词结束之前**发生的；写成"听完→反应"的串行链，成片就是两个机器人在轮流发言。这条与"台词与动作并行"同源（提示词规范 §十四·4）。

**3. 峰值定住一拍（定格是重音，不是慢）**

- 峰值动作（指着人的手、瞪视、扬起的巴掌、拍下去的手）**做到位后定住约 1 秒再切镜**——这一拍是节奏里的重音，必须保留。
- 要删的是**无信息的过渡帧**：走完全程的走位、完整的转身、镜头等人开口、动作做完后慢慢收回。
- 口诀：**快节奏＝删过渡，不是删重音。** 与 Y17 静默拍兼容——静默拍是"人在场的沉默"，也是重音的一种。

**4. 三条的组合写法（金标准范本，四人客厅冲突镜）**

```
老周眉骨轻压、下颚微绷、右手压兜的力度增加，语气从疑问转为受伤的反击（微表情×3）；
周涛话没说完就被抢断，手掌朝下轻抬一次又收回（快半拍 + 小动作）；
周晓慧在三人沙发右座抿住一句话后自然呼吸（倾听者微表情）；
秀兰捏围裙角的手指松开少许（倾听者微表情）。
```
注意这一镜**没有大动作**——因为它是铺垫拍。大动作留给下一个爆点镜。
